# 計算クエスト 〜数のダンジョン〜

中学生向けの**計算力トレーニングゲーム**。古典クエストの姉妹作（同じダンジョン構造・3モード・能力値・レーダーチャート）。
**正負の四則（中1）〜二次方程式（中3）の「計算」を網羅**。文章題・立式は扱わず、計算技能に特化。

公開URL：https://gamigamiigami.github.io/Workspace/keisan-quest/

## 全体構造（ねらい4点との対応）

```
🏰 数のダンジョン
├ ⚡ 暗算の塔（テンキーで即答）→ ⚔️攻撃力    …「瞬時にできる」
├ 📏 数直線の間（位置タップ・大小）→ 💫直感力 …「感覚的にできる」
├ 🧱 基礎の塔（9段位ドリル）→ 💪体力        …「基礎がしっかり」
└ 📝 途中式の間（道筋を組む）→ 📖知力       …「途中式で理解」
   ＋ 📅今日の試練クリアで 🛡防御力+1（共通）
   ※全塔に修行（★段位）／今日の試練（日替わり）／真剣勝負（1ミス即終了・時間制）
   ※能力値＝修行★換算（全★30）＋真剣勝負ベスト。レーダーチャート・称号も古典クエストと同仕様
```

## 各塔の内容

| 塔・間 | 回答方法 | 段位 |
|---|---|---|
| ⚡ 暗算の塔 | テンキー（±キーで負の数） | 正負加減→乗除→四則累乗→分配法則ワザ→√暗算（5段） |
| 📏 数直線の間 | 数直線タップ（誤差±OK）／大小2択 | 加減位置→乗除位置→分数小数大小→√のありか（4段） |
| 🧱 基礎の塔 | テンキー（□に入る数・解を入力） | 正負→文字式→一次方程式→単項式多項式→連立→展開→因数分解→平方根→二次方程式（9段） |
| 📝 途中式の間 | カードを正しい順にタップ／まちがい行をタップ | 一次方程式→連立→展開因数分解→二次方程式（4段・手作り15問） |

## 特徴

- **問題は乱数生成**（テンプレート×乱数）なので無限に出題。今日の試練は日付シードで全員同じ問題
- ミスの瞬間に型別ヒント（「移項したら符号が変わる！」「(−3)²と−3²はちがう！」）
- (−3)² vs −3²、x²+7x+6=0の「大きいほうの解は−1」など、**あるあるミスを意図的に出題**
- 「計算のコツ」早見表（符号・移項・乗法公式・因数分解・平方根・二次方程式）

## 技術仕様

- 1ファイル完結（`index.html`）・外部ライブラリ／CDNなし・オフライン動作
- 生成器は全問スクリプト検証済み（5,400問生成して答えの整数性・数直線範囲・大小の非同値を確認）
- セーブはlocalStorage（古典クエストとは別キー）
- iPad縦持ち優先・タップ領域44px以上

## 問題の追加方法

- **生成問題**：`GEN_ANZAN`／`GEN_LINE`／`GEN_KISO` の配列に「rng を受け取って問題オブジェクトを返す関数」を追加（1関数＝1段位）
- **途中式**：`TOCHU` 配列に追加
```javascript
// 並べかえ
{ stage: 0, kind: 'order', q: '2x＋3＝11', steps: ['2x＝11−3', '2x＝8', 'x＝4'], exp: '解説', hint: 'ヒント' },
// まちがい探し
{ stage: 0, kind: 'err', q: '問題文', lines: ['行1', '行2'], wrongIdx: 0, exp: '正しい式と理由', hint: 'ヒント' },
```
