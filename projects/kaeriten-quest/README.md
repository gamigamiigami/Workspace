# 古典クエスト 〜漢文と古文の修行場〜

中学生向けの**古典総合学習ゲームプラットフォーム**。
漢文の訓読（返り点）から始まり、返り点を自分で打つ・書き下し文を直す・歴史的仮名遣いを直す、まで古典の知識技能を1つのゲームで学べる。

公開URL：https://gamigamiigami.github.io/Workspace/kaeriten-quest/
（旧名「返り点クエスト」。URL・セーブデータはそのまま）

## モード一覧（7モード）

### 🗼 漢文の塔 〜読む修行〜（返り点の順に読む）

| モード | 内容 | リプレイ動機 |
|---|---|---|
| 🗼 漢文の塔 | 全6階のメインストーリー | 各階★3コンプリート |
| 📅 今日の試練 | 日付シードで毎日変わる5問 | **連続クリア日数🔥**が伸びる |
| 🥋 修行モード | タイムアタック。正解+8秒/ミス−5秒 | 自己ベスト撃破数の更新 |
| ⚡ 連続モード | **1ミス即終了**。制限時間が7%ずつ短縮。**25問ごとに🐲長文の試練** | 連続記録の更新 |

### ⛩ 古典道場 〜書く・直す修行〜

| モード | 内容 | 学習内容 |
|---|---|---|
| ⛩ 逆打ちの間 | **書き下し文を見て白文に返り点を打つ**。パレットでレ・一二・上下を選んで漢字にスタンプ→「⚖️これで読む！」で判定 | 返り点の出力（テストの記述問題対応） |
| 📜 書き下しの間 | 文中に漢字のまま残った**助動詞・助詞をタップしてひらがなに直す**（「漢文を読ま不」→不→ず） | 書き下し文のひらがな化ルール |
| 🖌 仮名遣いの間 | **歴史的仮名遣いを現代仮名遣いに直す**字をタップ（をかし・けふ・てふてふ等16語） | ハ行転呼・ゐゑ・ぢづ・「〜ょう」 |

称号システム：見習い書生 → 書生（★4）→ 訓読士（★9）→ 返り点マスター（★14）→ 訓読の達人（★18）→ **漢文王**（★18＋修行15問＋連続3日）

## 設計のポイント

- **データの一元化**：漢文問題は `FLOORS`／`LONG_PROBLEMS` の1か所だけ。逆打ちの間（返り点を隠して出題）も書き下しの間（ひらがな化対象を自動抽出）も同じデータから自動生成される。問題を1つ足すと3モードに反映
- **訓読文の正式表記**：返り点＝左下（赤）／送り仮名・助詞＝右下（カタカナ）／助動詞・助詞として読む字＝真横（ひらがな・青）
- **機械検証**：読み順・かな変換・書き下し一致をスクリプトで全問検証済み

## 技術仕様

- 1ファイル完結・外部ライブラリ／CDNなし・オフライン動作
- 縦書きは writing-mode 不使用（flex手動縦組み・ブラウザ差異回避）
- 進捗は localStorage 保存（try-catch保護・旧データ自動マイグレーション）
- iPad縦持ち（768px）優先。タップ領域44px以上

## データの追加方法

**漢文問題**（塔・試練・修行・連続・逆打ち・書き下しに自動反映）：
```javascript
// FLOORS の各階 problems に追加。chars: [漢字, 返り点, 送り仮名(カタカナ), ひらがな読み(真横)]
{ chars: [['思','二','フ'],['故','',''],['郷','一','ヲ']], order: [1,2,0],
  yomi: '故郷を思ふ', mean: 'ふるさとを思う' },
```

**仮名遣い問題**：
```javascript
// KANAZUKAI に追加。tokens: [文字, 直した後(不要ならnull)]
{ tokens: [['を','お'],['か',null],['し',null]], answer: 'おかし', rule: '「を」は「お」に直す' },
```
