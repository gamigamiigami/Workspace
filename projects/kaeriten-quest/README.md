# 返り点クエスト 〜漢文の塔〜

中学生向けの**漢文・訓読パズルゲーム**。
塔を登るダンジョンRPG風の演出で、「読む順番にタップする」というルール自体が返り点の学習になっている。
表示は**訓読文**：返り点（漢字の左下・赤）＋**送り仮名・助詞（漢字の右側・カタカナ）**付き。

公開URL：https://gamigamiigami.github.io/Workspace/kaeriten-quest/

## 3つのモード（繰り返しプレイの仕掛け）

| モード | 内容 | リプレイ動機 |
|---|---|---|
| 🗼 漢文の塔 | 全6階のメインストーリー | 各階★3コンプリート |
| 📅 今日の試練 | 日付シードで毎日変わる5問 | **連続クリア日数🔥**が伸びる（途切れるとリセット） |
| 🥋 修行モード | タイムアタック。正解+8秒/ミス−5秒で何問倒せるか | 自己ベスト撃破数の更新 |

さらに実績に応じて**称号**が昇格：
見習い書生 → 書生（★4）→ 訓読士（★9）→ 返り点マスター（★14）→ 訓読の達人（★18）→ **漢文王**（★18＋修行15問＋連続3日）

## 遊び方

1. 巻物（縦書きの訓読文）の漢字を、返り点のルールに従って**読む順番にタップ**
2. 全部正しい順でタップできたら番人にダメージ → 書き下し文と現代語訳が表示される
3. まちがえるとHPが減る（修行モードは時間が減る）。速く解くとボーナス得点
4. 階をクリアすると次の階が解放。ノーミスで★3

## ゲーム性と学びの設計

| 仕掛け | 学習効果 |
|---|---|
| 「読む順にタップ」という操作そのもの | 返り点の理解＝ゲームの攻略法。別々にならない |
| 階ごとの段階設計（返り点なし→レ点→一二点→ミックス→上下点） | 教科書と同じ学習順序で無理なくステップアップ |
| 各階の開始時にルールカードを表示 | 知ってから挑戦する足場かけ |
| ミス時に返り点の種類に応じたヒント（「二点！先に一まで読もう」） | まちがえた瞬間にルールで上書き |
| クリアごとに書き下し文＋現代語訳 | 順序がわかる→読めるをつなげる |
| 最上階は「百聞は一見に如かず」など本物の名句ボス戦 | 定期テスト・入試頻出句に触れる |
| ★3収集・速さボーナス・ベストスコア | 繰り返しプレイの動機づけ |

## 階構成

| 階 | 内容 | 問題数 |
|---|---|---|
| 1F | 返り点なし（上から順に読む） | 4 |
| 2F | レ点（連続レ点含む） | 5 |
| 3F | 一・二点（長い読み飛ばし含む） | 5 |
| 4F | レ点＋一二点ミックス（『登鸛鵲楼』含む） | 4 |
| 5F | 上・下点 | 3 |
| 6F | ボス戦：少年易老学難成／百聞不如一見／虎穴の名句 | 3 |

## 技術仕様

- 1ファイル完結（`index.html`）・外部ライブラリ／CDNなし・オフライン動作
- 縦書きは `writing-mode` を使わず **flexの縦並びで手動縦組み**（ブラウザ差異・iPad表示崩れを回避。knowledge/failures.md の注意点に対応）
- 漢文部分のみ端末内蔵の明朝体（Hiragino Mincho 等）、UIは system-ui
- 進捗（解放階・★・ベストスコア）は localStorage 保存（try-catch保護済み）
- iPad縦持ち（768px）優先。タップ領域44px以上

## 問題の追加方法

`index.html` 内の `FLOORS` 配列の各階 `problems` に追加：

```javascript
// chars: [漢字, 返り点, 送り仮名(カタカナ)] を上から順に。なしは ''
// order: 読む順番（charsのインデックス。0始まり）
{ chars: [['思','二','フ'],['故','',''],['郷','一','ヲ']], order: [1,2,0],
  yomi: '故郷を思ふ', mean: 'ふるさとを思う' },
```

追加した問題は「今日の試練」「修行モード」の出題プールにも自動で入る。
