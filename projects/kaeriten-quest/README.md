# 古典クエスト 〜古典ダンジョン〜

中学生向けの**古典総合学習ゲームプラットフォーム**。
ダンジョン（古典）の中に4つの塔・間があり、すべてに共通の3モード＋RPGステータスで繰り返し学習を促す。

公開URL：https://gamigamiigami.github.io/Workspace/kaeriten-quest/

## 全体構造

```
🏯 古典ダンジョン
├ 📖 読みの塔（返り点の順にタップ）→ ⚔️ 攻撃力
├ ⛩ 返り点の塔（書き下し文を見て返り点を打つ）→ 🖋 筆力
├ 📜 書き下しの間（ひらがな化・置き字の見分け）→ 📖 知力
└ 🖌 仮名遣いの間（現代仮名遣いに直す・3択）→ 🔮 魔力
```

**各塔・間に共通の3モード：**

| モード | 内容 | 能力値への反映 |
|---|---|---|
| 🏯 修行 | 段位制ステージ（★1〜3評価・HP5） | ★合計を換算（**全★クリアで30**） |
| 📅 今日の試練 | 日替わり5問（塔ごとに別問題） | クリアで**🛡忍耐力+1**（塔ごと1日1回） |
| 🗡 真剣勝負 | **1ミス即終了**。何問連続できるか | **最高記録がそのまま能力値に加算** |

例：読みの塔で修行全★（30）＋真剣勝負ベスト10問 → ⚔️攻撃力 40

- 読みの塔の真剣勝負のみ制限時間あり（字数×1字4秒→7%ずつ短縮→下限1.2秒）＋25問ごとに🐲長文の試練
- 称号は総合戦闘力で昇格：見習い書生(0)→書生(40)→訓読士(90)→返り点マスター(150)→訓読の達人(220)→**漢文王(300)**

## 教科内容のポイント

- **訓読文の正式表記**：返り点＝左下（赤）／送り仮名・助詞＝右下カタカナ／助動詞・助詞として読む字＝真横ひらがな（青）
  - 「入ら**ずんば**」は 不＝ず（真横ひらがな）＋ンバ（送り仮名・カタカナ）、「**べから**ず」は 可＝べ＋カラ、と正しく分離
- **置き字**（而など）：書き下しの間で「🖌ひらがな筆／✂️置き字バサミ」の道具を使い分けて処理。読む之（の）と読まない而の判別、代名詞「之＝これ」（漢字のまま）の引っかけも収録
- **仮名遣い**：直す字を見つけるだけでなく「**何に直す？**」の3択に答える（ふ→う/ぶ/お など、まぎらわしい誤答入り）

- 1ファイル完結・外部ライブラリ／CDNなし・オフライン動作・system-ui＋端末内蔵明朝

- iPad縦持ち（768px）優先。タップ領域44px以上

## データの追加方法

**漢文**（読みの塔・返り点の塔・書き下しの間に自動反映）：`FLOORS` の各階 `problems` に追加
```javascript
// chars: [漢字, 返り点, 送り仮名(カタカナ), ひらがな読み(真横)]
{ chars: [['不','レ','','ず'],['知','','ラ']], order: [1,0], yomi: '知らず', mean: '知らない' },
```

**置き字問題**：`OKIJI_ITEMS` に追加（tokens: [文字, 変換, 'oki', 個別ヒント]）

**仮名遣い**：`KANAZUKAI` に追加（stage: 0=ハ行 1=ゐゑをぢづ 2=拗音、省略時は試練・真剣勝負のみ）
```javascript
{ tokens: [['け','きょ'],['ふ','う']], answer: 'きょう', stage: 2, rule: 'エ段＋ふは「〜ょう」' },
```
