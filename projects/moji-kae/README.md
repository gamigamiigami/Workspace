# 文字かえ君

決めた法則で文字を置きかえる道具。謎解き・脱出ゲームの問題づくり用。

公開URL: <https://gamigamiigami.github.io/Workspace/projects/moji-kae/>

姉妹ツール：[文字ずらし君](../moji-zurashi/)（五十音表の上でずらす）／
[ことばかける君](../crossword/)（クロスワード作り）

## 入っているもの

| ファイル | 中身 |
|---|---|
| `index.html` | 文字かえ君（1ファイル完結・オフライン動作・完全無料） |

## 基本の使い方

1. **法則**を決める（例：`a` → `i`）
2. **言葉**を入れる（例：`あか`）
3. 右に結果が出る（`あか` → **`いき`**）

`あか` はローマ字で `aka`。`a` を `i` にすると `iki` ＝ `いき` になります。

## かえる単位は2つ

| 単位 | 書き方 | 例 |
|---|---|---|
| **ローマ字**（初期設定） | `a` → `i`、`k` → `s` | `あか` → `いき`、`あか` → `あさ` |
| **かな** | `あ` → `い`、`かき` → `こく` | `あか` → `いか` |

**複数文字もそのまま書けます。** `かき` → `こく` のように、2文字以上のまとまりで置きかえられます。

### 法則はいくつでも並べられます

`a`→`i` と `k`→`s` を同時にかけると `あか` → **`いし`** になります。

法則は**同時に**かけます（順番にかけません）。`a`→`i`、`i`→`u` があるとき、
順番にかけると `a` が `u` まで進んでしまい、暗号として成り立たなくなるためです。

### 拗音・小さい「っ」

かな単位のときは、`ゃ` `ゅ` `ょ` `っ` も**ほかの文字と同じ**に置きかえられます
（`ゃ`→`ゅ` で `きゃく` → `きゅく`）。「さがす」の総当たりにも入ります。

### ローマ字は訓令式です

`し` = `si`、`つ` = `tu`、`しゃ` = `sya` と書きます。

ヘボン式（`shi`・`tsu`）だと、`s`→`k` のような置きかえで `shi` → `khi` と形がくずれてしまいます。
訓令式なら法則がきれいに効くので、こちらを採用しています。

「ローマ字も見る」にチェックを入れると、`aka → isi` のように途中経過が出ます。

**「ん」の書き方**：`ぜんいん` は `zen'in` と区切りを入れます。
これがないと `zenin` → `ぜにん` と読みちがえてしまうためです（辞書25,715語すべてで往復一致を確認済み）。

## 逆引き（かえたあと → かえる前）

「入れる言葉は」を「**かえたあと**」にすると、答えから逆算して元の言葉が出ます。
入力欄は右がわに移り、矢印も `←` になります。

`a`→`i` と `e`→`i` のように**行き先が重なる法則**があると元に戻せないので、その場合は警告を出します。

## さがす（謎解きのネタ出し）

### 入れた言葉ぜんぶに使える法則をさがす

入れた言葉が**すべて同時に**別のちゃんとした言葉になる法則だけを見つけます。

例：`あか`・`かさ`・`あさ` → **2個**
- `a`→`i`：あか→いき（行き）／かさ→きし（騎士）／あさ→いし（石）
- `a`→`u`：あか→うく（浮く）／かさ→くす（楠）／あさ→うす（臼）

各行の「さがす」を押すと、その1語だけで調べます。

### 今の法則で使える言葉をさがす

辞書ぜんぶ（約2万6千語）から、その法則をかけると別のちゃんとした言葉になる言葉を拾い出します。
文字数（2〜4字）で絞れます。

例：`a`→`i` の3文字 → **617組**
- `かのう`（可能）→ `きのう`（機能）
- `たしか`（確か）→ `ちしき`（知識）
- `さんか`（参加）→ `しんき`（新規）

候補を押すと、その言葉が入力欄に入ります。

## 辞書にない言葉は色が変わります

`あめ` → `いめ` のように、変換はできたけれど**辞書にない言葉**になったときは
オレンジ色＋`？` で知らせます。問題として成立しない組み合わせにすぐ気づけます。

**辞書の中身**：固有名詞・活用形・カタカナ語・文法語を除いた一般語 約2万6千語（頻度順）。
出典は IPADIC（修正BSDライセンス）と wordfreq（MIT）。どちらも無料・再配布可です。

## 法則をまとめて入れる

「法則をまとめて入れる／お気に入り」を開くと、`a>i, k>s` のように**1行で書いて一度に入れられます**。
`a→i`・`a->i`・`a:i` の書き方でも通ります。区切りは「、」「,」「改行」のどれでも大丈夫です。

## ★お気に入りの法則

よく使う法則に名前をつけて登録できます。**どの作品でも共通**で、この端末に残ります。
押すとその法則（かえる単位ごと）に切りかわります。

## 1文字ずつの対応

「1文字ずつの対応を見る」にチェックを入れると、`あ→い　か→し` のように
**どの文字がどう変わったか**が言葉の下に出ます。生徒への説明に使えます。

## むずかしさ

「さがす」の結果を **どれでも／小学生向けだけ** の2段階でしぼれます。
小学生向け＝辞書のよく使う順で上位3000語まで。候補には <b>小</b> の印が付きます。

「上から10組をまとめて欄に入れる」を押すと、さがした言葉を一度に出題欄へ入れられます。

## 印刷する

| 選ぶもの | 出るもの |
|---|---|
| **問題用紙（答えなし）** | かえたあとの言葉＋答えを書く線。名前を書く欄つき |
| **答えの紙（答え入り）** | 法則と答えが入った、答え合わせ用 |

「問題用紙に法則も書く」のチェックを外すと**法則が伏せられる**ので、
「どんな決まりで文字が変わったか当てる」問題になります。

## 自動保存

作りかけの内容は**この端末に自動で残ります**。タブを閉じても、次に開いたとき続きからできます。

## 作品として保存

名前をつけて保存すると、**この端末のブラウザに残ります**（リンク配布はしません）。
「どんな言葉を・どんな法則で・どんな言葉にしたか」が一式で残り、一覧に要約が出ます。

- 保存ずみの作品をもう一度保存すると、**「上書き保存する／別の作品として保存する／やめる」**を聞きます
- 保存していない内容があるまま「新しく作る」「ほかの作品を開く」をすると、**消す前に確認**します
- **ファイルに保存／ファイルから読みこむ**で、別の端末へ移したりバックアップしたりできます
  （★お気に入りも一緒に入ります。読みこむときは、いまの★に**足します**）

## 決まっている方針

- 外部CDN・外部APIを使わない（学校のアクセス制御下でもオフラインで動く）
- iPad縦持ち（768px）での表示を優先
- タップ領域は44px以上、文字は16px以上
- **画面のズームは固定**（ダブルタップ拡大・ピンチ拡大を無効）
- 1ファイル完結（`index.html` を保存すればどこでも動く）
