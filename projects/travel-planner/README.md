# Travel Planner（旅行プランメーカー）

行きたい観光地を地図にピン留めし、経路を検索し、移動・場所ごとの費用を記録して旅行プランを組み立てる個人用ツール。

## 何ができる
- 🗺️ 本物の動く地図（OpenStreetMap）に場所をピン留め
- 🎨 ピンを **種類（観光地/宿/食事/移動拠点/その他）で色分け**、**状態（候補/確定）で見た目変化**
- 🔍 場所名で検索して追加 / 地図クリックで追加
- 🚌 移動手段（🚗車／🚃電車・バス／🚶徒歩）を選択。アプリ内は距離のめやす（OSRM＝車）、**正確な所要時間は「本物の地図(Googleマップ)」をその手段で開いて確認**（無料・電車の時刻表/渋滞込み）
- 💰 **「何に対する費用か」を記録**（移動 A→B のバス代/電車代、場所の宿泊・食事代など）
- 🔁 お金は **明細 ⇄ 合計** の表示切り替え。**一人あたり金額**も自動計算
- 📅 **日程わけ（Day1/Day2…）**、各場所に **ひとことメモ** と **公式サイトURL＋🔍調べるボタン**
- 💾 ブラウザに **自動保存**（localStorage）
- 🤝 プランを **書き出し / 取り込み / 共有リンク** で相手に渡せる（サーバー不要）

## 使い方
`index.html` をブラウザで開くだけ（PC優先・スマホ対応）。

## 技術メモ（重要）
- **このプロジェクトは coding-rules の「外部ライブラリ禁止・オフライン前提」規約の意図的な例外**。
  地図と経路検索のため、無料の外部サービスを利用する：
  - 地図ライブラリ：Leaflet（CDN）
  - 地図タイル：OpenStreetMap
  - 場所検索：Nominatim（OpenStreetMap）
  - 経路検索：OSRM（公開サーバー）
- すべて **無料・APIキー不要**。ただし **ネット接続が必要**。
- 個人用ツール（PC/スマホ）であり、生徒のiPad制限環境向けではないため、この例外は許容。
