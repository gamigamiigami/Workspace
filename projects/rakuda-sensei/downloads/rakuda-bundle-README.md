# らくだ先生 デジタル教材バンドル 完全版

ダウンロードありがとうございます🐪 残業嫌いのらくだ先生です。

このフォルダには、4つの完全版テンプレートが入っています。
Excel ファイルは Google スプレッドシートでも開けます（Google ドライブ
にアップロードしてから「Google スプレッドシートで開く」を選択）。

## 同梱ファイル

### 1. 中学校教員のためのToDo＆時間割テンプレ.xlsx
平日の校務時短に直結する ToDo 管理＋時間割テンプレ。日次タスクを朝
の 5 分で組み上げて、放課後の残業をゼロにするための骨組み。

### 2. 伊神流FP｜家計と先取り貯金テンプレ.xlsx
公務員が 5 年で 2,000 万貯めた「先取り投資 → 生活 → 貯金」の流れを
そのまま再現できる Excel。固定費・変動費・先取り投資額を入れるだけ
で不等式が成立しているかが見えます。

### 3. 夫婦で実践 サイドFIRE計画シート.xlsx
11 項目入力で「あと何年で辞められるか」「不足額をどう埋めるか」が出
る診断シート。夫婦の家計会議用に設計。

### 4. 通知表所見｜AIプロンプト完全版.md
ChatGPT / Claude に貼り付けるだけで、所見の下書きが 30 分→3 分にな
る完全プロンプト集。学年・学期・教科を問わず使えます。

## 使い方の順番（おすすめ）

1. **まず 1（ToDo&時間割）** で平日に「先取り投資の自動積立を設定する
   時間」を確保する
2. **次に 2（家計と先取り貯金）** で月の不等式を成立させる
3. **3（サイドFIRE計画）** で 20 年後のゴール数字を出す
4. **4（所見プロンプト）** は通知表の時期に開いて使う
