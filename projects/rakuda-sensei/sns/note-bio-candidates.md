## 🥇 メイン候補（推奨・160字以内・SP1スクロール内表示）

```
公立中学校教員（国語・20代）🐪
「定時で帰る」を本気で目指して、ICT・AI活用で残業ゼロにしました。
副業で月10万、5年で2000万円貯金（節約×低リスク投資）。
日本株デイトレで-50万やった失敗も全公開。
教員でも、時間とお金の自由は両立できる。
無料記事多めで、すぐ使える成果物だけ有料配布。
```

### 採用理由
- 数字3つ（残業ゼロ・月10万・2000万）で実績アピール
- 失敗談（-50万）で人間味
- 「無料記事多め」を明示 → 拡散・フォロー期待値を下げない
- 「すぐ使える成果物」で有料の差別化を予告
