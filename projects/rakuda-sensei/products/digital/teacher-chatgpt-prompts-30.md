# 中学校教員のためのChatGPTプロンプト集 30本

🐪 残業嫌いのらくだ先生
2026年6月版

---

## このプロンプト集の使い方

1. プロンプト本文をそのままChatGPT / Claudeにコピペ
2. 【】の部分だけ自分の状況に書き換える
3. 結果を「もう少し簡潔に」「中2向けに」等で微調整

**重要**: AIの回答は必ず先生の目視チェック。生徒個人を特定できる情報を入力しない。

## 🟢 所見・通知表系 (5本)

### 1. 所見の下書き作成

```
中学2年生の学級担任です。
以下の生徒情報をもとに、1学期通知表の所見を200字程度で書いてください。

生徒の特徴（観察事実のみ）:
- 【授業中の様子】
- 【人間関係】
- 【提出物・宿題】
- 【強み・伸ばしたい点】

文体: 保護者向けの丁寧語、ポジティブな表現を中心に、課題は前向きな表現で。
NG: 生徒の個性を否定しない、断定的な評価表現を避ける。
```

### 2. 所見の表現バリエーション展開

```
以下の所見原文を、3つの表現バリエーションに展開してください。
意味は変えず、語彙・文末のリズムを変える。

【原文をここに貼り付け】

出力: バリエーションA / B / C
```

### 3. 所見をネガティブからポジティブへ言い換え

```
以下の指導記録から、保護者向け所見として使える「前向きな言い換え」を作ってください。

記録: 【ネガティブな観察】

出力例の方針:
- 「集中できない」→「興味のある分野で集中力を発揮します」
- 「友達と揉める」→「自分の意見を明確に持っています」
```

### 4. 行動の所見（学級活動）

```
中学校学級活動の場面で、以下の生徒の動きを通知表所見に書きたい。150字で。

【生徒の行動メモ（一般化）】
【場面（給食指導・清掃・行事準備など）】

文体: 主体性・協働性・人間性のいずれかに位置づけて記述。
```

### 5. 学習面の所見（国語）

```
中学校国語の学習について、以下の生徒の学習状況から通知表所見を作成してください。180字。

【単元名】
【観察事実（音読・話し合い・記述・読み取り等）】

書きぶり: 「指導と評価の一体化」を意識、次学期の指導の手がかりが見える文に。
```

## 🟡 授業案・教材系 (5本)

### 6. 1時間の授業案ドラフト

```
中学校国語の1時間（50分）授業案を作成してください。

単元: 【単元名】
本時の目標: 【目標】
生徒の実態: 【クラスの学習傾向】

出力構成:
- 導入（5分）
- 展開1（15分）
- 展開2（20分）
- まとめ（10分）
各段階で「教師の発問・指示」「生徒の活動」「評価のポイント」を表で。
```

### 7. 文法導入の説明セリフ

```
中学2年生に【文法事項：助動詞「らしい」「ようだ」「そうだ」の識別】を教える導入5分のセリフを作ってください。

条件:
- 生徒の身近な例から入る（学校生活・SNS等）
- 専門用語を最初に出さない
- 質問形式で生徒に問いかける箇所を含む
- 黒板に書くキーワードを【】で示す
```

### 8. ワークシートの問題作成

```
中学【学年】の【単元】について、以下の3レベルのワークシート問題を作ってください。

- 基礎5問（選択式）
- 応用5問（記述）
- 発展5問（誤答指摘・説明）

各問題に解答と解説を添える。
```

### 9. 板書計画

```
中学国語【単元名】の1時間の板書計画を作ってください。

条件:
- 黒板を3分割（左：めあて / 中央：本時の核 / 右：まとめ）
- 中央には図解か対比表を入れる
- 色チョークの使い分け指示も
```

### 10. 国語の発問パターン展開

```
以下の文学教材【作品名】の核心場面について、思考を深める発問を5段階で作ってください。

場面: 【場面の概要】

段階:
1. 事実確認の発問
2. 行動の理由を問う発問
3. 心情の変化を問う発問
4. 作品テーマに迫る発問
5. 自分との関連を問う発問
```

## 🔵 採点・フィードバック系 (5本)

### 11. 記述式問題の採点ルーブリック作成

```
中学【学年】国語の記述式問題（200字以内）の採点ルーブリックを作ってください。

設問: 【設問の内容】
模範解答例: 【模範解答】

出力:
| 観点 | A評価（10点） | B評価（7点） | C評価（4点） | NG（0点） |

3つの観点に分けて。
```

### 12. 解答コメントの自動展開

```
記述式の生徒解答に対する「励まし＋改善示唆」コメントを作ってください。50字以内×3パターン。

生徒解答: 【解答】
模範解答との差分: 【何が足りないか】

文体: 中学生に響く、前向き、具体的に改善ポイントを示す。
```

### 13. テスト返却時のクラス全体コメント

```
中学2年生に国語テスト（中間/期末）を返却する際のクラス全体への話を3分で作ってください。

平均点: 【点数】
よくできた問題: 【番号】
できなかった問題: 【番号】

伝えたいこと:
- 結果に一喜一憂しない姿勢
- 次のテストへの具体アドバイス
- 質問は個別にOKと伝える
```

### 14. 提出物の良い面コメント

```
提出物（ノート/レポート/作文）の「良い点を3つ」と「次に挑戦したい点を1つ」をコメント30字以内で作ってください。

提出物の特徴: 【観察メモ】

文体: ポジティブ・具体的・短文・付箋に書ける長さ。
```

### 15. ペーパーテストの作問

```
中学【学年】【単元】の50分テストを作ってください。

構成:
- 漢字問題 10点（読み5・書き5）
- 知識問題 30点（選択式・穴埋め）
- 読解問題 40点（短文記述含む）
- 発展問題 20点（自由記述）

合計100点満点。難易度は中位生徒の正答率70%目安。
解答用紙のレイアウトも提示。
```


## 📝 プロンプトをさらに育てるコツ

1. **「中学2年生向けに」「保護者向けに」を必ず指定** → AIの語彙が適切になる
2. **「【】の項目は箇条書きで入力」のように構造化** → 結果が安定する
3. **「ただし生徒個人を特定できる情報は使わない」と明記** → 個人情報リスク低減
4. **生成後は「もっと具体的に」「もっと短く」で詰める** → 1発で完璧を狙わない
5. **保存はGoogleドライブ / Notion 等にライブラリ化** → 自分のプロンプト資産になる
