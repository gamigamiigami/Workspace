# 先生のTodoメモ

学校業務・副業・プライベートを一元管理できる付箋風Todoアプリ。

## 起動方法

`launch.bat` をダブルクリックするだけ。  
Microsoft Edge がアプリモードで開きます（アドレスバーなし・単独ウィンドウ）。

## 機能一覧

| 機能 | 説明 |
|------|------|
| タスク追加 | タイトル・カテゴリ・優先度・締切日・メモ・リンク |
| カテゴリ | 授業準備 / 校務 / 副業 / プライベート / その他（カスタム追加可）|
| 優先度 | 高（赤）・中（黄）・低（緑） |
| 締切管理 | 期限切れは赤枠・今日締切はオレンジ表示 |
| フィルタ | カテゴリ別・検索・完了済み表示切替 |
| 並び替え | 締切日順 / 優先度順 / 作成日順 |
| データ保存 | localStorage（PCを閉じても消えない）|

## ショートカット

| キー | 操作 |
|------|------|
| `Ctrl + N` | 新規タスク追加 |
| `Escape` | モーダルを閉じる |

## 自動起動の設定方法（任意）

1. `launch.bat` を右クリック →「ショートカットの作成」
2. 作成されたショートカットを `Win + R` → `shell:startup` で開いたフォルダに移動

これで PC 起動時に自動で Todo が開くようになります。
