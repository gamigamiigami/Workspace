# 2-4's TOY WORLD（ブラウザ版・Python不要）

もとのPython版（Wiiリモコン射的）を、**Python・追加インストール一切なし**で遊べる
ブラウザ版に作り直したものです。手とWebカメラだけで遊べます。

- **照準（ねらう）** … 人差し指の先をカメラに見せて動かす
- **発射（うつ）** … 親指と人差し指を「**つまむ**」
- 的の動き・スコア・40秒・結果画面は元の仕様を踏襲。ランキングはこのPCのブラウザ内に自動保存。
- インターネット接続は不要（手の認識AI「MediaPipe」もフォルダに同梱済み）。

---

## 遊び方（Windows・いちばん簡単）

1. このフォルダごとPCにコピーする（カメラ付きPC）
2. **`start-windows.bat` をダブルクリック**する
3. 黒い画面が出て、自動でブラウザが開きます
4. 「画面をクリックしてスタート」を押す → **カメラの使用を「許可」**
5. 手をカメラに見せて、人差し指でねらい、**つまむと発射！**

> `start-windows.bat` は Windows標準のPowerShellで小さなサーバーを立ち上げているだけです。
> （ブラウザのセキュリティ上、ファイルを直接ダブルクリックするとカメラAIが読み込めないため、
>  この方式にしています。）終了するときは黒い画面（コマンド画面）を閉じてください。

### Mac や その他の場合
ターミナルでこのフォルダに移動し、いずれかの簡易サーバーを立ててから
`http://localhost:8000/index.html` を開いてください。例：
```
python3 -m http.server 8000      # Python が入っている場合
npx serve .                       # Node が入っている場合
```
（Windowsの `start-windows.bat` なら、これらは不要です）

## 操作まとめ

| やりたいこと | 操作 |
|---|---|
| ねらう | 人差し指の先を動かす（青い照準が付いてくる） |
| 撃つ | 親指と人差し指を「つまむ」 |
| スタート / もう一度 | 同じく「つまむ」 |
| （予備）撃つ・選ぶ | マウスでクリックでもOK |

画面左下に「カメラOK」と出れば認識成功です。

## うまくいかないとき（`index.html` 上部の CONFIG を調整）

| 設定 | 意味 | 目安 |
|---|---|---|
| `MIRROR` | 鏡うつし | 手と画面の動きが逆なら `false` に |
| `SMOOTHING` | 照準のなめらかさ | 手ブレが気になるなら大きく（1未満） |
| `PINCH_ON` | つまみ判定の近さ | 撃ちにくいなら少し大きく |
| `SHOOT_COOLDOWN` | 連射の最短間隔(ms) | 撃ちすぎるなら大きく |

- **カメラが映らない** … PC設定でブラウザにカメラ許可があるか確認。USBカメラは挿し直す。
- **音が出ない** … 最初の「クリックしてスタート」を必ずクリック（音はクリックで解禁されます）。

## このバージョンについて（自動テスト済み）

ヘッドレスブラウザで以下を自動確認済みです（`起動・プレイができるか`の検証）：

- ✅ ページが読み込める（致命的なJSエラーなし）
- ✅ 手の認識AI(MediaPipe)が**同梱ファイルだけでオフライン動作**する
- ✅ つまみ＝発射でゲーム開始 → 的が9個出現
- ✅ 的を撃つとスコアが加算される
- ✅ 40秒で結果画面 → ランキングがブラウザに保存される

※「実際の手でつまんで撃つ」感触だけは、カメラ付き実機でのみ確認可能です（次のアクション）。

## ファイル構成

| ファイル/フォルダ | 役割 |
|---|---|
| `index.html` | ゲーム本体（これ1つで動く） |
| `start-windows.bat` | Windows用かんたん起動ツール（ダブルクリック） |
| `server.ps1` | 上記batが使う小さなサーバー（PowerShell・標準機能のみ） |
| `mediapipe/` | 手の認識AI一式（オフライン動作用・同梱） |
| `assets/` | 背景・的の画像・効果音・BGM（元の素材） |

## Python版との違い

| | ブラウザ版（このフォルダ） | Python版（`../toy-story-modoki`） |
|---|---|---|
| インストール | 不要 | Python + ライブラリが必要 |
| プレイ人数 | 1画面1人（カメラ1台） | 1P＋2P、複数PCをUDP接続 |
| ランキング | ブラウザに自動保存 | `TSM_score.py` で集計・表示 |
| 向いている場面 | 1台でサッと遊ぶ・配布が簡単 | イベントで複数台を連動 |

複数台連動や2人同時プレイをブラウザ版でも、という要望があれば拡張できます。
