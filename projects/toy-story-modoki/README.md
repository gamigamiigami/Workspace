# ToyStoryModoki（手＋カメラ版）

Wiiリモコン＋センサーバーで遊んでいた射的ゲームを、**Webカメラ＋手のジェスチャー**で
遊べるように改造したバージョンです。

- **照準（ねらい）** … 人差し指の先をカメラに向けて動かす
- **発射（うつ）** … 親指と人差し指を「**つまむ**」
- 的の動き・スコア計算・ランキング・通信など、**シューティングの仕方以外は元のまま**です。

Wiiリモコン・WiinRemote.exe・センサーバーはもう不要です。

---

## 完了基準チェックリスト

- [x] Wiiリモコン入力（1P）を手＋カメラに置き換え（`TSM_core.py`）
- [x] Wiiリモコン入力（2P送信機）を手＋カメラに置き換え（`TSM_input.py`）
- [x] 発射ジェスチャーは「つまむ」（誤爆が少なく子どもにも分かりやすい）
- [x] その他（的・スコア・UDP通信・ランキング `TSM_score.py`）は変更なし
- [ ] 実機（カメラ付きPC）での動作確認待ち ← **次のアクション**

## 1. 準備（最初の1回だけ）

カメラ付きのWindows PCを用意し、Python が入っている状態で、このフォルダを開いて
ターミナル（コマンドプロンプト）から次を実行します。**すべて無料**です。

```
pip install -r requirements.txt
```

> 補足: `opencv-python`（カメラ映像）と `mediapipe`（手を見つける無料AI）を使います。
> インターネット接続が必要なのは、この「インストールのとき」だけ。遊ぶときはオフラインでOK。

## 2. カメラと手の認識テスト（おすすめ）

ゲームを起動する前に、カメラと手がちゃんと認識されるか確認できます。

```
python hand_tracker.py
```

- カメラ映像の小窓が開き、人差し指の先に丸が付きます。
- 「つまむ」と丸が赤くなり、ターミナルに `BANG! 発射` と出れば成功です。
- カメラが映らない場合 → `hand_tracker.py` を開いて、上の方にある
  `CAMERA_INDEX = 0` の数字を `1`, `2` などに変えて試してください
  （USBカメラを使うときは内蔵カメラと番号が分かれます）。

## 3. ゲームを動かす

元の構成と同じです（**WiinRemote.exe の作業はもう不要**）。

1. `TSM_score.py`（1台）, `TSM_core.py`（最大3台）, `TSM_input.py`（最大3台）を起動
2. IPアドレスの設定は元の readme と同じ（`TSM_input.py` と `TSM_core.py` の
   `UDP_IP` / `SEND_IPS` を送信先に合わせて書き換え）
3. それぞれのPCにカメラを1台つなぐ（1台のPCにつき手は1人ぶん）

### 遊び方（プレイヤー向け）

- **手をカメラに見せて、人差し指の先で的をねらう**
- **親指と人差し指をつまむと発射**
- スタート画面・結果画面も「つまむ」で次へ進みます
- キーボードの `Enter` でもスタート/次へは進めます（予備）
- `Esc` で終了

## 調整したいとき（`hand_tracker.py` の上の方）

| 設定名 | 意味 | 困ったときの目安 |
|---|---|---|
| `CAMERA_INDEX` | 使うカメラの番号 | 映らないなら 0→1→2 と変える |
| `MIRROR` | 鏡うつしにするか | 手と画面の動きが逆なら切り替え |
| `SMOOTHING` | 照準のなめらかさ | 手ブレが気になるなら数値を上げる（最大1未満） |
| `PINCH_ON` | つまみ判定の近さ | 撃ちにくいなら少し大きく |
| `SHOOT_COOLDOWN` | 連射の最短間隔（秒） | 撃ちすぎるなら大きく |
