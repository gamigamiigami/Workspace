# 席替えツール（seat-assignment）

学校の先生が最小限の操作で席替えを考えて決定できるツール。

## 使い方

`index.html` をブラウザ（iPad Safari / PC Chrome・Edge）で開くだけ。
サーバー・ネットワーク不要。データはブラウザの localStorage に自動保存される。

### 個人情報について

このツールは外部通信を一切しない（fetch・CDN・Webフォント・解析タグなし）。
入力した名前は端末のブラウザ内（localStorage）だけに保存され、ネットには出ない。
より安全に使うなら、①ファイルを端末に保存してオフラインで開く、
②本名ではなく出席番号やイニシャルを入れる、の2つを併用するとよい。

## 機能

| 機能 | 説明 |
|---|---|
| 机の配置 | 縦×横の列数を自由に設定 |
| 隊形プリセット | 「ぜんぶ前向き」「コの字」をワンタップで適用 |
| コの字 | 左右の机は教室の中を向き、いちばん後ろの机は黒板を向き、まん中と黒板側があく形。人数が入りきらないときは自動で二重コの字（左右・後ろを2列）にする |
| 席の固定 | 特定の生徒を特定の席に固定（🔒） |
| 机の向き変更 | 机をタップするたびに向きが回る。四角の形（縦長/横長＋太い辺＝正面）で向きが見える |
| 空席設定 | 机はあるが誰も座らせない席をタップで設定 |
| 男女登録 | 生徒に男/女を登録 → 机の背景が青/ピンクになり、左上に「男」「女」の印が出る |
| 男女市松模様 | チェックを入れると、となり合う席が男・女・男・女…とジグザグ（市松模様）に交互になるよう席替えする |
| グループ設定 | 班は「席」に色をぬって決める（誰がその班になるかは席替えの結果で決まる）。班は太いわく＋右下の班名ラベルで表示され、男女の色と同時に見える |
| 色の見かた | 座席表の上に凡例を表示（どの色が男女で、どの色がどの班かがわかる） |
| ベストな席を自動でえらぶ | 1回の実行で最大40通りの席を作り、**前回とのダブりがいちばん少ないもの**を自動採用する |
| 前回とのくらべ | 席替えページの上に常に表示。「席が同じ／となりが同じ／前後が同じ／斜めが同じ／同じ班」を件数で出す（別ページを見に行かなくてよい） |
| 席の手なおし | 🔀2人を入れかえる／📌今回だけ固定する。📌は**この1回かぎり**で、記録すると自動で消える |
| NG設定 | 着席NG（席×生徒）・隣席NG（生徒×生徒）。**1年間ずっと**有効。「ぜんぶNGにする」→座ってよい席だけ解除、という入力もできる |
| NGやぶりの警告 | 先生が手で席を入れかえてNG設定にひっかかると、その場でポップアップ＋画面上部に赤い警告＋その席を赤く表示して知らせる |
| 学年・クラス・表示名 | 年度／学年／クラスを登録でき、**表示名**をつけると左上のタブにはその名前が出る |
| 出席番号 | 上から自動で連番。「1・2・3…（通し番号）」と「男1・女1…（男女別）」を切りかえ可能。個別に番号を手で指定することもできる。座席表・名簿に表示される |
| 男女を逆に | 今の男子と女子の位置を入れかえる（固定席・📌はそのまま） |
| 黒板の向き | 座席表を「黒板が上」「黒板が下」で切りかえ。名簿では両方を印刷でき、両面印刷に使える |
| 名簿 | 班別名簿（席の位置は表示しない）と、全員名簿（「Aさん ○班」のように名前と班を一覧） |
| 印刷／PDF | 名簿タブの内容をA4で印刷。**男女の●印・机の向きの矢印・🔒固定マーク・📌は印刷されず**、空席・通路は席ごと消える。座席表は「黒板が上」「黒板が下」の2枚が別ページに出るので両面印刷できる |
| 年度・クラス管理 | 「年度（R8など）」＋「クラス名（1-1など）」でデータを管理。同じ組み合わせを選べば翌年度以降も同じデータ（隣席履歴・同班履歴を含む）を呼び出せる |
| バックアップ | JSONエクスポート/インポートで端末間移行 |

詳細は [DESIGN.md](./DESIGN.md) を参照。

## 班の色について

班の色は10色。ひと目で区別できるよう、
- **となり合う番号（A班とB班など）の色を必ず大きく離す**（RGB距離163以上）
- **どの2色をとっても区別できる**（RGB距離97以上）
ように並べてある。班名ラベルの文字色は背景の明るさに応じて自動で白／黒に切り替わる。

赤 → 緑 → 青 → オレンジ → むらさき → 青緑 → ピンク → 茶 → こんいろ → はいいろ

## 「最高の席」をどう作っているか

このツールが避けたい「良くない席」は次の3つ。優先度の高い順に対処している。

1. **NGのペアが隣になる** → ハード制約。200回試して1度も起きないことをテストで確認済み
2. **前回と同じ席・前回と近くの人がまた近く** → 40通りの候補を作って減点の合計がいちばん小さいものを採用
3. **前々回以前のダブり** → 軽い減点として考慮

### 避けたい順（先生の指定）と減点の重み

| 印 | 項目 | 減点 | 意味 |
|---|---|---|---|
| ×× | 前回と**となり**が同じ | 2000 | 絶対に避けたい |
| × | 前回と**席の位置**が同じ | 600 | できるだけ避けたい（※） |
| ▲ | 前回と**前後**が同じ | 120 | 可能なら避けたい |
| ▲ | 前回と**斜め**が同じ | 100 | 可能なら避けたい |
| □ | 前回近くだった人と**同じ班** | 0 | 避ける必要はないが知りたい（お知らせのみ） |
| | もっと前の回で近くだった | 8 | 軽めに避ける |

※ NG設定のせいで**座れる席が1か所しかない生徒**は、前回と同じ席でも仕方がないので
「席が同じ」に数えない（画面には「○人は除外」と出る）。

30名・30席（自由度が最も低い条件）で200回実行した実測：

| 項目 | 1回あたり | 最悪 |
|---|---|---|
| ×× となりが同じ | **0.00組** | **0組** |
| × 席が同じ | 0.05人 | 1人 |
| ▲ 前後が同じ | 0.84組 | – |
| ▲ 斜めが同じ | 2.49組 | – |

旧方式（候補を1つだけ作る）との20回比較：同じ席 27人 → 0〜1人、となりが同じ 21組 → 0組。

## 3種類の「固定」の使い分け

| 種類 | 場所 | 有効期間 |
|---|---|---|
| 🚫 NG席・NGペア | 🚫NG設定タブ | **1年間ずっと** |
| 🔒 固定席 | ②生徒タブの「編集」 | **1年間ずっと** |
| 📌 今回だけ固定 | ③席替えタブ | **この1回だけ**（記録すると消える） |
