# 席替えツール（seat-assignment）

学校の先生が最小限の操作で席替えを考えて決定できるツール。

## 使い方

`index.html` をブラウザ（iPad Safari / PC Chrome・Edge）で開くだけ。
サーバー・ネットワーク不要。データはブラウザの localStorage に自動保存される。

### 個人情報について

このツールは外部通信を一切しない（fetch・CDN・Webフォント・解析タグなし）。
入力した名前は端末のブラウザ内（localStorage）だけに保存され、ネットには出ない。
より安全に使うなら、①ファイルを端末に保存してオフラインで開く、
②本名ではなく出席番号やイニシャルを入れる、の2つを併用するとよい。

| コの字 | 左右の机は教室の中を向き、いちばん後ろの机は黒板を向き、まん中と黒板側があく形。人数が入りきらないときは自動で二重コの字（左右・後ろを2列）にする |

| ならべて見くらべ | 過去の回と今回の座席表を左右にならべ、どちらかで生徒をタップすると**両方**でその子が光る。**くらべる回はえらべる**（初期値は前回）。ならべたまま右（今回）を入れかえ・📌固定でき、黒板の向きも両方そろって切りかわる |

## 班の色について

班の色は10色。ひと目で区別できるよう、
- **となり合う番号（A班とB班など）の色を必ず大きく離す**（RGB距離163以上）
- **どの2色をとっても区別できる**（RGB距離97以上）
ように並べてある。班名ラベルの文字色は背景の明るさに応じて自動で白／黒に切り替わる。

赤 → 緑 → 青 → オレンジ → むらさき → 青緑 → ピンク → 茶 → こんいろ → はいいろ

## 「最高の席」をどう作っているか

このツールが避けたい「良くない席」は次の3つ。優先度の高い順に対処している。

1. **NGのペアが隣になる** → ハード制約。200回試して1度も起きないことをテストで確認済み
2. **前回と同じ席・前回と近くの人がまた近く** → 40通りの候補を作って減点の合計がいちばん小さいものを採用
3. **前々回以前のダブり** → 軽い減点として考慮

### 避けたい順（先生の指定）と扱い

| 印 | 項目 | 扱い | 減点 |
|---|---|---|---|
| ×× | 前回と**となり**が同じ | **ルール（ハード制約）** — NG設定と同じあつかいで、そもそも作らない | – |
| × | 前回と**席の位置**が同じ | 減点して避ける（※） | 600 |
| ▲ | 前回と**前後**が同じ | 減点して避ける | 120 |
| ▲ | 前回と**斜め**が同じ | 減点して避ける | 100 |
| ▲ | **前回より前の回**でとなり同士だった | 減点して避ける | 110 |
| □ | 前回近くだった人と**同じ班** | お知らせのみ | 0 |
| | もっと前の回で前後だった | 軽めに避ける | 8 |

××は「絶対に避けたい」という指定なので、**減点ではなくルール**として扱う。
候補を作る段階で「前回となり同士だった2人を左右に置かない」を条件にし、
それを満たす候補だけを集める。教室の形がきびしすぎて1つも作れないときだけ
ルールをはずして作り直し、画面に「完全には避けられませんでした」と明示する。

※ NG設定のせいで**座れる席が1か所しかない生徒**は、前回と同じ席でも仕方がないので
「席が同じ」に数えない（画面には「○人は除外」と出る）。

30名・30席（自由度が最も低い条件）での実測：

| 項目 | 1回あたり | 最悪 |
|---|---|---|
| ×× となりが同じ | **0組（300回中0組）** | **0組** |
| × 席が同じ | 0.05人 | 1人 |
| ▲ 前後が同じ | 0.84組 | – |
| ▲ 斜めが同じ | 2.49組 | – |

5回つづけて記録をかさねても、となりが同じは0組のまま。
旧方式（候補を1つだけ作る）との20回比較：同じ席 27人 → 0〜1人、となりが同じ 21組 → 0組。

## 「となり同士」の定義

机は2つずつくっつけて置くことが多いので、横にならぶ数によって組が変わる。

| 教室の形 | となり同士 |
|---|---|
| 横が**偶数**（6列など） | 2つずつの組。`1&2` `3&4` `5&6` が となり。**`2&3` はとなりではない** |
| 横が**奇数**（5列など） | 左右どちらもとなり（`1&2` `2&3` `3&4` `4&5`） |
| 机が**内側向き**（←→、コの字の左右のうでなど） | 横の組にくわえて、**たてのならびもとなり** |
| 机が**前向き**（↑） | 横だけがとなり（たては「前後」になる） |

通路をはさんだ席はとなりにならない。内側向きの机のたてのならびは「となり」に
入れるので、「前後」には数えない（二重に数えない）。

※ NG設定の「隣席NG」だけは、この組の考え方を使わず**上下左右すべて**を隣とみなす。
絶対に近づけたくないペアなので、広めに守るほうが安全なため。

## 名簿順（出席番号順）について

出席番号はふつう あいうえお順 につけるので、**名前順＝あいうえお順＝出席番号順**。
ならびかえは「回数が多い順」と「名簿順」の2つだけにしてある。

ならびかえの基準は `rosterOrderOf()`（名簿にならぶ順番）で、次のように決まる。

| 番号の付け方 | ならぶ順 |
|---|---|
| 通し番号（1・2・3…） | 番号の小さい順 |
| 男女別（男1・女1…） | **男子ぜんぶ → 女子ぜんぶ → 性別未登録** の順 |

男女別のとき、番号の数字だけで比べると **男1と女1がどちらも「1」**になって
男女が交互に混ざってしまう。そのため男女で大きく差をつけた順番の値を持たせている
（男子＝0＋、女子＝100000＋、未登録＝200000＋）。番号が重なっても順番が決まるよう、
名簿での位置も足している。

つながりタブのペアは、**名簿で先に来る人を左**にそろえ、左の人でならべ、
左が同じなら右の人でならべる。班別名簿・全員名簿も同じ名簿順にならぶ。

## 3種類の「固定」の使い分け

| 種類 | 場所 | 有効期間 |
|---|---|---|
| 🚫 NG席・NGペア | 🚫NG設定タブ | **1年間ずっと** |
| 🔒 固定席 | ②生徒タブの「編集」 | **1年間ずっと** |
| 📌 今回だけ固定 | ③席替えタブ | **この1回だけ**（記録すると消える） |
