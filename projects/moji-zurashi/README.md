# 文字ずらし君

謎解き・脱出ゲームの問題づくりのための道具。

公開URL: <https://gamigamiigami.github.io/Workspace/projects/moji-zurashi/>

## 入っているもの

| ファイル | 中身 |
|---|---|
| `index.html` | 文字ずらし君（1ファイル完結・オフライン動作・完全無料） |

## 2つのモード

上のタブで切り替えます。

| モード | やること |
|---|---|
| **① 五十音表** | 表の文字をタップして登録。印のかたまりごと動かして、ずれ方を目で見ながら考える |
| **② 文字列** | 元の言葉と法則を打ち込むと、右となりに変化した言葉が出る。作れる言葉の提案つき |

## ① 五十音表モードの使い方

1. 五十音表の文字を順にタップする（例：`あ` `ん` `ぱ` `ん` `ま` `ん`）
   - タップした文字に**黄色の印**が付き、「もとの文字」の枠に `あんぱんまん` と出ます
   - 同じ文字を何度も使うと `×3` のように回数が出ます
2. 十字ボタン（↑↓←→）で、**印のかたまりごと**動かす
   - 動かした先には**青いわく**が付き、**番号で対応が分かります**
   - 「下に1／右に2」のように、**上下にいくつ・左右にいくつ**ずらしたかを表示します
   - キーボードの矢印キーでも動かせます
3. 「できあがり」に `あんぱんまん → いんぴんみん` のように**右となりに結果**が出ます
   - 1文字ずつの対応も下に並ぶので、どの文字がどう変わったか確認できます

はしの扱い（回り込むかどうか）は下の「ずらす」で切り替えられます。

「ずらした文字を『もとの文字』にする」を押すと、結果を出発点にして続けてずらせます。

## ② 文字列モード（まとめてずらす）

**入力欄が縦にいくつも並んでいて、同じ法則で一度にずらせます。**
このモードでは五十音表は出しません（表がいらない作業のため）。

1. 上から順に言葉を入れる（「＋ 欄をふやす」で何個でも増やせます）
2. 下の「ずらす」で法則を決める
3. 各行の右に、ずらした結果がその場で出ます

「結果をまとめてコピー」で `あい → いう` のような形で全行をまとめて写せます。

### 入力の向きを変える（逆引き）

「入れる言葉は」で切り替えます。

| 設定 | 動き |
|---|---|
| **ずらす前** | 入れた言葉をずらした結果が出ます（ふつう） |
| **ずらしたあと** | 答えから逆算して、**ずらす前の言葉**が出ます |

### 今の法則で使える言葉の組み合わせをさがす（逆探知）

「**今の法則で使える言葉の組み合わせをさがす**」を押すと、
**辞書ぜんぶ（約2万6千語）**の中から、いまの法則でずらすと
**別のちゃんとした言葉になる**組み合わせを全部拾い出します。文字数（2〜4字）で絞れます。

例：「下に1」で
- 2文字 → **588組**（`こと→かた`、`もう→まえ` …）
- 4文字 → **370組**（`けいさん（計算）→こうしん（更新）`、`そんけい（尊敬）→さんこう（参考）` …）

問題のネタさがしに使えます。候補を押すと、その言葉が入力欄に入ります。

### どんな言葉にできる？（提案機能）

各行の「**さがす**」を押すと、その言葉から**実際に辞書にある言葉**になる法則を全部見つけます。
**今えらんでいる「ずらし方」と「はしの扱い」に合わせて**さがします。

例：`あい`
- たて・よこ／回り込む → 10個（`うえ`＝下に2、`きく`＝左に1・下に1、`めも`＝右に4・上に2 …）
- あいうえお順で送る／回り込む → 12個（`うえ`＝2送る、`きく`＝6送る …）

よく使う言葉から順に並び、候補を押すとその法則に切り替わります。

**辞書の中身**：固有名詞・活用形・カタカナ語・文法語を除いた一般語 **約2万6千語**（頻度順）。
うち2〜4文字が20,601語で、短い言葉を厚くしてあります。
出典は IPADIC（修正BSDライセンス）と wordfreq（MIT）。どちらも無料・再配布可です。

## ずらし方は2種類

「ずらす」のところで選びます。**どちらも両方のモードで使えます。**

| ずらし方 | 意味 | 例 |
|---|---|---|
| **たて・よこにずらす** | 五十音表の上を、上下左右に動かす | `あ` を左に1・下に1 → `き` |
| **あいうえお順で送る** | 表を「あ・い・う…」と1本に並べて数え、その数だけ進む | `あ` を10送る → `さ` |

「あいうえお順で送る」は行をまたいで進みます（`お` を1送ると `か`）。
数をマイナスにすると戻ります。

## はしの扱い（ループ）

| 設定 | 動き |
|---|---|
| **はしで回り込む**（初期設定） | `お` から下に1で `あ` に戻る。一周ぶん動かすと元どおり |
| **回り込まない** | `お` から下にはずらせない。はみ出したところは **`×`** と表示してエラーを知らせる |

## どの文字がどこへ動いたかを見る

五十音表では、**同じ番号どうしが対応**しています。

- **もとの文字**：黄色いマス＋**左上に茶色の番号**
- **ずらした先**：青いわく＋**右下に青い番号**

同じ文字を何回か使ったときは `2,4` のようにまとめて出ます。
「できあがり」の下にも、1文字ずつの対応が番号つきで並びます。

## 表は2つ（清音／濁音・半濁音）

画面には**2つの表**を左右に並べています。

```
[ ぱ ば だ ざ が ]  [ わ ら や ま は な た さ か あ ]
   濁音・半濁音の表            清音の表
```

**べつの表なので、ずらしても表をまたぎません。**

- 清音の表は10行なので、`わ` を左に1で `あ`（同じ表の反対がわに回り込む）
- 濁音の表は5行なので、`が` を左に1で `ざ`、`ぱ` を左に1で `が`
- 濁音の文字が清音の表に出ることはありません（その逆も同じ）

**1画面に収まる作り**にしてあるので、スクロールは不要です
（iPad縦・iPad横・ノートPC・スマホで確認済み）。

## 法則を2つ使う（A・B・A&B）

「ずらす」の「**法則を2つ使う（A・B・A&B）**」にチェックを入れると、
法則Bの欄が出て、結果が**3つ並んで**表示されます。

| 表示 | 意味 |
|---|---|
| **A**（緑） | 法則Aだけをかけた結果 |
| **B**（青） | 法則Bだけをかけた結果 |
| **A&B**（桃） | AとBを**両方**かけた結果 |

例：A＝右に1、B＝下に1 → **A&B＝右に1・下に1**（右下に1ずつ）

A&B は、たて・よこ方式どうしなら**1つの法則にまとめて一度で計算**します
（順に2回かけると、途中でたまたま空欄に落ちたときに止まってしまうため）。

## 作品として保存

「作品として保存」に名前をつけて保存すると、**この端末のブラウザに残ります**（リンク配布はしません）。

保存されるのは「**どんな言葉を・どんな法則で・どんな言葉にしたか**」の一式です。
一覧には `かき→あい 【A：右に1／B：下に1】` のように要約が出るので、中身を開かなくても分かります。
押せばその状態がまるごと復元され、続きから作業できます。

## 表にない文字のあつかい

| 文字 | あつかい |
|---|---|
| `ん` | どちらの表にもないので**ずらさずそのまま**（清音の表の「わ行」のすぐ左に置いてあります） |
| 拗音（`ゃゅょ`）・`ー` | **使わない設計**（表から外してあります） |
| `を` `や行の空欄` などに来たとき | 文字がないので `・` と表示（ずらし方を変えると消えます） |

## 決まっている方針

- 外部CDN・外部APIを使わない（学校のアクセス制御下でもオフラインで動く）
- iPad縦持ち（768px）での表示を優先
- タップ領域は44px以上、文字は16px以上（iOSで勝手に拡大されないように）
- 1ファイル完結（`index.html` を保存すればどこでも動く）
