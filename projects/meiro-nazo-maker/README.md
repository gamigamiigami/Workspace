# 迷路謎メーカー

謎解き制作者むけの **迷路謎じどう作成ツール**。
**「どんな謎にするか」を決めると、その条件を全部みたす迷路のほうを自動で作ります。**

公開URL：https://gamigamiigami.github.io/Workspace/projects/meiro-nazo-maker/

---

## 3ステップで作れます

```
① どんな謎にするか カードから選ぶ
② こたえになる文章を入れる（例：あかいもじをよめ）
③ 「✨ 自動で作る」を押す → 印刷する
```

できあがった迷路は、かならず次の条件を満たしています（満たさないものは作り直します）。

- STARTからGOALへの道が **1本だけ**、または **次に短い道と4マス以上ちがう**
- 入れた文章が、そのとおりに読める
- 2段階の謎なら、指示どおりにすると本当に道が変わり、2段めも1本だけの道になる

## 選べる謎（7つ）

| | 名前 | 解く人がやること |
|---|---|---|
| 🔤 | ルートの文字を読む | 最短ルートを通って、通ったマスの文字を順に読む |
| 🔴 | 赤い文字だけ読む | 最短ルートを通って、通った道の赤い文字だけを読む |
| ✂️ | 赤い線を消して2段階 | 赤い文字の指示どおり赤い線を消すと道が変わり、もう一度解く |
| ⭕ | ○を全部通ってから読む | ○のマスを全部通りながらGOALへ。通ったマスの文字を読む |
| ❌ | ×を避けて進む | ×のマスを通らずにGOALへ。通ったマスの文字を読む |
| ⭐ | STARTが変わる2段階 | 赤い文字の指示で、赤い★から出発しなおしてもう一度解く |
| ✏️ | じぶんで道を描く | 正解にしたい道を指でなぞると、その道が最短になる迷路を作る |

## 「最短はこっちだ」と迷わせないしくみ

伊神さんから「最短なのかどうか怪しい距離感だった」という指摘を受けて入れた、いちばん大事な部分です。

**既定では、ぐるっと回れる道（輪っか）を作りません。** 道は木の枝のように分かれるだけなので、
STARTからGOALへの行き方は**そもそも1通りしかありません**。行き止まりに入ったら戻るだけです。

わき道（輪っか）を足す設定にしたときは、**次に短い道との差を必ず4マス以上**にします。
この差は「2番目に短い一本道」をきちんと計算して出しています（ヤンの方法の考え方）。
「1歩よそへ出て戻る」ような歩き方は別の道として数えないので、見た目どおりの差が出ます。

画面には「ほかに行ける道がないので、まちがえようがありません」「次に短い道より 6マス 短い」
のように出るので、印刷する前に確かめられます。

## 出力

- **印刷**：問題用紙（やることの文＋迷路）／段階ごとの盤面／答え
- **白黒印刷**：色を「線のもよう＋文字の飾り」に置きかえ、凡例もつけます
- **PNG保存**：印刷と同じ大きさで書き出します

画面・印刷・PNG・プレイヤー画面は**同じ描画関数を1本だけ**通しています。

## くわしく直したいとき

右上の「✏️ くわしく直す」で編集画面に移ります。「🏠 かんたん作成」でいつでも戻れます。

| 分類 | 内容 |
|---|---|
| 迷路編集 | 大きさ変更・壁の追加/削除・START/GOAL（複数可）・Undo/Redo・ズーム/パン |
| 正解ルート | ペンで描く／途中から描き直す／長さ表示／**このルートが最短になる迷路を作る** |
| 情報配置 | ひらがな・カタカナ・漢字・英字・数字・記号／色6色／大きさ／ドラッグ移動・複製・範囲選択 |
| 自動配置 | ルート上に文章を自動配置（順・逆順・等間隔・指定マス）／ダミー文字の自動散布 |
| 抽出 | 通過文字・色フィルター・読み順6種・奇数/偶数番目・種類しぼり |
| ギミック | ○を通る／×を避ける／一方通行／START変更／GOAL変更（記号でも指定可）／線を消す／文字を消す／反転・回転／ワープ（A〜D組） |
| 連鎖 | STEPエディタ・状態変化・再探索・ルート形状取得・別盤面への転写・囲まれた領域 |
| 検証 | 到達可能／最短が1本か／次に短い道との差／○全通過／×回避／一方通行の詰み／STEP間の状態変化／想定こたえとの一致 |

### 操作のこつ

| やりたいこと | やり方 |
|---|---|
| 迷路の変更をもどす | Ctrl+Z（上のバー「↶ 迷路をもどす」） |
| STEPの変更をもどす | 左の「↶ STEPをもどす」（迷路とは別の履歴です） |
| 文字・記号を動かす | 「えらぶ」でドラッグ |
| 画面じたいを動かす | 指2本、または盤の外側をドラッグ |
| 文字を打つ | 「もじ」でマスを押す。Enterで右へ進む |
| 消す／複製 | Delete ／ Ctrl+D |

## ファイル構成

```
meiro-nazo-maker/
├── index.html   画面とスタイル
└── js/
    ├── model.js     データ構造（Maze / Wall / Element / Route / Start / Goal）
    ├── engine.js    最短経路・道の本数・次に短い道との差・一方通行・○×・ワープ
    ├── generate.js  正解ルート → 迷路の自動生成
    ├── render.js    描画（画面・印刷・PNG・プレイヤー画面で共通の1関数）
    ├── ops.js       ギミック部品のレジストリ（入力→処理→出力）＋抽出
    ├── steps.js     STEPの連鎖・State計算・自動検証
    ├── packages.js  謎の型6つ。条件を満たす迷路が出るまで作り直す
    ├── wizard.js    かんたん作成画面（最初に出る3ステップの画面）
    ├── editor.js    キャンバス操作・Undo/Redo・ズーム/パン・その場文字入力
    └── app.js       編集画面の配線
```

### 設計上の約束（次に触るときのために）

- **設計図（Maze）と、STEPを通したあとの盤面（State）を分ける。**
  STEPを走らせるときは毎回 Maze を複製してから変換をかけるので、STEPをいじっても設計図は壊れない。
- **描画関数は `MZ.render.drawBoard` の1本だけ。** 画面・印刷・PNG・プレイヤー画面は全部これを呼ぶ。
- **ギミックは `MZ.ops.register()` に1つ足すだけで増える。** if文の場合分けは作らない。
- **謎の型は `MZ.packages.register()` に1つ足すだけで増える。**
  `make(recipe)` の中で作って、`MZ.steps.validateAll` に通し、**警告が1つでも出たら捨てて作り直す**。
  だから出てくるものは必ず解ける。
- 道は「ぐねぐね曲がった一本道を先に描く → その道が最短になる迷路を作る」順で作る。
  先に迷路を作ると、文字を置く場所も近道になる壁も足りなくなる（実測で197/200が失敗した）。
- 外部ライブラリ・CDNなし。`file://` で直接開いても動く。

## 動かない・困ったとき

- **作れませんでしたと出る**：文章が長すぎます。盤面を大きくするか、文章を短くしてください
- **保存できない**：プライベートモードでは保存できないことがあります。「ファイルに書き出す」を使ってください
- **文字が読めない**：白黒印刷なら「白黒で印刷する」にチェック
