1 どんなしかけを入れますか？（いくつでも組み合わせられます）

🏁 「STARTからGOALまで、いちばん短い道を通る」は、どの謎にも必ず入ります。
このページは上から下へ1〜5の順に進みます。4 できたものを見る・直すに出る迷路は 「できあがりの絵」ではなく本物の盤面なので、見ながらそのまま 文字や記号を置く・動かす・色を変える・消す ができます。

もっと細かく決める（ふつうはそのままでOK）

「わき道なし」だと、行き止まりはあってもぐるっと回れる道はできません。 解く人が「最短はこっちだ」と迷わずに決められます。

大きさ・文字の量・わき道の3つは ⑤ の「A 盤面と文字の量」と同じ値です（どちらで変えても両方に効きます）。 いまの盤面をその場で作り直すのは ⑤ の A にある「変える」ボタンです。

使い方（はじめての方へ）

このツールは「迷路を作る道具」ではなく「謎のしくみを作る道具」です。 条件を先に決めると、その条件を全部みたす迷路のほうを自動で作ります。

いちばんかんたんな使い方（3ステップ）

  1. どんな謎にするかをカードから選ぶ
  2. こたえになる文章を入れる（例：あかいもじをよめ）
  3. 「✨ 自動で作る」を押す → 印刷する

できあがった迷路は、かならず次の条件を満たしています。

  • STARTからGOALへの道は1本だけ（または次に短い道と4マス以上ちがう）
  • 入れた文章が、そのとおりに読める
  • 2段階の謎なら、指示どおりにすると本当に道が変わる

直したいとき（4 できたものを見る・直す）

  • 画面は切りかわりません。4に出ている迷路が「本物の盤面」です。見ながらそのまま直せます
  • 上のツールでもじ・きごう・かべを置く／けすで消す／えらぶでドラッグして動かす
  • 動かしたいものを「えらぶ」で選ぶと、盤面のすぐ下で色・大きさ・複製・削除ができます
  • 盤面の上のタブで「問題」と「n段めの答え」を切りかえられます（同じ迷路のまま、通り道だけ変わります）

もっと細かく直したいとき（5 もっと細かく直す）

  • C 読み方とこたえに「このルートを・この色で・この順に読んだら・この言葉」と書いて「✨ この通りに置く」を押すと、そのとおりに文字を置き直します
  • 「ルート」で道をなぞり、「このルートが最短になる迷路を作る」を押すと、その道が正解の迷路ができます
  • STEP（謎の流れ）を押すと、その時点の盤面が4に出ます。押したSTEPの中の↑↓で順番を入れかえられます
  • チェックに ✓ ばかりが並べば、謎として成立しています
  • 「⬆ 上（作るところ）へ」で、いつでもページの上に戻れます

覚えておくと便利

  • 迷路をもどす＝Ctrl+Z／STEPをもどすは⑤のSTEP欄にあります（別々です）
  • 大きさ・文字の量・わき道は、②の「もっと細かく決める」と⑤のAで同じ設定です（片方を変えるともう片方も変わります）
  • 消す＝Delete ／ 複製＝Ctrl+D
  • 文字は「もじ」でマスを押すとその場で打てます。Enterで右へ進みます
  • 文字や記号は「えらぶ」でドラッグして動かします
  • 画面じたいを動かすときは、指2本か盤の外側をドラッグ
