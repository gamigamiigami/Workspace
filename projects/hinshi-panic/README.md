# 品詞パニック

中学2年生向けの**文法（品詞の識別）アクションゲーム**。
クイズ形式ではなく「落ちものアクション」で、繰り返し遊ぶうちに品詞のみわけかたが反射レベルで身につくことを狙う。

## 遊び方

1. 画面上から単語が落ちてくる
2. **黄色く光っている単語**（いちばん下の単語）の品詞ボタンをタップ
3. 正解すると単語が消えて得点。連続正解で**コンボ**（最大4倍）
4. 単語を地面まで落とすとライフが1減る（3回でゲームオーバー）
5. 正解を重ねるとレベルアップ → 新しい品詞が登場し、スピードも上がる

## ゲーム性と学びの設計

| 仕掛け | 学習効果 |
|---|---|
| レベル制（3品詞 → 8品詞へ段階的に増加） | 用言3種の識別から始めて無理なくステップアップ |
| レベルアップ時に新品詞の「みわけかた」を表示 | ルールを知ってから実戦に入る足場かけ |
| ミス時に正解＋ヒントを表示して一時停止 | まちがえた瞬間に正しい知識で上書き |
| 「大きい／大きな」「きれいだ」などの引っかけ語 | 定期テスト頻出の混同ポイントを反復練習 |
| 結果画面に品詞別正答率＋まちがえた単語リスト | 自分の苦手品詞がひと目でわかる |
| ハイスコア・コンボ・称号（文法みならい〜品詞マスター） | 繰り返しプレイの動機づけ |

## 収録データ

- 単語：約110語（8品詞）
- 品詞：動詞・形容詞・形容動詞・名詞・副詞・連体詞・接続詞・感動詞
- レベル構成：
  - Lv1：動詞・形容詞・形容動詞（言い切りの形での識別）
  - Lv2：＋名詞
  - Lv3：＋副詞・連体詞
  - Lv4：＋接続詞・感動詞（全8品詞）
  - Lv5以降：エンドレス（だんだん高速化）

## 技術仕様

- 1ファイル完結（`index.html`）・外部ライブラリ／CDNなし・オフライン動作
- フォント：system-ui（学校のアクセス制御環境対応）
- ハイスコアは localStorage 保存（プライベートモードでも落ちないよう try-catch 済み）
- iPad縦持ち（768px）優先デザイン。タップ領域は44px以上

## 単語・問題の追加方法

`index.html` 内の `const WORDS = [...]` に1行追加するだけ：

```javascript
{ w: '単語', t: '品詞名', h: '（省略可）ミス時に出す個別ヒント' },
```

`t` は「動詞・形容詞・形容動詞・名詞・副詞・連体詞・接続詞・感動詞」のいずれか。
