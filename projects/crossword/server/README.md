# 短いリンクを使えるようにする手順（無料・所要15分ほど）

この作業をすると、配布リンクが

```
https://gamigamiigami.github.io/Workspace/projects/crossword/#g=H4sIAAAA…（900文字以上）
```

から

```
https://gamigamiigami.github.io/Workspace/projects/crossword/?q=ab3x9k
```

に変わります（**約70文字**）。

---

## 大前提：お金は一切かかりません

使うのは Cloudflare（クラウドフレア）という会社の**無料枠**です。

| 項目 | 無料でできる量 | このツールでの使用量 |
|---|---|---|
| 問題の読み込み | 1日10万回 | 1クラス40人が解いても40回 |
| 問題の保存 | 1日1,000回 | 1日に作る問題は数個 |
| 保存できる量 | 1GB | 問題1つ2KB＝**50万問**入る |

**クレジットカードの登録は不要**です。無料枠を超えても勝手に課金されることはなく、
一時的に止まるだけです（この使い方で超えることはまずありません）。

---

## 手順

### 1. アカウントを作る

1. <https://dash.cloudflare.com/sign-up> を開く
2. メールアドレスとパスワードを入れて登録
3. 届いたメールのリンクをクリックして、登録を完了させる

### 2. 保存場所（KV）を作る

1. 左のメニューから **「ストレージとデータベース」→「KV」** を選ぶ
2. **「ネームスペースを作成する」** を押す
3. 名前に `crossword-puzzles` と入れて、作成する

> KV は「消えない保存箱」のことです。ここに問題データが入ります。
> **有効期限は設定しないので、勝手に消えることはありません。**

### 3. サーバー（Worker）を作る

1. 左のメニューから **「Compute（ワーカー）」→「Workers と Pages」** を選ぶ
2. **「作成する」→「Worker から開始する」** を押す
3. 名前に `crossword-store` と入れて、**「デプロイ」** を押す
   （この時点では中身が空っぽですが、それで構いません）

### 4. コードを貼り付ける

1. デプロイ後の画面で **「コードを編集」** を押す
2. 出てきたコードを **全部消す**
3. このフォルダにある **`worker.js` の中身を全部コピーして貼り付ける**
4. 右上の **「デプロイ」** を押す

### 5. 保存場所とサーバーをつなぐ

1. その Worker の画面で **「設定」→「バインディング」** を開く
2. **「追加」→「KV ネームスペース」** を選ぶ
3. 次のように入れる

   | 欄 | 入れるもの |
   |---|---|
   | 変数名 | `PUZZLES` ← **この綴りで正確に**（大文字） |
   | KV ネームスペース | 手順2で作った `crossword-puzzles` |

4. **「デプロイ」** を押す

> ⚠️ 変数名を `PUZZLES` 以外にすると動きません。ここだけ間違えやすいので確認してください。

### 6. アドレスを控える

Worker の画面に、次のようなアドレスが表示されています。

```
https://crossword-store.〇〇〇.workers.dev
```

この `〇〇〇` の部分は伊神さんごとに違います。**このアドレスをコピー**してください。

### 7. ツールに設定する

`projects/crossword/index.html` を開き、**上のほう**にある次の行を探します。

```js
const SHARE_API = '';
```

ここに手順6のアドレスを貼り付けます。

```js
const SHARE_API = 'https://crossword-store.〇〇〇.workers.dev';
```

保存して、GitHubにアップすれば完了です。

> 面倒なら、手順6のアドレスを私（Claude）に教えていただければ、この設定と公開まで行います。

## ちゃんと動いたか確かめる

1. クロスワードを作って **「配布用リンクを作る」** を押す
2. リンクが `?q=` で始まる短いものになっていれば成功です
3. そのリンクを別の端末（スマホなど）で開いて、問題が出れば完璧です

---

## うまくいかないときは

| 症状 | 原因と対処 |
|---|---|
| リンクが長いまま | 手順7の `SHARE_API` が設定されていない。空欄のままだと今まで通り長いリンクになる（安全のための動作） |
| 「保存できませんでした」と出る | 手順5の変数名を確認。`PUZZLES` と正確に一致しているか |
| リンクを開くと「見つかりません」 | 手順4のコードが正しく貼れているか。Worker のアドレスの綴りが合っているか |

**うまくいかなくても、長いリンクとQRコードはいつでも使えます。**
短いリンクが作れないときは自動で長いリンクになるので、授業に穴があくことはありません。

---

## あとから消したいとき

Cloudflare の画面の KV から、保存された問題を個別に削除できます。
アカウントごと消せば、データも全部なくなります。
