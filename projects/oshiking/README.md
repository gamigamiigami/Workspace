# オシキング 〜ボタン1つのパーティ大会〜

オフ会用の大人数パーティゲーム。**ホストPCをスクリーン投影**し、参加者は**自分のスマホをコントローラー**にして遊ぶ（Jackbox型）。

公開URL（ホスト画面）：https://gamigamiigami.github.io/Workspace/projects/oshiking/

> 🤖 **開発を引き継ぐ場合は先に [`HANDOFF.md`](./HANDOFF.md) を読むこと。** アーキテクチャの勘所・既知のハマりどころ・未実装項目をまとめてある。このREADMEは遊び方・ルール説明が中心。

## 遊び方（当日の流れ）

1. **ホスト**：上のURLをPCで開いてスクリーン投影 → 画面にQRコードが出る
2. **参加者**：スマホのカメラでQRを読む → 名前を入れて「参加する」
3. ホスト画面に参加者が ● で表示される → 全員揃ったら「大会スタート」
4. ミニゲーム（最速おし／がまん／ジャスト／3すくみ／連打耐久／チキンレース／だるまさんがころんだ／少数決）を戦い、総合優勝を決める

> 1人＋CPUでもテストできます（ロビーの「＋CPUを追加」）。

## テスト機能の使い方

1. ロビーで「テストメニューへ」（1人＋CPUでもOK。「＋CPUを追加」でCPUを増やせる）
2. メニューでゲームを選ぶ → プレイ → 結果（3・2・1加点）
3. 結果画面で **☆1〜3** を押すと評価が保存され、メニューの各カードに★で表示される
4. 「通しで全部」で全ゲーム連続プレイも可能

### 親機プレイ（デバッグ用：ホストPCでも遊ぶ）

スマホを用意しなくても、**ホストPC本体でプレイヤーとして参加**できます。

- ロビーまたはメニューの「**＋自分も参加（親機）**」を押すと、`あなた(親機) 🎮` が参加者に加わる
- ゲーム中は **スペースキー / Enter**、または画面右下の「**あなたが押す**」ボタンで押下できる
- 押す経路はスマホ・CPUと同じ（`pressHandler`）なので、3すくみ・少数決のcycle系も「押すたびに選択が切り替わる」

## 3すくみ と 少数決 の違い

似た「押すたび選択が変わる（cycle）」操作だが、**勝敗の決め方が根本的に別物**：

- **3すくみ**：グー・チョキ・パーの**本物のじゃんけんルール**。手が2種類だけ出ていれば、勝つ方の手の人が全員勝ち（1回勝負）。手が1種類だけ、または3種類全部そろうと「**あいこ**」＝もう一回（実際のじゃんけんと同じ「あいこでしょ！」を自動で最大4回繰り返す）。**「なにを選ぶか」に正解不正解のある駆け引き**。
- **少数決**：🔴か🔵の2択。理由は問わず**人数が少ない方が無条件で生存**、多数派は道連れで脱落。これを**複数ラウンド**繰り返して最後の2〜3人まで絞り込むサバイバル方式。同数なら全員セーフ。**「みんなと違う方に賭ける」心理戦**。

要するに：3すくみ＝ルールに基づく1発勝負（あいこあり）、少数決＝人数の少なさだけで生き残る多ラウンド勝ち抜き。

## チキンレースのルール

押した順番で、**最後から2番目＝1位(3点)／3番目＝2位(2点)／4番目＝3位(1点)**。
**最後に押した人（ドベ）と、最後まで押さなかった人は負け**。ギリギリまで我慢する度胸試し。
**プレイ中は誰がいつ押したか他の人には分からない**（本人にだけ内緒でお知らせ）。時間切れ後、**結果発表で一人ずつ押した順を明かす**演出付き。

## がまんのルール（リニューアル）

「押すな」の間に**ニセの「いま押せ！？」がランダムに点滅**する。釣られて押したら脱落。
本物の「**解除！**」が出たら、そこから**一番早く押した人が勝ち**。ニセに釣られず・本物に素早く反応する我慢＋反応ゲーム。
（※「押さないだけ」だった旧版から、釣り合図＋最後の反応勝負に作り替え。）

## だるまさんがころんだのルール

「**すすめ！**」の間だけ連打してコマを前進。「**とまれ！**」の合図中に押すと**大きく後退**（前進の約4倍・強めのペナルティ）。
鬼（🧸）に**先に到達した順**が上位。反応の良さと我慢のハイブリッド。

## 少数決（道連れ）のルール

2択（🔴あか／🔵あお）を押して選ぶ。**少ない方（少数派）が生き残り、多数派は道連れで脱落**。
同数のラウンドは全員セーフ。これを繰り返し、**最後まで残った少数派が上位**（脱落は遅い人ほど上位）。
※コントローラーは3すくみと同じ「押すたび選択が変わる」cycle方式（選択肢ラベルだけ差し替え）。
結果発表では**各ラウンドで誰が🔴/🔵どちらに投票したか一覧表**を表示（偶奇投票も同様にA/B/C別の投票者一覧を表示）。

## 追加ゲーム（第1弾）のルール

- **丸太ジャンプ**：プレイヤーが**横一列**に並び、丸太が**右から左へ転がってくる**。自分の所に来た瞬間に押すと**ジャンプしてよける**。**何回押してもOK**（連打で構わない）で判定もややファジー（ぴったりのタイミングでなくてもOKな幅あり）。よけそこねると被弾して脱落、だんだん速くなる。よけた本数で順位。一番右のプレイヤーも丸太が見えやすいよう内側に配置。
- **3の倍数で押すな**：数字がリズムで進む（**2倍速テンポ**）。**本編前にメトロノーム的な予備カウント**＋**毎回ビート音（危険な数字は高い音）**でリズムが分かりやすい。**ふつうの数字は押す／3の倍数・3の付く数（3,6,9,13,23…）は押さない**。間違えたら脱落。どこまで耐えたかで順位。
- **早撃ちガンマン**：**3・2・1のカウントダウンの勢いのまま、標的の名前発表＝「どん！」でスタート**（発表まで誰が標的か分からず、間延びしない演出）。標的は撃たれ役なので**押したら負け**。標的以外は早押し、速い人ほど高得点。
- **秒数当て**：「◯秒で押せ」という**目標秒数を画面上部にずっと表示**。時計の数字は**最初の3秒だけ見え、その後は「？」**に隠れる。体内時計で目標秒に一番近い人が勝ち。
- **偶奇投票**：A/B/Cに投票（cycle）。今回は**偶数**か**奇数**か、画面上部に大きく表示。**各グループの人数が指定パリティに一致したグループが生存**、外れは脱落。最後まで残った人が上位。

## 追加ゲーム（第2弾）のルール

- **お題早押し**：「赤いもの／食べ物／動物／丸いもの が出たら押せ」。**ダミー（非該当）が数回出る間は押すな**（押すとフライング）。本命が出たら早押し、速い人が上位。
- **最速◯回**：規定回数（18回）を最速で連打。ただし**🔒ロック中に押すと回数が減る**。先に達成した順で上位。
- **果物カウント**：果物が**1個ずつ動画のように次々出現**（一覧をパッと見せるのではなく、数えながら見るテンポ）。出現が終わったら、スマホの**カウンター（＋1ボタン／押しすぎたら−1で戻せる）**で「何個あったか」を答える。正確に数えた人が上位。

## 技術メモ

- 1ファイル完結 `index.html`。`?room=<id>` の有無でホスト/コントローラーを自動切替
- 通信：**PeerJS**（無料の公開クラウド経由・サーバ構築不要）→ `https://unpkg.com/peerjs`
- QR：**qrcode-generator**（端末内で生成。URLは外部に送信しない）→ `https://cdn.jsdelivr.net/npm/qrcode-generator`
- 入力は `pressHandler` に集約し、各ゲームが差し替える設計（プロトタイプのループ構造は維持）

## 当日の注意（重要）

- **ネット必須**：PeerJSは公開クラウドを使うため、会場のWi-Fi/モバイル回線が必要。事前に接続確認を。
