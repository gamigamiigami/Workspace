# オシキング 〜ボタン1つのパーティ大会〜

オフ会用の大人数パーティゲーム。**ホストPCをスクリーン投影**し、参加者は**自分のスマホをコントローラー**にして遊ぶ（Jackbox型）。

公開URL（ホスト画面）：https://gamigamiigami.github.io/Workspace/projects/oshiking/

## 遊び方（当日の流れ）

1. **ホスト**：上のURLをPCで開いてスクリーン投影 → 画面にQRコードが出る
2. **参加者**：スマホのカメラでQRを読む → 名前を入れて「参加する」
3. ホスト画面に参加者が ● で表示される → 全員揃ったら「大会スタート」
4. 5ラウンドのミニゲーム（最速おし／がまん／ジャスト／3すくみ／連打耐久）を戦い、総合優勝を決める

> 1人＋CPUでもテストできます（ロビーの「＋CPUを追加」）。

## 技術メモ

- 1ファイル完結 `index.html`。`?room=<id>` の有無でホスト/コントローラーを自動切替
- 通信：**PeerJS**（無料の公開クラウド経由・サーバ構築不要）→ `https://unpkg.com/peerjs`
- QR：**qrcode-generator**（端末内で生成。URLは外部に送信しない）→ `https://cdn.jsdelivr.net/npm/qrcode-generator`
- 入力は `pressHandler` に集約し、各ゲームが差し替える設計（プロトタイプのループ構造は維持）

## 当日の注意（重要）

- **ネット必須**：PeerJSは公開クラウドを使うため、会場のWi-Fi/モバイル回線が必要。事前に接続確認を。
- スマホは file:// のホストには繋げないため、必ず**公開URL（GitHub Pages）**を使う。
- うまく繋がらない時：ロビーのルームIDが正しいか／同じネットに繋がっているか／ページ再読み込み。

## ローカルでの動作確認（開発者向け）

1. `index.html` をブラウザで開く（ホスト画面）。QRの下にURLが出る。
2. 別タブでそのURL（`?room=...`付き）を開く＝スマホ役。名前を入れて参加。
3. 別タブの大ボタンを押す → ホストタブの ● が光れば疎通OK。
   ※PeerJSはネット接続が必要（file://でも可）。
