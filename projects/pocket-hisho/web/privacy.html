ポケット秘書 プライバシーポリシー

2026年9月27日 制定

「ポケット秘書」（以下「このアプリ」）は、セミナー講師の予定・やること・運賃などを1か所にまとめ、 時間が来たら知らせるための、個人向けのアプリです。このページでは、このアプリがあつかう情報と、その使い方を説明します。

1. あつかう情報

  • アプリに入力された予定・やること・メモ・運賃やホテル代などの金額
  • 通知を届けるための、端末ごとの通知の宛先の情報
  • Googleカレンダーとつないだ場合：そのGoogleアカウントの「いつものカレンダー」にある予定 （題名・日時・場所・メモ）と、つないだカレンダーの名前（多くはメールアドレス）

2. 使い方

  • 予定を画面に表示すること、時間が来たら通知を送ることにだけ使います。
  • Googleカレンダーとつないだ場合は、アプリで入れた予定をGoogleカレンダーに書きこむこと、 Googleカレンダーで入れた・直した・消した予定をアプリに取りこむことにだけ使います。
  • 広告、分析、ほかのサービスへの提供には使いません。第三者に売ったり渡したりしません。

3. Google のデータについて

このアプリが Google API から受け取った情報の使用と、ほかのアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （「限定使用」の要件を含みます）に従います。

4. 保存する場所

情報は、このアプリを動かしている Cloudflare のサービス（Workers・D1）の中に保存します。

5. つながりの取り消し・削除

  • Googleカレンダーとのつながりは、アプリの「設定」→「Googleカレンダー」→「Googleとのつながりを切る」でいつでも切れます。 Googleアカウントの「サードパーティ製のアプリとサービス」からも取り消せます。
  • 保存されている情報を消したいときは、アプリの管理者に連絡してください。

6. 連絡先

このアプリについてのお問い合わせは、アプリの管理者（このアプリへの招待を送った人）までご連絡ください。
