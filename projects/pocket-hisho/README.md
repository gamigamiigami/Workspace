# ポケット秘書

全国をまわる**セミナー講師**のための、予定とお金の手帳。
伊神さんが作って、知り合いの講師の方に渡すツール（伊神さん自身は使わない）。

- 本体：`index.html`（この1ファイルだけで動く）
- 想定端末：**スマホ縦持ち**（パソコン・iPadでも崩れない）
- 通信：**一切しない**（外部CDN・外部API・サーバーなし）
- 費用：**完全無料**

---

## このツールが消す「めんどう」

全国を回る講師の困りごとは、**1件のセミナーの情報がバラバラの場所に散らばっていること**。

> 日程はカレンダー、会場の住所はメール、新幹線はアプリ、ホテルは別のメール、
> 主催者の電話番号はLINE、講演料は請求書……
> → 当日、駅で「何時入りだっけ？担当者の番号どこ？」になる。

そこで背骨を1つに決めた：

### **1つのセミナー＝1枚のカード。当日は開くだけで全部わかる。**

## 画面の構成

上のタブで **日・週・月・年** を切りかえる。
**右へ行くほど情報を減らす**（年・月で詳細は出さない）。どこをタップしても最後は「日」に着地する。

| タブ | 出すもの | 出さないもの |
|---|---|---|
| **日** | 全部（主役の画面） | — |
| **週** | 日付・会場・時刻・セミナー/宿泊の印 | 連絡先・持ち物・お金の内訳 |
| **月** | カレンダーの●印＋その月の一覧と合計 | 詳細すべて |
| **年** | 件数・売上・経費の合計と月別の棒 | 詳細すべて |

### 「日」に出るもの（すべて任意入力）

カウントダウン／セミナー名／開演・会場入り・終了 ／ 場所（地図・住所コピー）／
連絡先（タップで電話・メール）／当日のながれ／移動（行き・帰り）／宿泊／
内容（対象・人数・資料・話すメモ）／持ち物（その場でチェックできる）／お金／メモ

**中身が空のかたまりは表示しない**ので、画面が無駄に長くならない。

## データの扱い

| 項目 | 決めごと |
|---|---|
| 保存先 | その端末のブラウザの中（`localStorage`、キーは `pocket-hisho:v1`） |
| 送信 | **しない**。主催者の連絡先・売上を扱うため、外に出さない設計 |
| 必須入力 | **日付だけ**。他はあとから足せる（入力が面倒だと使われなくなるため） |
| バックアップ | ①ファイルに書き出す ②文字としてコピー ③ファイルから読み込む ④貼りつけて読み込む |
| CSV | 年を選んで、売上・経費を表に書き出せる（BOM付きなのでエクセルで文字化けしない） |

> **バックアップが2通りある理由：** スマホのブラウザによってはファイルの保存がうまくいかないことがある。
> そのときのために「文字としてコピーしてメールやメモ帳に貼る」経路を必ず残してある。

**注意：** データは端末の中にしか無い。機種変更やブラウザのデータ削除で消える。
設定画面にその警告を常時出してある。

## 渡し方

| 方法 | 手順 | 向き不向き |
|---|---|---|
| **URLで渡す**（おすすめ） | GitHub Pages に置いてURLを送る。相手はホーム画面に追加 | 1タップで開ける。更新も届く |
| ファイルで渡す | `index.html` をそのまま送る | スマホでローカルHTMLを開くのは少し手間 |

※ ホーム画面に追加しても**Safariのタブとして開く**作りにしてある（`apple-mobile-web-app-capable` は付けていない）。
フルスクリーンにすると保存場所がSafariと分かれて「入れたはずのデータが無い」事故が起きるため。

## 作りの決まりごと（直すときに壊さないために）

- 色は**すべてCSS変数**。`@media (prefers-color-scheme: dark)` では**変数の中身だけ**差しかえる。
  濃い色の上に置く文字は `--on-navy`（白固定にすると暗い画面で読めなくなる）。
- データの読み込み口は2つ（保存ぶん／バックアップぶん）あるが、形をそろえるのは `normalizeData()` **1本だけ**。
- 保存は `saveData()`、描画は `render()`、書き出しは `downloadFile()` に集約。入口を増やさない。
- 入力中は画面を描きなおさない（**日本語入力の変換がとぎれるため**）。読み取りは保存時に `readEditor()` でまとめて行う。
- 画面に出す文字は必ず `esc()` を通す。
- `<fieldset>` には `min-inline-size: 0` が要る（既定では中身より狭くならず、スマホで横にはみ出す）。

### 動作確認用の窓口

ブラウザのコンソールから：

```js
window.pocketHisho.getData()   // いま入っているデータ
window.pocketHisho.getState()  // いま見ている日・タブ
window.pocketHisho.reload()    // 保存ぶんを読み直して描きなおす
```
