# ポケット秘書 セットアップ手順

**この手順でかかるお金：0円**（Cloudflare の無料枠だけで動きます。クレジットカードの登録も不要です）
**かかる時間の目安：30〜45分**（はじめての方の場合）

---

## ⚠️ 先に読んでください

この手順は、**私（Claude）が実際に Cloudflare のアカウントを操作して確かめたものではありません。**
コードの動作は手元で全部テストしましたが、Cloudflare の画面の文言やボタンの位置は、
時期によって少し変わることがあります。

**「手順書どおりのボタンが見つからない」ときは、止めて私に聞いてください。**
画面に出ている文字をそのまま教えてもらえれば、その場で調べ直します。
自己流で進めるより、そのほうが早くて確実です。

---

## 全体の流れ

```text
  ① Cloudflare の無料アカウントを作る
        ↓
  ② GitHub のこのリポジトリとつなぐ（コードを自動で取ってきてもらう）
        ↓
  ③ データの保管庫（D1）を作る
        ↓
  ④ 保管庫の中に、表を作る（SQLを1回貼りつけるだけ）
        ↓
  ⑤ 合言葉を登録する
        ↓
  ⑥ 公開 → URLができる
        ↓
  ⑦ スマホで開いて「ホーム画面に追加」→ 通知をオンにする
```

**①〜⑥は全部パソコンのブラウザだけでできます。** ソフトのインストールは要りません。

---

## ① Cloudflare の無料アカウントを作る

1. <https://dash.cloudflare.com/sign-up> を開く
2. メールアドレスとパスワードを決めて登録する
3. 届いたメールのリンクを押して、メールアドレスを確認する

> 💡 **Cloudflare（クラウドフレア）とは**
> Webサイトを置いておく場所を貸してくれる会社です。個人が小さく使うぶんには無料で、
> クレジットカードの登録も要りません。今回は「アプリの置き場所」と「1分ごとの時計番」を
> ここにお願いします。

---

## ② GitHub のリポジトリとつなぐ

1. 左のメニューから **「Compute (Workers)」**（または「Workers & Pages」）を開く
2. **「Create」**（作成）→ **「Workers」** → **「Import a repository」**（Gitから取り込む）を選ぶ
3. GitHub との連携を許可する（初回のみ。GitHubのログインを求められます）
4. リポジトリ **`gamigamiigami/Workspace`** を選ぶ
5. 設定を次のようにする

   | 項目 | 入れる値 |
   |---|---|
   | Project name（名前） | `pocket-hisho` |
   | Production branch（枝） | `claude/new-tool-creation-klodhg` ※あとでmainに変更可 |
   | **Root directory（フォルダ）** | **`projects/pocket-hisho`** ← ここが大事 |
   | Build command（組み立て命令） | 空のまま |
   | Deploy command（公開命令） | `npx wrangler deploy` |

6. **まだ「Deploy」は押さないでください。** 先に③④をやります。
   （押してしまっても大丈夫です。エラーになりますが、⑥でやり直せます）

> ⚠️ **Root directory を `projects/pocket-hisho` にするのを忘れないでください。**
> このリポジトリには他のプロジェクトも入っているので、これを指定しないと
> 「ファイルが見つかりません」というエラーになります。

---

## ③ データの保管庫（D1）を作る

1. 左のメニューから **「Storage & Databases」** → **「D1 SQL Database」** を開く
2. **「Create database」**（作成）を押す
3. 名前に **`pocket-hisho`** と入れて作る（名前はこのとおりにしてください）
4. できたら、画面に **Database ID**（`xxxxxxxx-xxxx-...` という長い文字）が出ます。
   **これをコピーして、メモ帳に貼っておいてください。** ④のあとで使います。

---

## ④ 保管庫の中に、表を作る

1. いま作った `pocket-hisho` のデータベースを開く
2. **「Console」**（コンソール）というタブを開く
3. このリポジトリの **`projects/pocket-hisho/schema.sql`** をGitHubで開き、
   **中身を全部コピー**する
4. Console の入力欄に貼りつけて、実行する
5. 「Success」のような表示が出れば完了です

> 💡 これは「予定を入れる引き出しを作る」作業です。1回やれば、もうしません。

---

## ⑤ Database ID をコードに書き、合言葉を登録する

### (1) Database ID を書きこむ

1. GitHub で **`projects/pocket-hisho/wrangler.toml`** を開く
2. 鉛筆マーク（Edit）を押す
3. この行を探す

   ```toml
   database_id = "ここに手順3で表示されたIDを貼る"
   ```

4. `"..."` の中を、③でコピーした Database ID に書きかえる

   ```toml
   database_id = "a1b2c3d4-5678-90ab-cdef-1234567890ab"
   ```

5. 「Commit changes」で保存する（枝は `claude/new-tool-creation-klodhg` のまま）

### (2) 合言葉を登録する

1. Cloudflare に戻り、**「Compute (Workers)」** → `pocket-hisho` を開く
2. **「Settings」** → **「Variables and Secrets」**（変数とシークレット）
3. **「Add」** を押して、次のように入れる

   | 項目 | 入れる値 |
   |---|---|
   | Type（種類） | **Secret**（秘密の値） |
   | Variable name（名前） | `APP_PASS` |
   | Value（中身） | **講師の方に伝える合言葉** |

4. 保存する

> 🔑 **合言葉の決め方**
> ・**10文字以上**にしてください（短いと当てられます）
> ・例：`osaka-semi-2026-kato` のように、覚えやすい単語をハイフンでつなぐ形がおすすめ
> ・**誕生日や電話番号は使わない**でください
> ・この合言葉は、**伊神さんと講師の方の2人だけ**が知っている状態にしてください
> ・8回まちがえると15分間入れなくなります（他人が総当たりで試せないようにするため）

---

## ⑥ 公開する

1. Cloudflare の `pocket-hisho` の画面で **「Deployments」** タブを開く
2. **「Create deployment」** または **「Retry deployment」** を押す
3. 1〜2分待つ
4. 成功すると、**`https://pocket-hisho.〇〇.workers.dev`** のようなURLが出ます

   **このURLが、アプリのアドレスです。** 講師の方に渡すのはこれと合言葉の2つだけ。

5. そのURLをパソコンのブラウザで開き、合言葉を入れて入れるか確かめてください

### うまくいかないとき

| 症状 | 見るところ |
|---|---|
| ビルドが失敗する | Root directory が `projects/pocket-hisho` になっているか |
| 「合言葉が設定されていません」と出る | ⑤(2) の `APP_PASS` が Secret として登録されているか |
| 「D1_ERROR」「no such table」と出る | ④のSQLを実行し忘れていないか |
| 画面は出るが予定が保存できない | `wrangler.toml` の database_id が③のIDと一致しているか |

**どれに当てはまるか分からないときは、画面に出ているエラーの文字をそのまま私に送ってください。**

## ⑦ スマホで使えるようにする（講師の方にやってもらうこと）

講師の方には、**URLと合言葉**を伝えたうえで、次を案内してください。

### iPhone の場合（ここが一番大事）

```text
1. Safari で URL を開く
2. 合言葉を入れて「はいる」
3. 画面の下にある 共有ボタン（□に↑）を押す
4. 「ホーム画面に追加」を選ぶ
5. ホーム画面にできた「ポケット秘書」のアイコンから開き直す   ← ここ！
6. 右上の ⚙ →「通知をオンにする」→「許可」
7. 「テスト通知を送る」を押して、通知が届けば完了
```

> ⚠️ **5番を飛ばすと通知が使えません。**
> iPhoneは「ホーム画面に追加したアイコンから開いたときだけ」通知を許可できる決まりです。
> Safariのタブで開いたままだと、「通知をオンにする」ボタンが押せない状態になります。
> （アプリの中にも、この手順が自動で出るようにしてあります）

### Android の場合

```text
1. Chrome で URL を開く
2. 合言葉を入れて「はいる」
3. 「ホーム画面に追加」（メニューから。または自動で出る案内から）
4. ⚙ →「通知をオンにする」→「許可」
5. 「テスト通知を送る」で確認
```

### パソコンから使う場合

URLを開いて合言葉を入れるだけです。ブックマークしておくと便利です。

## ⑧ カレンダーとつなぐ（あとからでOK）

### アプリの予定を Googleカレンダー／iPhone純正カレンダーに出す

1. アプリの ⚙ →「カレンダー①」の**URLをコピー**
2. **Googleカレンダー**：左下の「他のカレンダー」＋ →「URLで追加」→ 貼りつけ
   **iPhone純正**：設定 → カレンダー → アカウント → アカウントを追加 → その他 →
   「照会するカレンダーを追加」→ 貼りつけ

> ⚠️ **Googleカレンダーは反映が遅いです（数時間〜24時間）。**
> これはGoogle側の仕様で、こちらでは変えられません。
> **急ぎのお知らせは、このアプリの通知が担当します**ので、実害はありません。
> iPhone純正カレンダーは「取得」の頻度を最短5分に設定できます。

### Googleカレンダーの予定をアプリに取り込む

1. Googleカレンダーの [設定] → 左の一覧から取り込みたいカレンダーを選ぶ
2. 下のほうの **「カレンダーの統合」** を開く
3. **「シークレット アドレス（iCal 形式）」** をコピー
4. アプリの ⚙ →「カレンダー②」に貼りつけて「保存して、いま取り込む」

> 🔒 このアドレスは**パスワードと同じ**くらい大事です。人に見せないでください。
> （ログインなしで予定が読めてしまうため）
> 万一もれたら、同じ画面の「リセット」で作り直せます。

## 運用のめやす

| 項目 | 無料枠 | このアプリの使用量の見込み |
|---|---|---|
| Worker の実行回数 | 10万回／日 | 1分ごとの見回りで **1,440回/日** ＋ 操作ぶん。**じゅうぶん収まります** |
| D1 の保存容量 | 5GB | 予定1件が約2KB。**1万件入れても20MB** |
| D1 の読み取り | 500万行／日 | 見回り1回で数十行。**問題ありません** |

**お金がかかることはありません。** 無料枠を超えそうになると、Cloudflare から
メールで知らせが来ます（その場合も勝手に課金されることはありません）。
