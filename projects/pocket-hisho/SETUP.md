# ポケット秘書 セットアップ手順

**この手順でかかるお金：0円**（Cloudflare の無料枠だけで動きます。クレジットカードの登録も不要です）
**かかる時間の目安：20〜30分**（はじめての方の場合）

---

## ⚠️ 先に読んでください

この手順は、**私（Claude）が実際に Cloudflare のアカウントを操作して確かめたものではありません。**
アプリの動きは手元で全部テストしましたが、Cloudflare の画面の文言やボタンの位置は、
時期によって少し変わることがあります。

**「手順書どおりのボタンが見つからない」ときは、止めて私に聞いてください。**
画面に出ている文字をそのまま教えてもらえれば、その場で調べ直します。

## 全体の流れ

```text
  ① Cloudflare の無料アカウントを作る                        5分
  ② 保管庫（D1）を作って、ID をコピーする                     3分
  ③ ID を設定ファイルに書く（Claude に送るだけでもOK）          2分
  ④ GitHub とつないで公開する → アプリのURLができる           10分
  ⑤ URLを開いて合言葉を決める（公開したら、すぐに）             1分
  ⑥ 招待リンクを作って、講師の方にLINEで送る                   1分
  ─────────────────────────────────────────
  ⑦ 講師の方：リンクを開いて、アプリの案内どおりに進める
```

**①〜⑥は全部パソコンのブラウザだけでできます。** ソフトのインストールは要りません。
各手順の最後に **「✅ こうなればOK」** を書いてあります。そうならなかったら、そこで止めて聞いてください。

### 用意するもの

- パソコン（ブラウザ）
- メールアドレス（Cloudflare の登録用）
- GitHub にログインできる状態（このリポジトリ `gamigamiigami/Workspace` の持ち主のアカウント）
- メモ帳（ID やURLを一時的に貼っておく）

## ① Cloudflare の無料アカウントを作る（5分）

1. <https://dash.cloudflare.com/sign-up> を開く
2. **Email**（メールアドレス）と **Password**（パスワード）を入れて **「Sign up」**（登録）
3. 届いたメールの **「Verify email」**（確認）のリンクを押す
4. 「何に使いますか」のような質問が出たら、**「Skip」**（とばす）か、いちばん近いものを選んで進む
5. 料金プランを聞かれたら **「Free」**（無料）を選ぶ。クレジットカードは入れない

✅ **こうなればOK：** 左側にメニューが縦に並んだ画面（ダッシュボード）が出る

> 💡 **Cloudflare（クラウドフレア）とは**
> Webサイトを置いておく場所を貸してくれる会社です。個人が小さく使うぶんには無料です。
> 今回は「アプリの置き場所」「予定の保管庫」「1分ごとの時計番（通知を送る係）」をお願いします。

## ② 保管庫（D1）を作って、ID をコピーする（3分）

「保管庫」は、予定・やること・設定をしまっておく場所です。

1. 左のメニューから **「Storage & databases」**（保管と データベース）を開き、
   **「D1 SQL database」** を押す
   （見当たらなければ、画面上の検索窓に `D1` と入れる）
2. **「Create Database」**（または「+ Create」）を押す
3. **Name**（名前）に **`pocket-hisho`** と入れる（このとおり。ハイフンは半角）
   - Location（場所）などの他の欄は、**さわらずそのまま**でOK
4. **「Create」**（作成）を押す
5. できた保管庫の画面に **Database ID** という欄があり、
   `a1b2c3d4-5678-90ab-cdef-1234567890ab` のような **ハイフン入りの長い英数字** が出ています。
   **これをコピーして、メモ帳に貼っておく**

✅ **こうなればOK：** メモ帳に「8けた-4けた-4けた-4けた-12けた」の英数字が貼れている

> 💡 **なぜここだけ手で作るのか**
> ④の「自動で公開する仕組み」には、保管庫を新しく作る権限が付いていないためです
> （Cloudflare の資料で確認）。作ってしまえば、表（引き出し）はアプリが自動で作ります。

## ④ GitHub とつないで公開する（10分）

1. 左のメニューから **「Compute (Workers)」** →（または **「Workers & Pages」**）を開く
2. **「Create」**（または「Create application」）を押す
3. **「Import a repository」**（リポジトリを取り込む）の **「Get started」** を押す
4. **「Connect GitHub」**（GitHubとつなぐ）を押す → GitHub の画面に切りかわる
   - Cloudflare のアプリを入れてよいか聞かれるので、
     **「Only select repositories」**（選んだリポジトリだけ）→ **`Workspace`** を選んで **「Install & Authorize」**（または「Install」）
   - GitHub のパスワードを聞かれたら入れる
5. Cloudflare の画面に戻ったら、リポジトリの一覧から **`Workspace`** を選ぶ
6. **「アプリケーションをセットアップする」** の画面で、次のようにする
   （画面は日本語で出ます。**この画面には「ブランチ（使う枝）」の欄はありません**）

   | 欄の名前 | 入れるもの・やること |
   |---|---|

   | ビルド コマンド | 空のまま |
   | デプロイ コマンド | `npx wrangler deploy`（最初から入っている） |
   | プレビューコマンド | さわらない |
   | **プレビュービルドを有効化** | **オフにする**（このリポジトリには枝がたくさんあり、ほかの枝に保存があるたびに組み立てが走ってしまうため） |

7. **「デプロイ」** を押す
8. **1回目は失敗して大丈夫です。** Cloudflare は最初、リポジトリの「いつもの枝」

   - 「本番以外のブランチのビルド」のような切りかえがあれば **オフ**
   - **保存**する
10. **Claude（私）に「変えた」と送る。** 私がこの枝に保存し直すと、それをきっかけに Cloudflare が自動で公開します
   （自分でやる場合は「デプロイ」の一覧から、`claude/new-tool-creation-klodhg` の組み立てをやり直す）
11. 2〜3分待つ。Worker の画面で **「アクセス」**（Visit）を押すか、**「設定」→「ドメインとルート」** を見ると、
    **`https://pocket-hisho.〇〇.workers.dev`** というURLがあります。**これがアプリのアドレスです。メモ帳に貼る**

✅ **こうなればOK：** URLを開くと、ポケット秘書の **「はじめての合言葉」** の画面が出る

## ⑤ URLを開いて、合言葉を決める（公開したら、すぐに・1分）

1. ④のURLをパソコンのブラウザで開く
2. **「はじめての合言葉」** の画面で、合言葉を2回入れて **「この合言葉で始める」**
3. アプリの画面に入り、**「はじめの準備」** が自動で開く

✅ **こうなればOK：** 「はじめの準備」のいちばん上に「講師の方に招待リンクを送る」が出ている

> 🔑 **合言葉の決め方**
> ・**8文字以上**（10文字以上がおすすめ）。例：`osaka-semi-2026-kato`（単語をハイフンでつなぐ）
> ・誕生日や電話番号は使わない
> ・**講師の方には伝えなくて大丈夫です**（⑥の招待リンクで入れるため）。

> ⚠️ **なぜ「すぐに」なのか**
> 合言葉は「**そのURLを最初に開いた人**」が決める仕組みです（合言葉をGitHubに書かずに
> 済ませるため）。URLはまだ誰にも知られていないので心配はほぼありませんが、
> 念のため、公開したらすぐに開いて決めてください。
> もし最初に開いたのに「合言葉を入れてください」の画面が出たら、下の「うまくいかないとき」を見てください。

## ⑥ 講師の方に招待リンクを送る（1分）

1. 「はじめの準備」のいちばん上の **「招待リンクを作る」** を押す
2. **「LINEで送る」** を押す → LINE が開くので、講師の方を選んで **送信**
   - パソコンにLINEが入っていないときは **「リンクをコピーする」** → 自分のスマホのLINEやメールに貼って送る
3. 送るときに、ひと言そえる（例）

   > 前に話していた予定管理のアプリです。リンクを開いて、画面の案内どおりに進めてください。
   > 途中で「ホーム画面に追加」と「通知をオン」があります。5分くらいで終わります。

✅ **こうなればOK：** 「はじめの準備」の招待の欄に ✓ が付き、「できています」と出る

> 💡 **招待リンクについて**
> ・リンクを開くだけで入れます（**合言葉は要りません**）。**14日間**使えます
> ・期限が切れた・講師の方が機種変更した、などのときは ⚙設定 →「講師の方を招待する」で作り直せます
>   （作り直すと、前のリンクは使えなくなります）
> ・リンクを他の人に見せないようにしてください（見た人も入れてしまうため）

「はじめの準備」は、あとから **⚙設定 →「🚀 はじめの準備をひらく」** でいつでも開けます。

> ⚠️ **このアプリは「1冊の手帳を、伊神さんと講師の方で見る」作りです**
> ・伊神さんが入れた予定は、講師の方のアプリにも出ます（通知も講師の方に届きます）。
>   **伊神さんは自分の予定を入れないでください**（⚙設定の「見本の予定を入れてみる」も押さない）
> ・通知は、通知をオンにした**すべての端末**に届きます。伊神さんの端末で通知をオンにすると、
>   講師の方のお知らせが伊神さんにも届きます。**伊神さんの端末では通知をオンにしないでください**
>   （「はじめの準備」で「ホーム画面に追加」が出ても、しなくて大丈夫です）
> ・講師の方の予定は、伊神さんからも見えます。講師の方に一言伝えておくと安心です

## ⑦ 講師の方がやること（アプリが案内します）

講師の方には、LINEで「届いたリンクを開いて、画面の案内どおりに進めてください」と
一言添えるだけで大丈夫です。リンクを開くと、アプリが**その人のスマホに合わせた手順**を出します。

### iPhone の場合（アプリが出す案内）

```text
1. LINEのリンクをタップ → Safari で開く（ふつうは自動でSafariに切りかわります。
   LINEの中で開いてしまったときは、アプリが「Safariで開いて」と案内します）
2. 「はじめの準備」が出るので、書いてあるとおりに
     共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. ホーム画面にできた「ポケット秘書」のアイコンから開く
     → 自動でログインした状態になります
4. 「通知をオンにする」を押して「許可」
     → テスト通知が自動で届きます。届けば完了
5. （任意）「iPhoneのカレンダーに表示」を押して「照会」
```

> 💡 **自動でやっていること**
> ・iPhoneでは、Safari と「ホーム画面のアイコン」でデータの置き場所が別になるため、
>   ふつうはもう一度ログインが必要です。このアプリは、Safariの画面にある**6けたの番号を
>   アイコンに自動で渡す**ので、講師の方は何も入れずに入れます。
>   （うまく渡らなかったときだけ「6けたの番号」を聞かれます。Safariの画面に大きく出ています）
> ・通知をオンにした直後に、テスト通知を自動で送ります
> ・通知の登録が消えていたら、アプリを開いたときに何もしなくても登録し直します

> ⚠️ **iPhone は iOS 16.4 以降が必要です**（通知の仕組みがそれ以降にしかないため）。
> 設定 → 一般 → 情報 →「iOSバージョン」で確かめられます。

### Android の場合

```text
1. LINEのリンクをタップ → Chrome で開く
2. 「はじめの準備」の「ホーム画面に追加する」ボタンを押す（または ︙ →「ホーム画面に追加」）
3. 「通知をオンにする」→「許可」→ テスト通知が届けば完了
4. （任意）「Googleカレンダーに表示」を押して「追加」
```

### パソコンから使う場合

URLを開いて合言葉を入れるだけです。ブックマークしておくと便利です。

## カレンダーとつなぐ（あとからでOK）

### アプリの予定を、いつものカレンダーに出す

アプリの ⚙設定 →「カレンダーに表示する」のボタンを押すだけです。

- **iPhoneのカレンダーに表示** → 開いた画面で「照会」
- **Googleカレンダーに表示** → 開いた画面で「追加」

> ⚠️ **Googleカレンダーは反映が遅いです（数時間〜24時間）。**
> これはGoogle側の仕様で、こちらでは変えられません。
> **急ぎのお知らせは、このアプリの通知が担当します**ので、実害はありません。

### Googleカレンダーの予定を、アプリに取り込む（パソコンでやるのがかんたん）

1. パソコンでGoogleカレンダーを開き、[設定] → 左の一覧から取り込みたいカレンダーを選ぶ
2. 下のほうの **「カレンダーの統合」** を開く
3. **「シークレット アドレス（iCal 形式）」** をコピー
4. アプリの ⚙設定 →「🔧 くわしい設定」→「ほかのカレンダーの予定を、アプリに取り込む」に
   貼りつけて「保存して、いま取り込む」

> 🔒 このアドレスは**パスワードと同じ**くらい大事です。人に見せないでください。
> 万一もれたら、Googleカレンダーの同じ画面の「リセット」で作り直せます。

## うまくいかないとき

| 症状 | 見るところ・やること |
|---|---|
| 失敗の画面に「D1」「database」「Authentication error」の文字がある | ③の ID が書きこまれていないか、まちがっている。`wrangler.toml` の `database_id = "…"` が②の Database ID と同じか確かめる |
| 失敗の画面に「name」「does not match」の文字がある | ④の Project name が `pocket-hisho` になっていない。Worker を消して作り直すのがかんたん |
| 失敗の画面に「wrangler.toml」「not found」「Could not find」の文字がある | Root directory が `projects/pocket-hisho` になっていないか、枝が `claude/new-tool-creation-klodhg` になっていない。Settings → Build で直して公開し直す |
| 最初に開いたのに「合言葉を入れてください」と出る（自分で決めた覚えがない） | 他の人が先に決めた可能性があります。下の「合言葉を決め直す」の**方法B**でやり直してください |
| 講師の方が「この招待リンクは使えません」と言われる | 期限切れ（14日）か、作り直して前のリンクになった。⚙設定 →「講師の方を招待する」で新しいリンクを送る |
| 講師の方が「しばらく試せません」と言われる | 合言葉か番号を8回まちがえて、15分止まっています。伊神さんの端末で ⚙設定 → くわしい設定 →「別の端末の『入れません』を解除する」 |
| 通知が来ない | アプリの「はじめの準備」を開くと、何が足りないかが出ます。iPhoneは「ホーム画面のアイコンから開いているか」「iOS 16.4以降か」 |

**どれに当てはまるか分からないときは、画面に出ているエラーの文字をそのまま私に送ってください。**

### 合言葉を決め直す（忘れたとき・他の人に決められたとき）

**方法A：Cloudflare 側で決める（合言葉を忘れたとき。かんたん）**

1. Cloudflare の `pocket-hisho` → **「Settings」** → **「Variables and Secrets」**
2. **「Add」** で、Type を **Secret**、名前を `APP_PASS`、中身を新しい合言葉にして保存
3. これで、アプリの合言葉は `APP_PASS` のほうになります（画面で決めたものより優先）

**方法B：はじめからやり直す（他の人に決められたとき・スマホをなくしたときなど、
ほかの端末のログインもすべて消したいとき）**

> 方法Aでは、すでにログインしている端末はそのまま使えてしまいます。
> 知らない人を確実に締め出したいときは、こちらを使ってください。

1. 左のメニュー **「Storage & Databases」→「D1 SQL Database」→ `pocket-hisho`** を開く
2. **「Console」**（コンソール）タブで、次の3行を**1行ずつ**貼りつけて実行する

   ```sql
   DELETE FROM kv WHERE k = 'pass';
   DELETE FROM sessions;
   DELETE FROM subs;
   ```

   （1行目＝合言葉を消す／2行目＝すべての端末をログアウト／
   3行目＝通知の宛先を消す。なくしたスマホに予定の通知が届き続けないように）
3. アプリのURLを開くと「はじめての合言葉」の画面に戻ります（**予定のデータは消えません**）
4. すべての端末がログアウトされるので、講師の方には招待リンクを送り直してください。
   通知の宛先は、ログインし直してアプリを開いたときに自動で登録し直されます

> ※ 方法Aで `APP_PASS` を登録している場合は、画面の合言葉ではなく `APP_PASS` のままになります。

- **ログを見る**：`pocket-hisho` →「Logs」→「Live」で、いま何が起きているか見えます
- **通知が来ない**：アプリの ⚙設定 →「テスト通知を送る」でまず確認。
  届かなければ、端末の設定でこのアプリの通知が許可されているか確認してください
