# ポケット秘書 セットアップ手順

**この手順でかかるお金：0円**（Cloudflare の無料枠だけで動きます。クレジットカードの登録も不要です）
**かかる時間の目安：15〜20分**（はじめての方の場合）

---

## ⚠️ 先に読んでください

この手順は、**私（Claude）が実際に Cloudflare のアカウントを操作して確かめたものではありません。**
アプリの動きは手元で全部テストしましたが、Cloudflare の画面の文言やボタンの位置は、
時期によって少し変わることがあります。

**「手順書どおりのボタンが見つからない」ときは、止めて私に聞いてください。**
画面に出ている文字をそのまま教えてもらえれば、その場で調べ直します。

---

## 全体の流れ

```text
  ① Cloudflare の無料アカウントを作る                  … 伊神さん（5分）
        ↓
  ② GitHub のこのリポジトリをつないで「Deploy」を押す    … 伊神さん（5分）
        │   └ データの保管庫・表づくりは自動
        ↓
  ③ できたURLを開いて、合言葉を決める                    … 伊神さん（1分）
        ↓
  ④ アプリの「はじめの準備」で招待リンクを作り、LINEで送る … 伊神さん（1分）
        ↓
  ⑤ 講師の方がリンクを開くと、あとはアプリが順番に案内する … 講師の方
```

**①〜④は全部パソコンのブラウザだけでできます。** ソフトのインストールは要りません。

### 前のやり方からの変更点（以前の手順書を読んだ方へ）

| 前のやり方 | いま |
|---|---|
| データの保管庫（D1）を自分で作る | **公開のときに自動で作られます** |
| 表を作るSQLを貼りつけて実行する | **アプリがはじめて動いたときに自動で作ります** |
| Database ID を wrangler.toml に書きこむ | **不要**（ファイルは書きかえなくてOK） |
| 合言葉を Cloudflare の Secret に登録する | **アプリの画面で決めます** |
| 講師の方にURLと合言葉を伝える | **招待リンクをLINEで送るだけ**（合言葉は伝えなくてよい） |

## ① Cloudflare の無料アカウントを作る

1. <https://dash.cloudflare.com/sign-up> を開く
2. メールアドレスとパスワードを決めて登録する
3. 届いたメールのリンクを押して、メールアドレスを確認する

> 💡 **Cloudflare（クラウドフレア）とは**
> Webサイトを置いておく場所を貸してくれる会社です。個人が小さく使うぶんには無料で、
> クレジットカードの登録も要りません。今回は「アプリの置き場所」「予定の保管庫」
> 「1分ごとの時計番（通知を送る係）」をここにお願いします。

---

## ② GitHub のリポジトリをつないで公開する

1. 左のメニューから **「Compute (Workers)」**（または「Workers & Pages」）を開く
2. **「Create」**（作成）→ **「Import a repository」**（Gitから取り込む）を選ぶ
3. GitHub との連携を許可する（初回のみ。GitHubのログインを求められます）
4. リポジトリ **`gamigamiigami/Workspace`** を選ぶ
5. 設定を次のようにする

   | 項目 | 入れる値 |
   |---|---|
   | Project name（名前） | `pocket-hisho` |
   | Production branch（公開に使う枝） | `claude/new-tool-creation-klodhg` |
   | **Root directory（フォルダ）** | **`projects/pocket-hisho`** ← ここが大事 |
   | Build command（組み立て命令） | 空のまま |
   | Deploy command（公開命令） | `npx wrangler deploy` |

6. **「Deploy」**（公開）を押す
7. 1〜3分待つ。成功すると **`https://pocket-hisho.〇〇.workers.dev`** のようなURLが出ます。
   **これがアプリのアドレスです。**

> ⚠️ **Root directory を `projects/pocket-hisho` にするのを忘れないでください。**
> このリポジトリには他のプロジェクトも入っているので、これを指定しないと
> 「ファイルが見つかりません」というエラーになります。

> 💡 **このとき自動で起きること**
> 公開の途中で「`pocket-hisho` という名前のデータの保管庫（D1）」が自動で作られ、
> アプリとつながります。表（予定・やること・通知の宛先などを入れる引き出し）は、
> アプリがはじめて動いたときに自動で作ります。**伊神さんがやることはありません。**

> 💡 **workers.dev の名前を聞かれたら**
> はじめて Workers を使うアカウントでは、URLの「〇〇」の部分（サブドメイン）を
> 決める画面が出ることがあります。英小文字で好きな名前を入れてください（例：`igami`）。

---

## ③ URLを開いて、合言葉を決める（公開したら、すぐに）

1. ②でできたURLを、パソコンのブラウザで開く
2. **「はじめての合言葉」** という画面が出るので、合言葉を2回入れて「この合言葉で始める」
3. アプリの画面に入れたら完了です

> 🔑 **合言葉の決め方**
> ・**8文字以上**（10文字以上がおすすめ）
> ・例：`osaka-semi-2026-kato` のように、覚えやすい単語をハイフンでつなぐ形
> ・誕生日や電話番号は使わない
> ・**講師の方には伝えなくて大丈夫です**（④の招待リンクで入れるため）。
>   伊神さん自身が、別のパソコンから入るときに使います。

> ⚠️ **なぜ「すぐに」なのか**
> 合言葉は「**そのURLを最初に開いた人**」が決める仕組みです（合言葉をGitHubに書かずに
> 済ませるため）。URLはまだ誰にも知られていないので心配はほぼありませんが、
> 念のため、公開したらすぐに開いて決めてください。
> もし最初に開いたのに「合言葉を入れてください」の画面が出たら、下の「うまくいかないとき」を見てください。

---

## ④ 講師の方に招待リンクを送る

③でアプリに入ると、**「はじめの準備」という画面が自動で開きます。** 上から順に進めるだけです。

1. いちばん上の **「招待リンクを作る」** を押す
2. **「LINEで送る」** を押し、講師の方を選んで送る
   （LINEを使わないときは「リンクをコピーする」でメールなどに貼ってもOK）

> 💡 **招待リンクについて**
> ・リンクを開くだけで入れます（**合言葉は要りません**）
> ・**14日間**使えます。講師の方が機種変更したときなどは、⚙設定 →「講師の方を招待する」で
>   作り直せます（作り直すと、前のリンクは使えなくなります）
> ・リンクを他の人に見せないようにしてください（見た人も入れてしまうため）

「はじめの準備」は、あとから **⚙設定 →「🚀 はじめの準備をひらく」** でいつでも開けます。

## ⑤ 講師の方がやること（アプリが案内します）

講師の方には、LINEで「届いたリンクを開いて、画面の案内どおりに進めてください」と
一言添えるだけで大丈夫です。リンクを開くと、アプリが**その人のスマホに合わせた手順**を出します。

### iPhone の場合（アプリが出す案内）

```text
1. LINEのリンクをタップ → Safari で開く（ふつうは自動でSafariに切りかわります。
   LINEの中で開いてしまったときは、アプリが「Safariで開いて」と案内します）
2. 「はじめの準備」が出るので、書いてあるとおりに
     共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. ホーム画面にできた「ポケット秘書」のアイコンから開く
     → 自動でログインした状態になります
4. 「通知をオンにする」を押して「許可」
     → テスト通知が自動で届きます。届けば完了
5. （任意）「iPhoneのカレンダーに表示」を押して「照会」
```

> 💡 **自動でやっていること**
> ・iPhoneでは、Safari と「ホーム画面のアイコン」でデータの置き場所が別になるため、
>   ふつうはもう一度ログインが必要です。このアプリは、Safariの画面にある**6けたの番号を
>   アイコンに自動で渡す**ので、講師の方は何も入れずに入れます。
>   （うまく渡らなかったときだけ「6けたの番号」を聞かれます。Safariの画面に大きく出ています）
> ・通知をオンにした直後に、テスト通知を自動で送ります
> ・通知の登録が消えていたら、アプリを開いたときに何もしなくても登録し直します

> ⚠️ **iPhone は iOS 16.4 以降が必要です**（通知の仕組みがそれ以降にしかないため）。
> 設定 → 一般 → 情報 →「iOSバージョン」で確かめられます。

### Android の場合

```text
1. LINEのリンクをタップ → Chrome で開く
2. 「はじめの準備」の「ホーム画面に追加する」ボタンを押す（または ︙ →「ホーム画面に追加」）
3. 「通知をオンにする」→「許可」→ テスト通知が届けば完了
4. （任意）「Googleカレンダーに表示」を押して「追加」
```

### パソコンから使う場合

URLを開いて合言葉を入れるだけです。ブックマークしておくと便利です。

## カレンダーとつなぐ（あとからでOK）

### アプリの予定を、いつものカレンダーに出す

アプリの ⚙設定 →「カレンダーに表示する」のボタンを押すだけです。

- **iPhoneのカレンダーに表示** → 開いた画面で「照会」
- **Googleカレンダーに表示** → 開いた画面で「追加」

> ⚠️ **Googleカレンダーは反映が遅いです（数時間〜24時間）。**
> これはGoogle側の仕様で、こちらでは変えられません。
> **急ぎのお知らせは、このアプリの通知が担当します**ので、実害はありません。

### Googleカレンダーの予定を、アプリに取り込む（パソコンでやるのがかんたん）

1. パソコンでGoogleカレンダーを開き、[設定] → 左の一覧から取り込みたいカレンダーを選ぶ
2. 下のほうの **「カレンダーの統合」** を開く
3. **「シークレット アドレス（iCal 形式）」** をコピー
4. アプリの ⚙設定 →「🔧 くわしい設定」→「ほかのカレンダーの予定を、アプリに取り込む」に
   貼りつけて「保存して、いま取り込む」

> 🔒 このアドレスは**パスワードと同じ**くらい大事です。人に見せないでください。
> 万一もれたら、Googleカレンダーの同じ画面の「リセット」で作り直せます。

## うまくいかないとき

| 症状 | 見るところ・やること |
|---|---|
| 公開（Deploy）が失敗する | Root directory が `projects/pocket-hisho` になっているか |
| 失敗の画面に「D1」「database」の文字がある | 保管庫の自動作成がうまくいかなかった可能性があります。左のメニュー **「Storage & Databases」→「D1 SQL Database」→「Create」** で、名前を **`pocket-hisho`**（このとおり）にして作り、②の画面で公開をやり直してください。同じ名前の保管庫があれば、自動でそれにつながります |
| 最初に開いたのに「合言葉を入れてください」と出る（自分で決めた覚えがない） | 他の人が先に決めた可能性があります。下の「合言葉を決め直す」の**方法B**でやり直してください |
| 講師の方が「この招待リンクは使えません」と言われる | 期限切れ（14日）か、作り直して前のリンクになった。⚙設定 →「講師の方を招待する」で新しいリンクを送る |
| 講師の方が「しばらく試せません」と言われる | 合言葉か番号を8回まちがえて、15分止まっています。伊神さんの端末で ⚙設定 → くわしい設定 →「別の端末の『入れません』を解除する」 |
| 通知が来ない | アプリの「はじめの準備」を開くと、何が足りないかが出ます。iPhoneは「ホーム画面のアイコンから開いているか」「iOS 16.4以降か」 |

**どれに当てはまるか分からないときは、画面に出ているエラーの文字をそのまま私に送ってください。**

### 合言葉を決め直す（忘れたとき・他の人に決められたとき）

**方法A：Cloudflare 側で決める（合言葉を忘れたとき。かんたん）**

1. Cloudflare の `pocket-hisho` → **「Settings」** → **「Variables and Secrets」**
2. **「Add」** で、Type を **Secret**、名前を `APP_PASS`、中身を新しい合言葉にして保存
3. これで、アプリの合言葉は `APP_PASS` のほうになります（画面で決めたものより優先）

**方法B：はじめからやり直す（他の人に決められたとき・スマホをなくしたときなど、
ほかの端末のログインもすべて消したいとき）**

> 方法Aでは、すでにログインしている端末はそのまま使えてしまいます。
> 知らない人を確実に締め出したいときは、こちらを使ってください。

1. 左のメニュー **「Storage & Databases」→「D1 SQL Database」→ `pocket-hisho`** を開く
2. **「Console」**（コンソール）タブで、次の3行を**1行ずつ**貼りつけて実行する

   ```sql
   DELETE FROM kv WHERE k = 'pass';
   DELETE FROM sessions;
   DELETE FROM subs;
   ```

   （1行目＝合言葉を消す／2行目＝すべての端末をログアウト／
   3行目＝通知の宛先を消す。なくしたスマホに予定の通知が届き続けないように）
3. アプリのURLを開くと「はじめての合言葉」の画面に戻ります（**予定のデータは消えません**）
4. すべての端末がログアウトされるので、講師の方には招待リンクを送り直してください。
   通知の宛先は、ログインし直してアプリを開いたときに自動で登録し直されます

> ※ 方法Aで `APP_PASS` を登録している場合は、画面の合言葉ではなく `APP_PASS` のままになります。

## 運用のめやす

| 項目 | 無料枠 | このアプリの使用量の見込み |
|---|---|---|
| Worker の実行回数 | 10万回／日 | 1分ごとの見回りで **1,440回/日** ＋ 操作ぶん。**じゅうぶん収まります** |
| D1 の保存容量 | 5GB | 予定1件が約2KB。**1万件入れても20MB** |
| D1 の読み取り | 500万行／日 | 見回り1回で数十行。**問題ありません** |

**お金がかかることはありません。** 無料プランのまま使う限り、勝手に課金されることはありません
（無料枠を超えた日は、その日だけ動きが止まる仕組みです）。

## 困ったときの連絡先メモ

- **Cloudflare のダッシュボード**：<https://dash.cloudflare.com>

- **通知が来ない**：アプリの ⚙設定 →「テスト通知を送る」でまず確認。
  届かなければ、端末の設定でこのアプリの通知が許可されているか確認してください
