# ポケット秘書 セットアップ手順

**この手順でかかるお金：0円**（Cloudflare の無料枠だけで動きます。クレジットカードの登録も不要です）
**かかる時間の目安：20〜30分**（はじめての方の場合）＋ Googleカレンダーとつなぐ準備（⑦）に30分

---

## ⚠️ 先に読んでください

この手順は、**私（Claude）が実際に Cloudflare・Google Cloud のアカウントを操作して確かめたものではありません。**
アプリの動きは手元で全部テストしましたが、Cloudflare の画面の文言やボタンの位置は、
時期によって少し変わることがあります。

**「手順書どおりのボタンが見つからない」ときは、止めて私に聞いてください。**
画面に出ている文字をそのまま教えてもらえれば、その場で調べ直します。

## 全体の流れ

```text
  ① Cloudflare の無料アカウントを作る                        5分
  ② 保管庫（D1）を作って、ID をコピーする                     3分
  ③ ID を設定ファイルに書く（Claude に送るだけでもOK）          2分
  ④ GitHub とつないで公開する → アプリのURLができる           10分
  ⑤ URLを開いて合言葉を決める（公開したら、すぐに）             1分
  ⑥ 招待リンクを作って、講師の方にLINEで送る                   1分
  ⑦ Googleカレンダーとつなぐ準備（Google Cloud・無料）          30分
  ─────────────────────────────────────────
  ⑧ 講師の方：リンクを開いて、アプリの案内どおりに進める
         （最後に「Googleカレンダーとつなぐ」を押す）
```

**①〜⑦は全部パソコンのブラウザだけでできます。** ソフトのインストールは要りません。
各手順の最後に **「✅ こうなればOK」** を書いてあります。そうならなかったら、そこで止めて聞いてください。

## ① Cloudflare の無料アカウントを作る（5分）

1. <https://dash.cloudflare.com/sign-up> を開く
2. **Email**（メールアドレス）と **Password**（パスワード）を入れて **「Sign up」**（登録）
3. 届いたメールの **「Verify email」**（確認）のリンクを押す
4. 「何に使いますか」のような質問が出たら、**「Skip」**（とばす）か、いちばん近いものを選んで進む
5. 料金プランを聞かれたら **「Free」**（無料）を選ぶ。クレジットカードは入れない

✅ **こうなればOK：** 左側にメニューが縦に並んだ画面（ダッシュボード）が出る

> 💡 **Cloudflare（クラウドフレア）とは**
> Webサイトを置いておく場所を貸してくれる会社です。個人が小さく使うぶんには無料です。
> 今回は「アプリの置き場所」「予定の保管庫」「1分ごとの時計番（通知を送る係）」をお願いします。

## ② 保管庫（D1）を作って、ID をコピーする（3分）

「保管庫」は、予定・やること・設定をしまっておく場所です。

1. 左のメニューから **「Storage & databases」**（保管と データベース）を開き、
   **「D1 SQL database」** を押す
   （見当たらなければ、画面上の検索窓に `D1` と入れる）
2. **「Create Database」**（または「+ Create」）を押す
3. **Name**（名前）に **`pocket-hisho`** と入れる（このとおり。ハイフンは半角）
   - Location（場所）などの他の欄は、**さわらずそのまま**でOK
4. **「Create」**（作成）を押す
5. できた保管庫の画面に **Database ID** という欄があり、
   `a1b2c3d4-5678-90ab-cdef-1234567890ab` のような **ハイフン入りの長い英数字** が出ています。
   **これをコピーして、メモ帳に貼っておく**

✅ **こうなればOK：** メモ帳に「8けた-4けた-4けた-4けた-12けた」の英数字が貼れている

> 💡 **なぜここだけ手で作るのか**
> ④の「自動で公開する仕組み」には、保管庫を新しく作る権限が付いていないためです
> （Cloudflare の資料で確認）。作ってしまえば、表（引き出し）はアプリが自動で作ります。

## ⑦ Googleカレンダーとつなぐ準備（Google Cloud・無料・30分）

これをすると、**アプリ・Googleカレンダー・iPhoneのカレンダーの予定が1つにまとまります。**

| 予定を入れた場所 | アプリへ | Googleへ | iPhoneのカレンダーへ |
|---|---|---|---|
| アプリ | ― | **数秒** | iPhoneが取りに来たとき※ |
| Googleカレンダー | **1分以内**（アプリを開けばその場で） | ― | iPhoneが取りに来たとき※ |
| iPhoneのカレンダー（Googleアカウント） | **1分以内** | **数秒** | ― |

※ Google → iPhone の取りこみだけは Apple 側のタイミング（カレンダーを開いたとき・15分ごとなど）です。

ここでは、アプリが講師の方のGoogleカレンダーに書きこむための**「身分証（クライアントID）」**を、
Googleの開発者向けの管理画面（**Google Cloud**）で作ります。**伊神さんが1回だけ**やる作業です。

> 💰 **お金はかかりません。** Google Calendar API（カレンダーを読み書きする仕組み）は無料です。
> ⚠️ 画面に **「無料トライアルを開始」「無料で開始」** などが出ても**押さないでください**
> （クレジットカードの登録を求められます。この作業にはカードは要りません）。

> 🔑 途中で出てくる **「クライアント シークレット」は合言葉と同じくらい大事**です。
> Claude（私）にも送らず、アプリの画面に直接貼ってください。

### ⑦-1 Google Cloud を開く

1. パソコンで <https://console.cloud.google.com/> を開く（**伊神さんのGoogleアカウント**でOK）
2. はじめてのときは「国」（日本）を選び、利用規約に同意して「同意して続行」

### ⑦-2 プロジェクトを作る

1. 画面の上のほうにある **「プロジェクトを選択」**（またはプロジェクト名が出ている欄）を押す
2. **「新しいプロジェクト」** を押す
3. プロジェクト名に `pocket-hisho` と入れて **「作成」**
4. できたら、画面上の欄が `pocket-hisho` になっているか確かめる（なっていなければ選ぶ）

### ⑦-3 カレンダーの機能をオンにする

1. 画面上の検索欄に `Google Calendar API` と入れて、出てきた **「Google Calendar API」** を押す
2. **「有効にする」** を押す

### ⑦-4 アプリの名札（同意画面）を作る

1. 左上の **≡（メニュー）→「Google Auth Platform」** を開く（見当たらなければ検索欄に `Google Auth Platform`）
2. **「開始」**（または「使ってみる」）を押す
3. 次のように入れて進める

   | 画面 | 入れるもの |
   |---|---|
   | アプリ情報 | アプリ名 `ポケット秘書`／ユーザー サポートメール：伊神さんのメール →「次へ」 |
   | 対象 | **「外部」** →「次へ」 |
   | 連絡先情報 | 伊神さんのメール →「次へ」 |
   | 終了 | ポリシーに同意するチェック →「続行」→「作成」 |

### ⑦-5 「本番環境」に公開する（ここが大事）

1. 左の **「対象」** を開く
2. 「公開ステータス」が **「テスト中」** になっているので、**「アプリを公開」** →「確認」
3. **「本番環境」** になればOK

> ⚠️ **「テスト中」のままだと、7日ごとにGoogleとのつながりが切れます。** 必ず「本番環境」にしてください。
> 「確認（審査）が必要です」のような表示が出ても、**審査は申し込まなくて大丈夫です**
> （使う人が100人までなら、審査なしで使えます。そのかわり、講師の方がつなぐときに
> 「このアプリは Google で確認されていません」という画面が1回出ます）。

### ⑦-6 身分証（クライアント）を作る

1. 先にアプリを開き、⚙設定（または「はじめの準備」）の **「Googleカレンダー」** の欄にある
   **リダイレクトURI**（`https://pocket-hisho.〇〇.workers.dev/api/google/callback`）の **「コピー」** を押しておく
2. Google Cloud に戻り、左の **「クライアント」** →「**クライアントを作成**」
3. 次のように入れる

   | 欄 | 入れるもの |
   |---|---|
   | アプリケーションの種類 | **「ウェブ アプリケーション」** |
   | 名前 | `pocket-hisho`（なんでもOK） |
   | **承認済みのリダイレクト URI** | 「URI を追加」を押して、1でコピーしたものを貼る |

   ⚠️ 「承認済みの JavaScript 生成元」ではなく、その下の **「承認済みのリダイレクト URI」** です。
4. **「作成」** を押す

### ⑦-7 すぐに2つをアプリに貼る

1. 作成した直後の画面に **「クライアント ID」** と **「クライアント シークレット」** が出ます
   - ⚠️ **シークレットは、この画面でしか見られません。** 閉じる前にアプリへ貼ってください
     （「JSON をダウンロード」で保存しておくのも安心です）
2. アプリの ⚙設定（または「はじめの準備」）→ **「Googleカレンダー」** の欄に
   **クライアントID** と **クライアントシークレット** を貼って **「保存する」**

✅ **こうなればOK：** 「このボタンは、講師の方のスマホで押してもらうものです」と出る

> 💡 シークレットをなくしたら：Google Cloud の「クライアント」→ 作ったものを開く →
> 「シークレットを追加」で新しいものを作り、アプリに貼り直せばOKです。

### ⑦-8 講師の方に伝える

「アプリを開いて、『Googleカレンダーとつなぐ』を押してください」と伝えるだけです。
アプリの「はじめの準備」にも、その手順（警告画面の進み方も）が出ます。

> ⚠️ **伊神さんのスマホ・パソコンでは「Googleカレンダーとつなぐ」を押さないでください。**
> 伊神さんのGoogleでつなぐと、伊神さんのカレンダーの予定が講師の方のアプリに入ってしまいます。

```text
・別のタブでポケット秘書のアプリ（https://pocket-hisho.〇〇.workers.dev）を開いて、ログイン済みです。

【絶対に守ること】
・お金がかかる操作は一切しない。「無料トライアルを開始」「無料で開始」「お支払い」「請求先アカウント」は押さない。
  クレジットカードは入力しない。求められたら、そこで止めて私に聞く。
・すでにある他のプロジェクトや設定は変えない。
・クライアントシークレットは、ポケット秘書の入力欄に貼る以外、どこにも書かない（返事やメモにも出さない）。
・ポケット秘書の「Googleカレンダーとつなぐ」ボタンは押さない。
・画面がこの説明とちがうとき、迷ったときは、進めずに私に聞く。

【手順】
1. ポケット秘書のタブで右上の ⚙（設定）を開き、「Googleカレンダー」の欄にある
   「リダイレクトURI」（/api/google/callback で終わるもの）を読み取る。
2. https://console.cloud.google.com/ を開き、新しいプロジェクト「pocket-hisho」を作って、それを選ぶ。
3. 「Google Calendar API」を有効にする。
4. 「Google Auth Platform」を開始する。アプリ名「ポケット秘書」、ユーザーサポートメールと連絡先は私のメール、
   対象は「外部」。ポリシーに同意して作成する。
5. 「対象」で公開ステータスを「本番環境」にする（「アプリを公開」）。審査（確認）の申し込みはしない。
6. 「クライアント」→「クライアントを作成」。種類は「ウェブ アプリケーション」、名前は「pocket-hisho」。
   「承認済みのリダイレクト URI」に、1で読み取ったURIを追加して作成する
   （「承認済みの JavaScript 生成元」ではない）。
7. 作成直後に出るクライアントIDとクライアントシークレットを、その画面を閉じる前に、
   ポケット秘書のタブの ⚙設定 →「Googleカレンダー」の欄の「クライアントID」「クライアントシークレット」に貼り、
   「保存する」を押す。
8. 「このボタンは、講師の方のスマホで押してもらうものです」と出たら完了。
9. 最後に、やったことを箇条書きで報告する（シークレットは書かない）。
```

**伊神さんがやること：** Claude が「これを押してよいですか」と聞いてきたら、中身を見て「許可」を押す。
Google のログインやパスワードを聞かれたら、自分で入れる。おかしいと思ったら、Claude の画面の **停止** を押す。

✅ **こうなればOK：** ポケット秘書の設定に「このボタンは、講師の方のスマホで押してもらうものです」と出ている

> 💡 拡張機能も画面を見て動くので、シークレットは Claude に見えます。そのかわり、チャットに書き残さず、
> アプリに**直接**貼らせるようにしています。

## ⑧ 講師の方がやること（アプリが案内します）

講師の方には、LINEで「届いたリンクを開いて、画面の案内どおりに進めてください」と
一言添えるだけで大丈夫です。リンクを開くと、アプリが**その人のスマホに合わせた手順**を出します。

### iPhone の場合（アプリが出す案内）

```text
1. LINEのリンクをタップ → Safari で開く（ふつうは自動でSafariに切りかわります。
   LINEの中で開いてしまったときは、アプリが「Safariで開いて」と案内します）
2. 「はじめの準備」が出るので、書いてあるとおりに
     共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. ホーム画面にできた「ポケット秘書」のアイコンから開く
     → 自動でログインした状態になります
4. 「通知をオンにする」を押して「許可」
     → テスト通知が自動で届きます
5. 「Googleカレンダーとつなぐ」を押す（⑦がすんでいるとき）
     → いつものGoogleアカウントを選ぶ
     →「このアプリは Google で確認されていません」と出たら「詳細」→「ポケット秘書（安全ではないページ）に移動」
     →「カレンダーの予定の表示と編集」にチェック →「続行」
     →「つながりました」と出たら、その画面を閉じてアプリに戻る。これで完了
```

> 💡 **iPhoneのカレンダーにも出すには**：iPhoneの「設定」→「カレンダー」→「アカウント」に
> **Google** が入っていれば、そのまま出ます（入っていなければ「アカウントを追加」→「Google」）。
> iPhoneのカレンダーで予定を入れるときは、**Googleのカレンダーを選んで**入れてください
> （「iCloud」のカレンダーに入れた予定は、Googleにもアプリにも入りません）。

> 💡 **自動でやっていること**
> ・iPhoneでは、Safari と「ホーム画面のアイコン」でデータの置き場所が別になるため、
>   ふつうはもう一度ログインが必要です。このアプリは、Safariの画面にある**6けたの番号を
>   アイコンに自動で渡す**ので、講師の方は何も入れずに入れます。
>   （うまく渡らなかったときだけ「6けたの番号」を聞かれます。Safariの画面に大きく出ています）
> ・通知をオンにした直後に、テスト通知を自動で送ります
> ・通知の登録が消えていたら、アプリを開いたときに何もしなくても登録し直します

> ⚠️ **iPhone は iOS 16.4 以降が必要です**（通知の仕組みがそれ以降にしかないため）。
> 設定 → 一般 → 情報 →「iOSバージョン」で確かめられます。

### Android の場合

```text
1. LINEのリンクをタップ → Chrome で開く
2. 「はじめの準備」の「ホーム画面に追加する」ボタンを押す（または ︙ →「ホーム画面に追加」）
3. 「通知をオンにする」→「許可」→ テスト通知が届く
4. 「Googleカレンダーとつなぐ」を押す（iPhoneの5と同じ）
```

### パソコンから使う場合

URLを開いて合言葉を入れるだけです。ブックマークしておくと便利です。

## Googleとつながないときだけ：購読でカレンダーに出す（前のやり方）

⑦の「Googleカレンダーとつなぐ」を使うなら、**この章は読まなくて大丈夫です**
（つなぐと、アプリの設定からこのボタンは消えます。両方使うと、同じ予定が2つずつ出ます）。

### アプリの予定を、いつものカレンダーに出す

**講師の方のスマホで**、アプリの ⚙設定 →「カレンダーに表示する」のボタンを押します。

- **ふだん見ている方を1つだけ**押す（両方押すと、同じ予定が2つずつ出ることがあります）
  - **iPhoneのカレンダーに表示** → 開いた画面で「照会」
  - **Googleカレンダーに表示** → 開いた画面で「追加」
- **やるのは最初の1回だけです。** あとはアプリで予定を入れたり直したりするたびに、
  カレンダーのほうが自動で見に来て並べ直します（毎回ボタンを押す必要はありません）
  - iPhone：15分〜1時間ほどで反映（アプリから「15分ごとに見に来て」とお願いしています）
  - Google：数時間〜1日ほどで反映
- ⚠️ **伊神さんのスマホでは押さないでください。** 講師の方の予定が、伊神さんのカレンダーに並んでしまいます

> 💡 **なぜ最初の1回はボタンが要るのか**
> スマホのカレンダーに新しいカレンダーを足すことは、本人の操作が無いとできない決まりになっています
> （アプリが勝手に足せると、知らないうちに予定を書きこまれてしまうため）。

> ⚠️ **Googleカレンダーは反映が遅いです（数時間〜24時間）。**
> これはGoogle側の仕様で、こちらでは変えられません。
> **急ぎのお知らせは、このアプリの通知が担当します**ので、実害はありません。

### Googleカレンダーの予定を、アプリに取り込む（パソコンでやるのがかんたん）

1. パソコンでGoogleカレンダーを開き、[設定] → 左の一覧から取り込みたいカレンダーを選ぶ
2. 下のほうの **「カレンダーの統合」** を開く
3. **「シークレット アドレス（iCal 形式）」** をコピー
4. アプリの ⚙設定 →「🔧 くわしい設定」→「ほかのカレンダーの予定を、アプリに取り込む」に
   貼りつけて「保存して、いま取り込む」

> 🔒 このアドレスは**パスワードと同じ**くらい大事です。人に見せないでください。
> 万一もれたら、Googleカレンダーの同じ画面の「リセット」で作り直せます。

## うまくいかないとき

| 症状 | 見るところ・やること |
|---|---|
| Googleの画面に **「redirect_uri_mismatch」** と出る | ⑦-6 のリダイレクトURIが、アプリに出ているものと1文字でもちがう。アプリの「コピー」を使って貼り直す（`https://` や最後の `/callback` まで同じに） |
| Googleの画面に **「アクセスをブロック」「テスト中」「確認プロセスを完了していません」** と出る | ⑦-5 の「本番環境」への公開がまだ。「対象」→「アプリを公開」 |
| Googleの画面に **「このアプリは Google で確認されていません」** と出る | 正常です。「詳細」→「ポケット秘書（安全ではないページ）に移動」で進む |
| アプリに **「Googleとのつながりが切れました」** と出る | 講師の方がGoogleの設定で許可を取り消した、または⑦-5がまだ「テスト中」。講師の方のスマホで「もう一度つなぐ」 |
| 予定が2つずつ出る | 前に「iPhoneのカレンダーに表示」「Googleカレンダーに表示」で購読していた。iPhoneは「設定」→「カレンダー」→「アカウント」→「照会するカレンダー」から、Googleは左の一覧の「ポケット秘書」→「登録を解除」で消す |
| 失敗の画面に「D1」「database」「Authentication error」の文字がある | ③の ID が書きこまれていないか、まちがっている。`wrangler.toml` の `database_id = "…"` が②の Database ID と同じか確かめる |
| 失敗の画面に「name」「does not match」の文字がある | ④の Project name が `pocket-hisho` になっていない。Worker を消して作り直すのがかんたん |
| 失敗の画面に「wrangler.toml」「not found」「Could not find」の文字がある | Root directory が `projects/pocket-hisho` になっていないか、枝が `claude/new-tool-creation-klodhg` になっていない。Settings → Build で直して公開し直す |
| 最初に開いたのに「合言葉を入れてください」と出る（自分で決めた覚えがない） | 他の人が先に決めた可能性があります。下の「合言葉を決め直す」の**方法B**でやり直してください |
| 講師の方が「この招待リンクは使えません」と言われる | 期限切れ（14日）か、作り直して前のリンクになった。⚙設定 →「講師の方を招待する」で新しいリンクを送る |
| 講師の方が「しばらく試せません」と言われる | 合言葉か番号を8回まちがえて、15分止まっています。伊神さんの端末で ⚙設定 → くわしい設定 →「別の端末の『入れません』を解除する」 |
| 通知が来ない | アプリの「はじめの準備」を開くと、何が足りないかが出ます。iPhoneは「ホーム画面のアイコンから開いているか」「iOS 16.4以降か」 |

**どれに当てはまるか分からないときは、画面に出ているエラーの文字をそのまま私に送ってください。**

### 合言葉を決め直す（忘れたとき・他の人に決められたとき）

**方法A：Cloudflare 側で決める（合言葉を忘れたとき。かんたん）**

1. Cloudflare の `pocket-hisho` → **「Settings」** → **「Variables and Secrets」**
2. **「Add」** で、Type を **Secret**、名前を `APP_PASS`、中身を新しい合言葉にして保存
3. これで、アプリの合言葉は `APP_PASS` のほうになります（画面で決めたものより優先）

**方法B：はじめからやり直す（他の人に決められたとき・スマホをなくしたときなど、
ほかの端末のログインもすべて消したいとき）**

> 方法Aでは、すでにログインしている端末はそのまま使えてしまいます。
> 知らない人を確実に締め出したいときは、こちらを使ってください。

1. 左のメニュー **「Storage & Databases」→「D1 SQL Database」→ `pocket-hisho`** を開く
2. **「Console」**（コンソール）タブで、次の3行を**1行ずつ**貼りつけて実行する

   ```sql
   DELETE FROM kv WHERE k = 'pass';
   DELETE FROM sessions;
   DELETE FROM subs;
   ```

   （1行目＝合言葉を消す／2行目＝すべての端末をログアウト／
   3行目＝通知の宛先を消す。なくしたスマホに予定の通知が届き続けないように）
3. アプリのURLを開くと「はじめての合言葉」の画面に戻ります（**予定のデータは消えません**）
4. すべての端末がログアウトされるので、講師の方には招待リンクを送り直してください。
   通知の宛先は、ログインし直してアプリを開いたときに自動で登録し直されます

> ※ 方法Aで `APP_PASS` を登録している場合は、画面の合言葉ではなく `APP_PASS` のままになります。

## 運用のめやす

| 項目 | 無料枠 | このアプリの使用量の見込み |
|---|---|---|
| Worker の実行回数 | 10万回／日（アカウント全体） | 1分ごとの見回りで **1,440回/日**（テスト用も作ると2つで2,880回）＋ 操作ぶん。**じゅうぶん収まります** |
| D1 の保存容量 | 5GB | 予定1件が約2KB。**1万件入れても20MB** |
| D1 の読み取り | 500万行／日 | 見回り1回で数十行。**問題ありません** |
| Google Calendar API | 無料（個人で使う量なら上限に届かない） | 1分ごとの同期で **約1,500回/日**。上限は1分あたりの回数で決まっていて、1分に数回しか使わない |

**お金がかかることはありません。** 無料プランのまま使う限り、勝手に課金されることはありません
（無料枠を超えた日は、その日だけ動きが止まる仕組みです）。
