# semiretire Skill

## Overview
副業・販売物・収益化に関わるプロジェクトを作る際のコンテキスト。

## When to use
- 副業用ツール・販売ページを作るとき
- イベント集客・運営ツールを作るとき
- 収益化・販売を意識した設計をするとき

## 目標

- **最終目標**: 教師を辞めて副業＋アルバイトのみで生活
- **副業月収目標**: 月10万円
- **期限**: 5年以内（〜2031年）

## 副業の現状

| 活動 | 状況 |
|---|---|
| ボードゲーム会 | 月約1.5万円（稼働中） |
| リアル脱出ゲーム | 準備中 |
| 教員向けツール販売 | 検討中 |

## 設計上の注意点

- **スマホ対応必須**（移動中・イベント当日の使用を想定）
- 仕組み化・自動化・時短につながる設計を意識する
- 集客・販売を意識したUIにする（チープに見せない）
