# note-writer: 売れるnote記事の達人スキル

最終更新：2026-05-24（リサーチベース）

> **使用前提**：このスキルを使うときは [knowledge/persona.md](../../../knowledge/persona.md) のペンネーム・NGリスト、[knowledge/sns-playbook.md](../../../knowledge/sns-playbook.md) の文体方針、[knowledge/pdca-kpi.md](../../../knowledge/pdca-kpi.md) のKPIを必ず参照する。

---

## 0. このスキルの使い方

noteまたは類似デジタルコンテンツ（ブログ・有料マガジン・Tips等）の記事を制作するときに参照する。

実行する作業：
1. 記事テーマからペルソナ・型を選定（§1）
2. SEOタイトルを5案出して最良を選ぶ（§2）
3. 構成テンプレに沿って本文を執筆（§3）
4. 無料/有料の境界線を引く（§4）
5. 価格を設定（§5）
6. サムネ指示書を作る（§6）
7. AI差別化チェック（§7）
8. 投稿前チェックリストを通す（§9）
9. 投稿後の効果測定設計（§10）

## 1. ペルソナと記事型の選定

### ペルソナ（読者）を1人に絞る原則
売れる記事は「特定の1人」に向けて書かれている。性別・年齢・職業・直面している悩みを1文で書ける状態にする。

例（教員向けの場合）：「中学校で国語を教える3〜5年目、文法（特に助動詞）の指導に毎年苦戦している先生」

### 売れる記事の7型

| 型 | 構成 | 適ジャンル | 価格レンジ |
|----|------|----------|----------|
| ① 体験談ベース型 | 失敗→気づき→学び→今こうしてる | エッセイ、教員あるある、転職体験 | 300〜980円 |
| ② 問題解決・ノウハウ型 | 悩み定義→原因→解決法→事例 | 授業技術、働き方、業務効率化 | 500〜1,800円 |
| ③ ストーリー＋学び型 | 物語→転機→教訓 | キャリア、学級経営の長期記録 | 500〜1,500円 |
| ④ リスト型（◯選） | 導入→列挙→まとめ | 教材アイデア集、便利ツール集 | 300〜980円 |
| ⑤ 比較型 | 候補A vs B→評価軸→選び方 | 教材比較、ツール比較 | 500〜1,500円 |
| ⑥ ステップ型（◯ステップで） | ゴール→手順→各論→完成 | 授業作り、教材制作プロセス | 980〜1,800円 |
| ⑦ Q&A型 | よくある質問→回答 | 教員採用、初任者の不安解消 | 500〜1,500円 |

→ 教員向けは **②④⑥** が刺さりやすい（時短ニーズ＋すぐ使える）。

## 2. SEOタイトル設計

### 鉄則

- **32文字以内**（Google検索結果の表示上限）
- **文頭にメインキーワード**（検索ハイライトでクリック率UP）
- **複合キーワード2〜3語**（単キーワードは競合が強すぎ）
- **数字＋パワーワード**（CTRが2〜4倍変わる）
- **タイトルだけでベネフィットが伝わる**

### 教員向けタイトルテンプレ

```
【YYYY年最新】{学年}{単元} {悩み解決} {型}｜{ベネフィット}
例：【2026年最新】中2助動詞ワークシート｜時短で点数UP

{悩み・失望} {解決} {ノウハウ}
例：助動詞の指導に毎年つまずく先生へ｜10年使える指導フロー

{数字} {テーマ} {誰のため} {結果}
例：5ステップで完成｜中学国語「助動詞」が定着する授業案
```

### パワーワード集（過剰でない範囲で使う）
- 完全ガイド／永久保存版／秘訣／コツ／時短
- 〜だけで／〜するだけ／秘密の／プロが使う
- 失敗しない／挫折しない／後悔しない
- 知らないと損／実は／意外と／本当は
- 2026年最新／初心者でも／中級者向け

### NG（避ける）
- 釣りタイトル（中身と食い違うとフォロワー離脱）
- 「神」「最強」など主観的・空虚なワード単独使用
- ペルソナと無関係なバズワード

### タイトルは5案出して選ぶ
1案目に固執せず必ず5案。1〜2週間後にPVを見て、伸びていなければタイトルだけリライトする。

## 3. 構成（本文）テンプレ

### 標準テンプレ（②問題解決型／②④⑥ハイブリッド）

```
1. リード（200〜400字）
   - 「こんな先生に向けて書きました」を最初に明示
   - 共感1文＋本記事を読むベネフィット
   - 続きを読みたくなる引き

2. 結論先出し（200字）
   - 「先に結論を言うと〜です」
   - 読者は時間がない。最重要メッセージを先に

3. 背景・悩みの言語化（500〜800字）
   - なぜこの悩みが起こるのか
   - 一般論ではなく、現場のリアルで書く

4. 解決法の全体像（500〜800字）
   - 大枠を図/表で見える化
   - 順序・関係性を示す

5. 各論ステップ（各400〜700字×3〜5本）
   - 具体例を必ず入れる
   - 著者の体験を1つ以上挟む

──── ペイウォール（ここで有料/無料を切る）────

6. 実践テンプレ（有料）
   - 即使えるワークシート、台本、原稿、データ等
   - コピペで動く形

7. 失敗例と回避策（有料）
   - 著者の失敗・読者からの相談ベース
   - ここが「有料の価値」の中核

8. まとめ＋次に読むべき記事（有料）

9. （任意）コメント欄での質問歓迎の呼びかけ
```

### 1見出しの長さ
- 1見出し400〜700字程度
- 1段落2〜3行（スマホで読みやすく）
- 強調は **太字** または引用（`> 〜`）を効果的に

### 画像の挟み方
- 見出しごとに1枚を目安（H2の直下）
- 画像はテキストの「目休め」と「情報補完」を兼ねる
- 教材スクショ・図解・引用画像など

## 4. 無料/有料境界線の引き方

### 鉄則：無料部分は3,500〜4,000字

これがnoteで売れる記事の定石。
- 短すぎ（〜2,000字）：「情報を得た感」が出ず購入されない
- 長すぎ（〜5,000字）：「もう満足」と離脱
- 3,500〜4,000字＝"腹八分"感

### 何を見せて何を隠すか

| 無料部分に入れるもの | 有料部分に入れるもの |
|--------------------|--------------------|
| 結論（要約レベル） | 結論の実装テンプレ |
| 体験談・失敗エピソード | 失敗の具体的回避策 |
| 解決法の全体像（フレームワーク名・概念） | フレームワークの実例・手順・台本 |
| 1〜2個の小さなテクニック（試供品） | 全テクニック・チェックリスト・データ |
| 「ここまで読んで響いたら有料で全部解説」と一言 | DL可能ファイル（PDF、Word、テンプレ等） |

### ペイウォール直前の一文（重要）

ペイウォール直前に必ず「ここから先に何があるか」を箇条書きで予告する。

```
ここから先で解説するのは：
- 中2助動詞「らしい/ようだ」を区別させる5問のワークシート（PDFダウンロード可）
- 生徒がつまずく3パターン別の声かけ台本
- 単元末テスト直前の3日間スケジュール例
- 私が3年間で改良してきた板書フォーマット
```

→ これで「買う理由」が明確になる。

### ペイウォールの仕組み制約
- 1記事につきペイウォールは1本のみ（分割不可）
- ドラッグで段落境界に移動可能
- 公開後の有料/無料切り替えは慎重に

## 5. 価格設定（2026年最新）

### note公式データ（2024/12〜2025/11の30万記事分析）

**売れている記事TOP20%の価格中央値**：
- **実用系（ノウハウ・テンプレ・教材）: 1,800円**
- **読み物系（エッセイ・体験談）: 980円**

全体の9割以上は500円以下だが、売れているのは中〜高単価。
→ **「安すぎは売れない」が事実**。

### 段階的値上げ戦略（伊神向け推奨）

| フェーズ | 価格 | 目的 |
|---------|------|------|
| 第1弾（初記事） | 300円 | 試し買いハードルを下げる、最初の購入実績作り |
| 5記事目以降 | 500〜800円 | 実績がついた段階の標準価格 |
| 10記事目以降 | 980円 | 読み物系の標準ライン |
| 実用系（テンプレ・教材付き） | 1,500〜1,800円 | DLコンテンツや実装例で高単価正当化 |
| まとめパック | 2,500〜3,500円 | 既存記事3〜5本＋特典 |
| 有料マガジン月額 | 500〜1,000円 | 継続収益化、5本以上溜まったら |

### 値付けの判断軸

「相場」より「信用の増減」で考える：
- 高すぎる→失望→悪評・返金リスク（信用減）
- 安すぎる→価値が伝わらない・タダ働き（信用伸びず）
- 適正＝「読者が読了後に『この値段で得した』と感じる」点

### 段階的値上げのやり方
1. 初週は予告した価格で公開
2. 2週間で売れ行きを見る
3. 売れ行きが鈍ければタイトル/サムネをリライト
4. 売れ行きが好調なら2倍まで段階的に値上げ可（既購入者には影響なし）

### 教員向けの教材付き価格目安
- ワークシート1枚: 300〜500円
- 単元セット（5〜10枚）+ 解説: 980〜1,500円
- 学期パック（30枚＋指導案）: 2,500〜3,500円
- 年間パック: 5,000〜8,000円

## 6. サムネ・ヘッダー画像

### サイズ
- **推奨：1280×670px（16:9）**
- 高品質版：1920×1006px
- サムネ表示時は中央が正方形にクロップされる → **重要要素は中央に配置**

### デザイン原則
- 3秒で「誰向け・何の記事か」が伝わる
- 文字は太め日本語ゴシック
- 配色：白背景＋アクセント1〜2色（チープに見せない）
- 端には大事な情報を置かない（クロップで切れる）

### 必須要素（教材販売の場合）
1. メインキーワード（大きく、上半分）
2. 学年・単元（中央）
3. 形式バッジ（PDF / ワークシート / 動画付き 等）
4. 価格（任意・小さく）
5. ペンネーム（右下に小さく）

### NG
- 教室の写真（バレ防止）
- 顔写真（[persona.md](../../../knowledge/persona.md) NGリスト準拠）
- 教材スクショで個人情報・学校名が映る

### おすすめツール
- Canva（無料で十分）
- Figma（細かい調整したい人向け）

## 7. AI活用パターン（差別化を担保する）

### やってはいけない：完全AI量産
2024年3月のGoogleスパムアップデート以降、**AI生成のみのコンテンツ量産はインデックス削除リスク大**。note内検索でも上位に出にくくなる。

### 正解：AI共作モデル

1記事40分構成の例：
1. **AI（10分）**：ペルソナと型を渡してアウトラインを出させる
2. **人間（5分）**：アウトラインを自分の体験で肉付け
3. **AI（10分）**：各見出しの本文ドラフト生成
4. **人間（10分）**：体験談・具体例・現場のリアルを追記。AIっぽい言い回しを修正
5. **AI（3分）**：タイトル案5本、ペイウォール直前の一文、まとめを生成
6. **人間（2分）**：タイトル選定・最終チェック

### AI生成を「人間化」する手法
- 一人称・口調を [persona.md](../../../knowledge/persona.md) のペルソナに合わせる
- 体験を必ず1個以上入れる（「私が3年前に〜」のような具体的な記憶）
- 数字を具体化（「多くの生徒」→「30人中22人」）
- 体言止め・反語など、AIが使いがちな単調パターンを崩す
- ハイフン区切り（〜は、〜なのです、〜だからこそ、）の連続を避ける

### AIっぽさが残るNGサイン
- 「〜と言えるでしょう」「〜と考えられます」の多用
- 抽象表現の連発（「重要です」「ポイントです」）
- 各セクション末尾の同じ締め方
- 箇条書きの粒度が均一すぎる

→ 1記事につき1回は声に出して読み、機械的な箇所を手で書き直す。

### AIプロンプトのテンプレ（執筆用）

```
あなたは中学校国語教師です。下記の条件で note 記事のアウトラインを作ってください。

## ペルソナ
{persona.mdのペンネームと属性}

## 読者
中学校国語教師、教歴3〜5年目、{具体悩み}

## 記事の型
{1〜7型のどれか}

## 主張（結論）
{1文で}

## 含めたい体験
- {体験1}
- {体験2}

## 制約
- リード→結論→背景→解決→ステップ→ペイウォール→実践テンプレ
- 無料部分3,500〜4,000字想定
- 文末を「〜です」「〜ます」で統一しない（リズム重視）
- AIっぽい抽象表現禁止（「ポイント」「重要」を使わない）
```

## 8. 教員ジャンル特化ノウハウ

### 売れるテーマTOP（リサーチ＋慣行）
1. **教材・ワークシート**（即使える、時短ニーズ最強）
2. **授業案・指導案**（年度初め・単元初めに需要急増）
3. **学級経営ノウハウ**（4月・9月にPV爆発）
4. **働き方・業務効率化**（教員界隈で常時需要）
5. **保護者対応・トラブル対応**（経験談ベース、感情的共感）
6. **教員採用試験対策**（春〜夏ピーク）
7. **初任者向け**（年中需要、4月最大）

### 教員向け記事の信頼構築要素
- 「現役○年目」「○年間で○○を試した」など実績の数値
- 失敗談を出す（成功談だけだと響かない）
- 完璧主義の同業者に「私もこれくらいでいいんだ」と思わせる安心感
- すぐ使える素材を必ず1つは無料部分に

### 季節需要カレンダー（投稿タイミング）
| 月 | 高需要テーマ |
|----|-----------|
| 3月 | 新年度準備、学級開き、教材一年分 |
| 4月 | 学級経営、自己紹介、初任者向け |
| 5月 | GW明けの立て直し、保護者会対策 |
| 6月 | 単元末テスト、評価 |
| 7月 | 通知表、夏休み課題、研究授業 |
| 8月 | 二学期準備、教員採用試験 |
| 9月 | 二学期立て直し、生徒指導 |
| 10月 | 行事、合唱コン |
| 11月 | 単元末、評価 |
| 12月 | 通知表、冬休み |
| 1月 | 三学期、受験指導 |
| 2月 | 学年末、卒業 |

→ **記事は需要時期の3〜4週間前に投稿する**（SEOで上がる時間を見込む）

## 9. 投稿前チェックリスト

公開前に以下すべてを確認：

### 必須
- [ ] [persona.md](../../../knowledge/persona.md) のNGリストに違反していない
- [ ] 画像に教室・地名・本名・生徒/同僚が映り込んでいない
- [ ] タイトルが32文字以内
- [ ] タイトル文頭にメインキーワード
- [ ] 無料部分が3,500〜4,000字
- [ ] ペイウォール直前に「ここから先で解説するもの」予告がある
- [ ] 価格が今のフェーズの推奨レンジ内
- [ ] サムネが1280×670で重要要素が中央
- [ ] タグが2〜3個（過不足なし）
- [ ] 「こんな先生に向けて書きました」がリード冒頭にある
- [ ] 結論を先出ししている
- [ ] AIっぽい言い回しを手で直した

### あれば良い
- [ ] 関連する自分の他記事へのリンク（回遊狙い）
- [ ] X等のSNSアカウントへの導線
- [ ] 商品（BOOTH等）への導線

### 著作権・倫理
- [ ] 教科書本文の引用は引用範囲を超えていない
- [ ] 他者の画像・素材は出典明記またはフリー素材
- [ ] 生徒・同僚の事例は完全に一般化されている

## 10. 投稿後のPDCA

### 投稿当日
- X等でシェア（[sns-playbook.md](../../../knowledge/sns-playbook.md) の③商品宣伝型）
- noteのコメント欄に「読了感想いただけたら嬉しいです」と一言

### 1週間後
- PV、スキ、購入数を記録（[pdca-kpi.md](../../../knowledge/pdca-kpi.md) のフォーマット）
- スキ率（スキ÷PV）が3%以下なら本文を見直し
- 購入率（購入÷PV）が0.5%以下ならタイトル/サムネ/価格を見直し

### 2週間後
- 売れ行き鈍ければ：
  1. タイトル変更（最優先・効果大）
  2. サムネ変更
  3. リード文の最初の200字を書き直し
  4. 価格を1段下げる（最終手段）

### 月次（[pdca-kpi.md](../../../knowledge/pdca-kpi.md) 月次レビュー）
- 売れ筋テーマを特定→同型を増やす
- 売れない型は捨てる
- 月3本以上の投稿リズムを維持できているか確認

### リライトの判断
- 投稿後1ヶ月で目標PV/売上の50%未満 → タイトル＋サムネ全リライト
- 投稿後3ヶ月で売れていない → 内容の再構成 or 無料化して集客記事に転換

## 11. マガジン化のタイミング

単記事5本以上の販売実績ができたら有料マガジン化を検討。

### マガジン設計
- 月額500〜1,000円（読み物系）／月額1,500〜2,500円（実用系）
- 既存有料記事3〜5本＋月2本程度の新記事
- マガジン購読者限定の付録（DL素材、コミュニティ等）

### マガジンが売れる条件
- 単記事3本以上が月10部以上売れている
- フォロワーが300〜500人いる
- 同じテーマで継続的に書ける見通しがある
