# patterns Skill

## Overview
過去のプロジェクトで有効だった実装パターン集。
実装方針を決める前に確認して、車輪の再発明を防ぐ。

## When to use
- 実装を開始する前
- 「どうやって作るか」を考えているとき

## パターン一覧

詳細なコードは `knowledge/patterns.md` を読むこと。

| パターン名 | 用途 |
|---|---|
| クイズ問題のシャッフル表示 | Fisher-Yatesアルゴリズムで問題をランダム化 |
| 正解・不正解フィードバック表示 | ✓/✗ アイコン＋色で視覚的に区別 |
| スコア表示と進捗バー | 現在の問題番号・スコアの常時表示 |
| 画面遷移なしのページ切り替え | `.screen` / `.screen.active` によるSPA方式 |

## 使用手順

1. `knowledge/patterns.md` を読む
2. 使えるパターンを特定する
3. コードを実装に組み込む

## 追加ルール

- 新しいパターンが生まれたら `knowledge/patterns.md` に追記する
- 複数プロジェクトで使えると分かったものには `[汎用]` タグを付ける
