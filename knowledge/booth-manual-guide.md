# BOOTH 手動出品手順（週1回・2-3分）

BOOTHは UI が頻繁に変わるため、自動化はメンテコストが高すぎる。
AI が**コピペできる素材**を週1で生成 → あなたが2分で出品する流れ。

---

## 流れ

```
[毎週日曜 21:00 UTC 自動]
 ↓
 商品HTMLが projects/rakuda-sensei/products/ に生成される
 ↓
[同時に Issue 自動起票] ← これがリマインダーになる
 ↓
[あなたが 2-3 分で出品]
 ↓
 Issueをクローズ
```

---

## 出品手順（コピペ運用）

### 1. 生成された商品ファイルを開く

GitHub の Issue にリンクがあるので、それをクリック。
または直接：
```
projects/rakuda-sensei/products/chuN-{topic}-{date}/worksheet.html
```

### 2. ファイル冒頭の HTML コメントから情報をコピー

ファイルの先頭にこんなコメントブロックがある：

```html
<!--
BOOTH_TITLE: 中1国語「漢字・部首と画数」ワークシート - らくだ先生
BOOTH_PRICE: 300
BOOTH_DESC:
中1国語の「漢字・部首と画数」を効率よくマスターできるワークシート。
基礎5問＋応用5問＋発展5問＋解答＋採点ルーブリック付き。
B4横二つ折り両面印刷推奨。授業の小テスト・宿題・自主学習に。
教員が時短で配れる/採点できる設計。
BOOTH_TAGS: 中学国語,漢字・部首と画数,ワークシート,教員,教材
-->
```

### 3. HTML → PDF に変換

ブラウザでHTMLファイルを開く → Cmd+P（印刷） → 「PDF として保存」

### 4. BOOTHで出品

1. <https://manage.booth.pm/items/select_type> を開く
2. **「ダウンロードコンテンツ」** を選ぶ
3. フォームに記入：
   - **商品名**: `BOOTH_TITLE` をコピペ
   - **説明文**: `BOOTH_DESC` をコピペ
   - **価格**: `BOOTH_PRICE` の数字をコピペ
   - **タグ**: `BOOTH_TAGS` をカンマ区切りで貼り付け
4. **商品ファイル**: ステップ3で作ったPDFをアップロード
5. **商品画像（サムネイル）**:
   - 任意のテンプレート画像（らくだ先生キャラ＋単元名）
   - サイズ目安: 1200x630px
6. **公開する** → 出品完了

### 5. Issue をクローズ

GitHub の該当 Issue を `Close` する。

---

## サムネイル画像の作り方（簡易）

1. Canva で「BOOTH 商品サムネイル」テンプレ（1200x630）を使う
2. らくだ🐪のシンプルなアイコン＋単元名（漢字・部首と画数 等）
3. 背景はベージュ系（ブランドカラー）
4. JPG で書き出して BOOTH にアップロード

毎週同じテンプレを使い回せば 30秒で完了。

---

## なぜ自動化を諦めたか

| 試みた回数 | 結果 |
|---|---|
| 約10回 | 全部失敗 or サイレント失敗 |
| 主な障壁 | BOOTH UI 変更頻度 / SPA レンダリング / 入力欄構造変化 |
| 開発時間 | 多大 |
| 投資効果 | 月10分の手動 < 自動化のメンテコスト |

→ **賢明な撤退判断**。自動化が当たり前の時代でも、手動の方がROI高い領域はある。
