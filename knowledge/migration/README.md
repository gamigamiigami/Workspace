# Claudeアカウント移行キット

作成：2026-09-10 ／ 対象：メールアドレス変更にともなうClaudeアカウントの引っ越し

このフォルダは「新しいClaudeアカウントを、今のアカウントと同じ賢さにする」ための手順書です。
読む順番：**このREADME → checklist.md（作業）→ paste-texts.md（コピペ本文）**

---

## 大前提：あなたの資産は2か所に分かれている

```
┌─────────────────────────────┐   ┌──────────────────────────────┐
│ ① GitHub 側                  │   │ ② Claudeアカウント 側          │
│  github.com/gamigamiigami/  │   │  claude.ai のあなたのログイン内  │
│  Workspace                  │   │                              │
│                             │   │  ・個人設定（Claudeへの指示）    │
│  ・CLAUDE.md（運用ルール）    │   │  ・プロジェクトとカスタム指示     │
│  ・.claude/skills/（スキル）  │   │  ・スタイル                   │
│  ・knowledge/（知識・失敗集） │   │  ・コネクタ（GitHub連携など）    │
│  ・projects/（作った教材）    │   │  ・Claude Code の環境設定       │
│  ・.github/workflows（自動化）│   │  ・チャット履歴・Artifacts      │
│                             │   │                              │
│  → アカウントを変えても       │   │  → 新アカウントでは **空っぽ**   │
│    100% そのまま残る ✅      │   │    手で作り直すしかない ⚠️      │
└─────────────────────────────┘   └──────────────────────────────┘
```

**用語：** 「コネクタ」＝Claudeが外部サービス（GitHubなど）を読み書きするための接続設定のこと。

つまり、サポートの言う「自分でデータ移行するしかない」の対象は **②だけ** です。
①（あなたの作った教材・知識・自動化のほぼ全部）は、GitHubアカウントを変えないかぎり何もしなくても無傷で引き継がれます。

## 「チャット履歴」について（ここが一番の悩みどころ）

エクスポートで出てくるのは会話の生ログです。これを新アカウントに読み込む機能はありません。
ただし、**あなたの場合はほぼ問題ありません**。理由：

過去の会話から得た学びは、すでに毎セッション終了時のフックで
`knowledge/` の各ファイルに書き出す運用になっているからです。実際に蓄積済みなのは：

- `knowledge/details/failures.md`（12.8万字）— ハマった原因と解決策
- `knowledge/details/patterns.md`（21万字）— うまくいった実装パターン
- `knowledge/details/ui-components.md`（5.5万字）— 再利用UIパーツ
- `knowledge/mistakes.md` — あなたの明示的な訂正から作った禁止事項
- `knowledge/sales-playbook.md`（10.6万字）— 販売ノウハウ
- `knowledge/log.md` / `task-diary.md` — 作業の記録

**つまり「賢さの本体」はすでにGitHub側に移してあります。** 会話ログそのものは保険として保管すれば十分です。

それでも過去チャットに拾い残しがないか確かめたい場合 → checklist.md の「任意作業」を参照。

## 進め方（推奨の順番）

1. **旧アカウントが生きているうちに**：エクスポート＋設定の書き出し（checklist.md 手順A）
2. **メール移行**：GitHubなど外部サービスのログインメールを先に新しくする（手順B）
3. **新アカウント作成と初期設定**（手順C・paste-texts.md）
4. **動作確認**（手順D）
5. **旧アカウント解約**（手順E・確認が全部済んでから）

⚠️ **順番厳守。旧アカウントを先に消さないでください。** 消すとエクスポートも設定の確認もできなくなります。
