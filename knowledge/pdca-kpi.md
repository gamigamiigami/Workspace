## 実験別KPI

### 実験A: BOOTH 教員向け国語教材
- **リードKPI（先行指標）**：月の新規商品数、商品ページPV
- **結果KPI**：月売上、購入者数、リピート率
- **健康ライン**：3ヶ月平均で月¥3,000以上
- **撤退ライン**：3ヶ月平均で月¥1,000未満

### 実験B: note 教員向け記事
- **リードKPI**：noteフォロワー数、記事スキ数、月公開記事数
- **結果KPI**：有料記事/マガジン売上
- **健康ライン**：3ヶ月でフォロワー300人 / 月¥2,000売上
- **撤退ライン**：3ヶ月でフォロワー100未満

### 実験C: Kindle 電子書籍
- **リードKPI**：刊行数、Amazon商品ページPV、レビュー数
- **結果KPI**：月印税
- **健康ライン**：6ヶ月平均で月¥1,500以上
- **撤退ライン**：6ヶ月平均で月¥500未満

### 集客（X）
- **リードKPI**：フォロワー増数/月、月インプレッション、エンゲージメント率
- **健康ライン**：月+50フォロワー、平均エンゲージメント率1%以上

## 月次レビュー手順（毎月1日）

1. **人間**：各チャネルの売上CSV/スクショをDL → 共有フォルダに保存（[handoff.md](./handoff.md)）
2. **AI**：データを集計・分析、以下のレポートをAddnessコメントに投下：
   - 各実験の今月売上・累計売上・KPI達成率
   - 健康ライン/撤退ライン照合
   - 売れた商品TOP3、売れなかった商品ワースト3
   - 次月推奨アクション（新商品案、SNS方針、配分変更等）
3. **人間**：レポートを確認 → 翌月の方針を確定（コメントで応答）
4. **AI**：確定方針に基づいて翌月の制作・投稿計画を生成

## 判断ルール

| シグナル | アクション |
|---------|----------|
| ある実験が3ヶ月連続で健康ラインを下回る | 投下時間を1/3に縮小 |
| ある実験が3ヶ月縮小しても撤退ライン継続 | 撤退・新実験に振替 |
| ある実験が3ヶ月連続で健康ラインの2倍 | 追加投資（商品数倍増・有料広告検討） |
| 全体売上が累計目標の80%未満が2ヶ月続く | 全体戦略見直し（新チャネル追加/ペルソナ見直し） |
| 全体売上が累計目標を超過 | 高単価商品・自動化への投資を前倒し |
