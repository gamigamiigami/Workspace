# AIのミス記録

ユーザーからの明示的な訂正のうち、繰り返し起こりうるものだけを記録する。

形式：
YYYY-MM-DD: [一言で何を間違えたか]
NG: 実際にやってしまったこと
OK: 次回からの正しい対応
場面: このルールが適用される状況

---

2026-06-10: 訓読文で助動詞の読みをカタカナ送り仮名として表記した
NG: 「不」の読み「ず」を送り仮名と同じ扱いでカタカナ「ズ」にして右下に表示した
OK: 助動詞・助詞として読む字（不＝ず、之＝の、也＝なり等）は送り仮名ではないので、ひらがなで漢字の真横（右側中央）に表記する。送り仮名・助詞の補い（ヲ・ニ・ハ等）はカタカナで右下のまま
場面: 漢文・訓読文・書き下し文を扱う教材やゲームを作るとき

2026-06-10: git remoteのプロキシURLを見て「公開不可」と誤断定した

OK: この実行環境のgit remoteはプロキシ経由でGitHub本体に中継される。デプロイ不調時は憶測で「できない」と言わず、GitHub Actionsの実行履歴・ログを確認してから原因を報告する
