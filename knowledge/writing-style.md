# writing-style.md：売れる note の書き方・装飾ガイド

生成記事と推敲時に必ず参照する。
目的は「収益を上げる note の自動運用」と「AI 投稿バレ防止」の両立。

---

## 1．AI バレを防ぐ大原則

### 使わない表現

- 「実は」「結論から言うと」「ポイントは」「重要なのは」（定型句）
- 「全部わかる」「絶対」「ガラッと変わる」「ぶっちゃけ」（大袈裟）
- 「〜と言えるでしょう」「〜と考えられます」（語尾を曖昧にして責任回避）
- 「メリット・デメリット」（コピペ感）
- 体言止めを連続させる
- 各章の終わりを同じ締めにする（「〜していきましょう」連発）

### 入れるもの

- 著者個人の数字（5年で2,000万、月15万NISA、デイトレで-50万）
- 著者個人の人物関係（妻、保育士、結婚2027年4月）
- 著者個人の判断や迷い（「ここで悩んだ」「半年かかった」）
- 具体的なツール名（オルカン、S&P500、NASDAQ100、レバ系、SBI、楽天証券）
- 日付や金額の桁数を具体的に（「約500万」より「498万」と書く方が生っぽい）

## 2．装飾ルール（マークダウン記法）

note はマークダウンを自動でリッチテキストに変換する。生成時から記法を入れておけば、note エディタで自動装飾が効く。

### 太字 `**text**`

各段落で 1〜2 フレーズだけ太字に。

- ✅ 良い例：「シートに入れるのは **黄色セル11個だけ** です」
- ❌ 悪い例：「**全部**が**自動**で**わかる**ようになります」（太字が多すぎ）

太字にすべきもの：
- 結論の数字（「**5年で2,000万**」）
- 行動の指示（「**ここを書き換える**」）
- 重要な前提（「**現金と運用は分けて入力**」）

### 引用ブロック `> text`

- 結論を1行で言い切る箇所
- 読者への問いかけ
- 自分の体験談の核

```
> 月15万円の積立を5年続けただけです。
```

### 見出し `## ## ###`

- 章は `##`、節は `###`
- 章は短く（10〜15文字）
- 節は問いの形にしない（「なぜ45歳か？」より「45歳にした3つの理由」）

### 水平線 `---`

章と章の間には必ず入れる。視覚的な区切りで読みやすさが上がる。

### 箇条書き `-`

3つ以上の並列要素は必ずリスト化。

- ✅ 良い：3〜5項目のリスト
- ❌ 悪い：1〜2項目のリスト（リストにしない方が自然）
- ❌ 悪い：6項目以上（読者の集中が切れる、表に変える）

### 表

数値の比較・条件と対応の組は表に。

```markdown
| 種類 | 利率 | 18年後 |
|---|---|---|
| 現金 | 0% | 元本のまま |
| 運用 | 5% | 約2.4倍 |
```

## 3．段落と改行のリズム

### 1段落の長さ

- 1段落 2〜4文（5文以上は読まれない）
- スマホ縦 1画面に 1〜2段落まで（noteの一般的なリズム）

### 文長

- 1文 50〜80字を基本
- 100字超えたら必ず分ける

### 連続する文末

- 「〜です」「〜ます」を3連続させない
- 体言止めの後に「〜です」を続ける
- たまに「〜でした」「〜と考えています」を混ぜる

## 4．売れる記事の構成（柱B 公務員×資産形成）

```
1. リード（200〜300字）
   「こんな夫婦に向けて書きました」
   箇条書きで読者の悩み 3〜4 個
   「私もちょうど半年前まで同じ場所にいました」
2. 先に結論（150〜200字）
   何を渡すか、何が分かるか、を1段落で
3. 自分の物語（500〜800字）
   3つの壁・3つの理由・3つの失敗
   「壁1．」「壁2．」と番号付き見出し
4. 商品の核となる仕組み（500〜800字）
   他と違う1つのポイントだけ深く
5. 商品の中身を全部見せる（1,500〜2,500字）
   各シート・各章の構成を具体的に
   ここで画像を 1〜2 枚入れる
6. 設計のこだわり（300〜500字）
   一番悩んだところ、一番工夫したところ
7. 想定する使い方（200〜300字）
   日常のどの場面で使うか
8. 向き不向き（200字）
   「向いていない」を先に書く
9. 有料パートで渡すもの（150字）
   箇条書きで明示
10. ペイウォール
11. 有料部分（最小限）
    ダウンロードリンクだけ、もしくは
    プラスして著者のリアル数値
```

---

## 5．サムネと冒頭画像

- 1280×670 px（noteの推奨サイズ）
- 文字は太め日本語ゴシック
- 中央に「結論シートのスクショ風」を載せる（商品イメージが伝わる）
- 端には情報を置かない（クロップで切れる）

---

## 6．タイトル

- 全角縦線「｜」は使わない（人間の読み心地が悪い、機械的に見える）
- 区切りは全角スペース or コロン
- 32 文字以内
- 「公務員夫婦のサイドFIRE達成診断シート　5分入力で答えが出る」のような形

---

## 7．記事の自動装飾の優先順位

generate_note_article.py や post_to_note.py で適用する装飾の優先順位。

1. 段落分け（改行 2 つで段落区切り）
2. 章間の `---`
3. 各章の結論文を太字
4. 3項目以上の並列要素をリスト化
5. 数値比較を表に
6. 1記事に引用ブロック `> ...` を 1〜2 個入れる
7. 各章の冒頭で読者への問いかけを 1 文（「〜ですよね」）

---

## 8．ヒット記事の最低条件

| 項目 | 数値目安 |
|---|---|
| 無料部分 | 4,000〜6,000 字 |
| 有料部分 | 300〜2,500 字（商品で決まる） |
| 章の数 | 5〜10 |
| 表の数 | 1〜3 |
| 画像の数 | 2〜5（冒頭、各章、結論前） |
| 太字フレーズ数 | 8〜15 |
| 引用ブロック数 | 1〜2 |
