# 商品制作プレイブック

最終更新：2026-05-24

**参照タイミング：** 新商品を企画・制作するすべての場面

---

## 商品設計の原則

1. **小さく早く出す**：完璧より公開。最初の1弾は2週間以内に。
2. **悩みから逆算**：「先生のこの悩みを解決」を商品ページに必ず明文化
3. **試供品を必ず用意**：BOOTH無料サンプル / note無料記事3本 / Kindle試し読み充実
4. **タイトルは検索される言葉で**：「中2 国語 助動詞 ワークシート」のように具体的に
5. **シリーズ化前提**：単発でなく「シリーズの1本目」として構造化

---

## 対象学年×単元 優先度マトリクス

| 単元 | 優先度 | 理由 |
|------|--------|------|
| 文法（助詞・助動詞・動詞活用） | 高 | 教えにくい単元、需要安定 |
| 漢字・語彙 | 高 | 全学年対応・継続使用される |
| 古文（基礎） | 中 | 苦手意識高い、丁寧な教材ニーズあり |
| 漢詩・返り点 | 中 | 教材が薄い領域、差別化可能（profile.mdで明示） |
| 読解 | 低 | 既存教材多い、差別化難 |
| 作文・表現 | 中 | ニッチだがファン化しやすい |

※ profile.md の優先順位（文法 → 漢詩 → 漢字・語彙）とも整合。

## 品質チェックリスト（公開前）

- [ ] 誤字脱字なし（音読チェック）
- [ ] 学習指導要領に整合（最新版）
- [ ] 解答・解説を分けて掲載
- [ ] 著作権クリア（教科書本文の引用範囲を守る、フリー素材出典明記）
- [ ] iPad/A4印刷で崩れない（rules.md のテンプレ準拠）
- [ ] 商品説明文に「対象学年」「収録範囲」「ページ数」「形式」を明記
- [ ] サムネに「学年」「単元」「形式」が3秒で読める
- [ ] persona.md のNGリストに違反していない（教室写真等）

## ファイル命名規則

rules.md の規約に従う（kebab-case）：
- PDF: `{単元}-{学年}-{形式}-v{バージョン}.pdf`
  - 例: `joshi-chu2-worksheet-v1.pdf`
- HTML: kebab-case
  - 例: `helps-verb-quiz.html`
- バージョン管理：大幅改訂時は v2, v3。誤字修正は v1.1 等

---

## サムネテンプレ

- サイズ：1200×630（BOOTH/note OGP標準）
- 配色：白背景 + アクセント色1〜2色（チープに見せない・profile.mdのデザイン方針）
- フォント：太め日本語ゴシック
- 必須要素：①学年 ②単元 ③形式 ④価格 ⑤ペンネーム（小さく）

## ストック管理

- 完成品：`projects/{shop-name}/products/{商品名}/`
- 制作中：`projects/{shop-name}/wip/`
- アイデアプール：`projects/{shop-name}/ideas.md`（タイトル・概要を3行で）

---

## AIによる商品案出しのプロセス

1. PDCA結果（[pdca-kpi.md](./pdca-kpi.md)）から「次に伸ばす単元」を特定
2. 既存ラインナップとカニバらない切り口を選定
3. タイトル案を5本、商品構成案を3本出す
4. 人間（伊神）が選定 → AIが制作
5. 完成品を `projects/{shop-name}/products/` に保存
6. 商品説明文・サムネ指示書・出品先候補をAddnessコメントに投下 → 人間が出品
