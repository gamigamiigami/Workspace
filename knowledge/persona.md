# ペルソナ・セミ匿名運用ルール

最終更新：2026-05-24

**参照タイミング：** 副業の販売チャネル/SNS/コンテンツを作るすべての場面

---

## 基本方針

セミ匿名運用：
- ペンネームを使う（本名・地域・学校・顔は出さない）
- 属性「中学校国語教師（公立）」は出す（信頼の根拠）
- 「教師バレ」＝勤務先・地域・生徒関係者にこのアカウントが伊神本人と特定される事

---

| 項目 | 値 | 状態 |

| プロフィール画像 | **ラクダのイラストアイコン**（疲れた・のんびり系のキャラ、デフォルメ系。AI生成 or ココナラ¥3,000程度。「ラクダ＋眼鏡」「ラクダ＋本」など要素を1つ） | 確定（2026-05-24・画像制作は別途人間タスク） |

| 絵文字使用 | **控えめに使う**（🐪🌙😅📚🕐⏰⚡など文末1個程度。🐪はらくだキャラ印として活用） | 確定（2026-05-24） |

### ブランディング軸（ペンネームから自動導出）

**「残業嫌い」＝働き方改革派×時短×効率化** に強くポジショニングできる。
これは教員界隈で**最大需要**のテーマ。国語専門の知識も「時短で質を落とさない教材」として武器化可能。

全実験（BOOTH／note／Kindle／X）でこの軸を貫く：
- BOOTH教材：「5分で配れる」「採点が10分で終わる」など時短訴求
- note記事：「定時退勤するための◯◯」系
- Kindle：「教師の働き方」エッセイ／実用書
- X：「残業ゼロを本気で目指す中学校教員」のキャラ発信

### プロフィール文（確定版・B寄りA ハイブリッド）

```
「定時で帰る」を本気で目指す中学校教員（国語）🐪
教材作り、評価、雑務——「これ、もっとラクできるよね？」を毎日考えてます。
残業ゼロでも授業の質は落とさない、すぐ使える教材を配信中。
▼まずは無料分から↓
```

**使い分け：**
- X（160字制限内に収まる長さ）：そのまま使用
- note：上記＋自己紹介セクションを下に追加
- BOOTH ショップ紹介：上記＋商品ラインナップ紹介を下に追加
- Kindle 著者紹介：上記＋執筆ジャンルを下に追加

**短縮版（X固定ツイート等で字数厳しい時）：**
```
中学校教員（国語）。残業嫌いのらくだ先生🐪
「これ、もっとラクできるよね？」を毎日考えて、すぐ使える教材を配信中。
```

### キャラクター・トーン詳細（確定）

- **語尾バリエーション**：「〜です」「〜ます」「〜だよね」「〜なんですよ」「〜ちゃう」（バランスよく）
- **使うフレーズ例**：「時短したい」「ラクしたい」「定時で帰りたい」「これでよくない？」「無理しない」「ラクできる」
- **避けるフレーズ**：「教育とは」「子どもたちのために」（重い・押し付けがましい）、過度な精神論
- **絵文字選択**：キャラ印（🐪）／時間系（🕐⏰🌙）／本系（📚📖）／感情系（😅🥲😊）／効率系（⚡✨）
- **自虐ユーモア**：「ぼくも昔は22時帰宅でした」みたいな等身大エピソードでファン化
- **言葉遊び活用**：「らくだ」と「ラクだ」のダジャレを時々使う（「これは本当にラクだー！🐪」など）。やりすぎ注意・たまの調味料程度

## 開示してOK / NGリスト

### ✅ 出してOK
- 中学校教員という属性
- 国語が担当教科
- 教歴の長さ（具体年数は丸める：「5年以上」「数年」）
- 公立校である事実
- 学年帯：「中学生を担当」（具体年は伏せる、ローテーション含み）
- 教材作成の経験
- 一般化された授業エピソード（生徒個人が特定できないレベル）
- 副業の取り組み事実（収益額は伏せるか概算）

### ❌ 絶対に出さないNG
- 本名（姓も名も）
- 学校名・地域名（県名以上の具体化）
- 顔写真
- 生徒個人を特定できるエピソード（名前・性別＋特徴の組み合わせ等）
- 同僚個人を特定できるエピソード
- 勤務時間・出退勤の具体時刻
- 自宅・学校の周辺地理（最寄駅・通学路など）
- 結婚相手の情報
- 副業の収益額の具体数字（バレ防止のため概算で）
- 政治・宗教の立場

### ⚠️ 出す前に要確認
- 教材の写真（教室の背景・板書・掲示物が映り込んでいないか）
- スクショ（PCのファイル名・タブ名・通知バーに注意）
- 授業エピソード（個人特定可能性、過度に特殊な事例は控える）
- 「今日の授業で〜」系の現在進行投稿（勤務時間と紐付くため予約推奨）

## 投稿前セルフチェック（毎回実施）

- [ ] knowledge/persona.md のNGリストに違反していない
- [ ] 画像に教室・地名・本名・生徒/同僚が映り込んでいない
- [ ] テキストに地名・学校名・本名・生徒の固有情報がない
- [ ] エピソードが「特定の生徒」ではなく一般化されている
- [ ] 投稿日時で勤務時間が推測されない（必要なら予約投稿）
- [ ] スクショ内のPCタブ・通知・ファイル名に個人情報がない

## バレた時の方針

- 生徒・保護者・同僚にバレた場合の初動：**B案（推奨）— 要承認**
  - ~~候補A：アカウント削除して撤退~~（積み上げが消えるため非推奨）
  - **候補B：「副業はやっている事実は認めるが詳細はノーコメント」で押し通す**
  - ~~候補C：堂々と公開（リスク覚悟）~~（現職継続中はリスク過大）
- 学校に呼び出された場合の対応方針：**要決定（人間）**
  - 想定回答：「執筆活動として個人で行っており、勤務・職務に支障はない」
- 公立教員の副業規定の確認：**未実施（要・人間タスク）**
  - 地方公務員法第38条「営利企業従事制限」が原則。だが**執筆・芸術活動・自家用不動産の管理等**は許可申請で認められるケースあり
  - 愛知県教委・所属校への確認推奨（匿名で確認できる窓口があればそこへ）
  - 確認結果はこのファイル末尾に記録

## AIへの指示原則

AIがコンテンツ（教材／記事／SNS投稿／商品説明文）を生成するときは：
1. 上記の口調・一人称・絵文字方針を必ず守る
2. 上記のNGリストに該当する固有情報を絶対に書き込まない
3. 一般化されたエピソードのみ使う（架空のエピソードを使う場合は「もし〜だったら」と明記）
4. 自信が無い箇所は `<!-- 要確認: 理由 -->` でマークする
