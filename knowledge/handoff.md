# 人間タスク手順書（ハンドオフ）

最終更新：2026-05-24

**参照タイミング：** 人間にしかできない作業をやる時

---

## ハンドオフの考え方

AIが出来ないこと：
- ブラウザ操作（ログイン、出品ボタン押下等）
- 本人確認（身分証提出）
- 銀行口座登録
- SNS投稿の実行（投稿ボタンを押す）
- 売上データの取得（管理画面DL）
- 物理的な対面/電話対応

→ これらは伊神（人間）が手を動かす必要がある。
本ドキュメントは「迷わずできる」よう手順化したもの。

## 月次ルーティン（毎月1日 / 約30分）

- [ ] **BOOTH 売上CSV**: ダッシュボード → 売上管理 → CSVダウンロード → 共有フォルダ
- [ ] **note 売上**: 設定 → 売上管理 → 月集計をスクショ → 共有フォルダ
- [ ] **Kindle 印税**: KDPレポート → 月集計をスクショ → 共有フォルダ
- [ ] **X分析**: アナリティクス → 月インプレッション・フォロワー増数をテキスト控え → Addnessにペースト
- [ ] **AIにレビュー依頼**：Addnessに「@Claude 今月のPDCAレポートをお願い」または定期トリガー実行

## 商品出品ルーティン（新商品ごと / 1商品約20〜30分）

### BOOTH
- [ ] `projects/{shop-name}/products/{商品名}/` の中身を確認
- [ ] BOOTH管理画面 → 商品追加
- [ ] AIが用意した商品ページテキスト（title.txt / description.txt / price.txt）をコピペ
- [ ] サムネ画像（1200×630）をアップ
- [ ] PDF/ZIPをアップ
- [ ] 公開 → URLをAddnessコメントに記録

### note
- [ ] 記事テキスト（`articles/{記事名}.md`）をエディタにコピペ
- [ ] サムネをアップ
- [ ] タグ設定（テンプレに従う）
- [ ] 有料/無料を確認 → 公開
- [ ] URLをAddnessに記録

### Kindle (KDP)
- [ ] Word/EPUB原稿をKDP管理画面でアップ
- [ ] 表紙画像アップ
- [ ] 商品説明・キーワード・カテゴリ設定（AI用意分をコピペ）
- [ ] 価格設定（70%印税帯：¥250〜¥1,250）
- [ ] 出版 → 数日後にURLをAddnessに記録

## アカウント開設ルーティン（初回のみ）

### 推奨順序（本人確認書類の提出が重なるため）

1. **X**（最速・無料・本人確認不要）— 集客導線を先に作る
2. **note**（本人確認は売上発生時、無料で始められる）
3. **BOOTH**（Pixiv経由、本人確認1〜2週間かかる）
4. **Kindle (KDP)**（税務情報入力あり、原稿完成後で十分）

### 銀行口座の方針

- 推奨：副業専用口座を新設（楽天銀行／住信SBIネット銀行などネット銀行が便利）
- 全チャネル同じ口座でOK（確定申告時の仕分けが楽）

### BOOTH
1. Pixivアカウント取得（既にあれば飛ばす）
2. BOOTHでショップ開設（屋号 = persona.mdのペンネーム）
3. 売上振込設定で銀行口座登録
4. 本人確認書類提出（運転免許等）
5. 完了後、AddnessにショップURLをコメント

### note
1. メールでアカウント作成
2. プロフィール設定（[persona.md](./persona.md)に従う）
3. クリエイター登録（有料記事を出すなら必須）
4. 銀行口座登録
5. AddnessにプロフィールURL記録

### KDP (Kindle)
1. Amazon.co.jpアカウントから https://kdp.amazon.co.jp/ にログイン
2. 著者情報・税務情報・銀行口座を登録
3. 著者名 = persona.mdのペンネーム
4. 最初の本のアップロードは原稿完成後

### X (Twitter)
1. メールでアカウント作成（既存個人アカと分ける）
2. ユーザー名 = persona.mdのペンネーム
3. プロフィール・固定ツイート設定
4. AIが用意した初期投稿5本を予約
