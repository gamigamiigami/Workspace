# クロスワード（ゲーム用便利ツール）

Workspace 直下の作業フォルダ。クロスワードを「作る側」のための道具を置く場所です。

## 入っているもの

| ファイル | 中身 |
|---|---|
| `crossword-maker.html` | クロスワード作成ツール（1ファイル完結・オフライン動作） |

## 使い方（クロスワード作成ツール）

1. `crossword-maker.html` をダブルクリック（またはiPadのファイルアプリからタップ）してブラウザで開く
2. **① 盤面をつくる** … よこ・たての数を選んで「この大きさにする」
3. **② 黒マスと文字を入れる**
   - 「黒マスを置く」に切り替えてマスをタップ → 黒マスになる（「点対称に黒マスを置く」ONなら反対側も同時に黒くなる）
   - 「文字を入れる」に切り替えてマスをタップ → キーボードで1文字ずつ入力
   - 同じマスをもう一度タップすると入力方向（ヨコ↔タテ）が切り替わる
4. **③ カギ（ヒント）を書く** … 番号ごとの欄に問題文を書く。左の□は今入っている答えのプレビュー
5. **④ 保存・印刷** … 「問題を印刷」で生徒配布用、「解答を印刷」で答え合わせ用

## 特長

- **外部サービス不要・完全無料**：インターネットにつながっていなくても動く（フォントは system-ui、外部CDN・外部API不使用）
- **自動保存**：入力内容はブラウザに自動保存され、閉じても次に開いたとき復元される
- **ファイル保存**：「ファイルに保存」でJSONファイルとして書き出し、別の端末で「ファイルを読み込む」で開ける
- **番号は自動**：黒マスを動かすと番号は自動で振り直される。カギは座標で覚えているので番号が変わっても消えない
- **印刷対応**：`@media print` により、印刷時は操作パネルが消えて盤面＋カギ一覧だけになる

## 注意点

- 自動保存はブラウザごと・端末ごと。**別の端末に持っていくときは「ファイルに保存」を使う**
- プライベートブラウズ（シークレットモード）では自動保存が効かない旨の警告が出る（ファイル保存は使える）
- 1マス＝1文字。ひらがな・カタカナ・漢字どれでも入る（クロスワードとしてはカタカナ推奨）
